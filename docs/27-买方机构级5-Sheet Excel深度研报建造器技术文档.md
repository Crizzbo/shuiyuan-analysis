## 一、 功能背景与业务用途

### 1. 业务背景
在买方机构投资决策与投委会汇报中，静态图片或文本研报无法支持分析师对估值模型、关键假设及三表配平开展即时动态调优与二次测算。传统脚本生成的 Excel 报表存在诸多缺陷：如缺乏网格线、列宽固定导致大量单元格显示为 `###`、未对齐国际会计准则（FAST Standard）与金融色彩规范（CFI），以及缺乏底层资产负债表刚性配平自检公式。本功能基于 OpenPyXL 引擎构建买方机构级 5-Sheet Excel 深度投研工作簿建造器，实现从三表底稿、内生估值、敏感度矩阵到决策备忘录的全联动、多维度交付。

### 2. 核心用途
本功能解决三大投研报告工程问题：
1. **严格对齐 FAST Standard 建模与 CFI 视觉色彩体系**：区分输入事实（深蓝）、派生公式（黑色）与关键假设（淡黄），强制开启网格线并自适应列宽；
2. **原生 Excel 公式注入与平账自检**：在资产负债表置顶行与多阶段 DCF 矩阵内注入原生 Excel 计算公式，支持离线动态重算；
3. **文本物理洁净度保障**：对进入单元格的自然语言执行正则表达式物理清洗，剔除 Emoji 表情符号，保持严肃金融质感。

### 2. 核心数学模型推导

1. **资产负债表刚性配平自检公式**：
   $$Discrepancy = |Assets - (Liabilities + Equity)|$$
   在 Excel 中通过原生函数实现：
   `=IF(ABS(Assets-(Liabilities+Equity))<1, "100% 官方平账配平", "平账异常")`
2. **二维敏感度矩阵估值公式**：
   $$P_{\text{intrinsic}} = \frac{FCF_0 \times (1 + g)}{WACC - g}$$
   断言要求：矩阵内折现率序列与永续增长率序列必须满足 $WACC - g \ge 0.50\%$。
3. **加权字符列宽计算方程**：
   $$\text{Width} = \max\left( \text{MinColWidth}, \; \min\left( \sum_{c \in s} w(c) + 4.0, \; 60.0 \right) \right)$$
   其中对于 ASCII 字符 $w(c) = 1.0$，对于全角中文字符 $w(c) = 2.0$。

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **强制显示网格线**：每个新建的工作表必须显式执行 `ws.views.sheetView[0].showGridLines = True`，防止在跨平台查看时网格线缺失。
- [ ] **冻结窗格配置**：每个工作表必须配置窗格冻结（如 `ws.freeze_panes = "A5"` 或 `ws.freeze_panes = "B5"`），保证上下滚动时表头不丢失。
- [ ] **文本 Emoji 物理过滤**：所有写入单元格的文本必须经由 `AIResearchAgent.clean_text_no_emoji()` 正则过滤，杜绝表情符号。
- [ ] **临时文件原子替换**：工作簿生成过程必须先写入 `.tmp` 临时文件，校验完成之后方可调用 `os.replace` 原子替换，严禁留下破损工作簿。
