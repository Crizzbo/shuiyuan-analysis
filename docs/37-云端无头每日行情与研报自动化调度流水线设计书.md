# 云端无头每日行情与研报自动化调度流水线技术设计规格书 (Cloud Headless Daily Pipeline Specification)

> **功能标识**：`PIPELINE_CLOUD_HEADLESS_DAILY_SUITE`  
> **所属业务分类**：类别 E：底层数据工程层面（云端定时自动化、无头渲染、流式分批分发与密码学链条存证）  
> **技术成熟度**：生产基准 (Production)  
> **单一事实来源**：  
> - 云端主控入口：`scripts/cloud_daily_pipeline.py`  
> - GitHub Actions 调度工作流：`.github/workflows/daily_market_pipeline.yml`  
> - 行情新鲜度门禁：`financial_reporting/quote_freshness_gateway.py`  
> - 密码学预测账本：`financial_core/engines/prediction_ledger.py`  
> - 研报契约 Schema：`schemas/daily-briefing.schema.json`、`schemas/daily_briefing.schema.json`  
> - 自动化测试集：`scripts/test_cloud_daily_pipeline.py`

## 一、 功能背景与业务用途

### 1. 业务背景
在买方机构级日常投研运营中，每日大盘行情分析与公司重点标的跟踪具备极强的时间窗口敏感性：
- **美股市场 (US)**：美东时间 16:00 闭市（北京时间次日 04:00/05:00），需要在盘后完成全天交易数据聚合、恐慌指数与期权 PCR 扫描、重大商业事件穿透与买点推演；
- **日股市场 (JP)**：东京时间 15:30 闭市（北京时间 14:30），需要在收盘后即时生成日经与东证全市场研判并穿透出口制造业与半导体链条。

若将此类重型批处理任务放在本地用户终端运行，不仅长时间占用本地 CPU 与浏览器渲染进程，而且极易因本地休眠、网络波动或环境路径差异导致调度中断。因此，系统必须构建**完全脱离本地桌面、具备高度自洽性与自适应防御能力的云端无头自动化流水线 (Cloud Headless Daily Pipeline)**。

### 2. 核心用途与解决的问题
本规格书解决三大系统级工程痛点：
1. **云端无头自适应渲染 (Headless Cross-Platform Rendering)**：
   在 Linux/GitHub Actions 云端容器中，自动探测并适配无头 Chromium/Google Chrome 或 Edge 引擎，消除对本地特定 Windows 路径与 GUI 桌面的依赖，稳定输出高保真无截断纯净矢量 PDF 与高交互 HTML。
2. **多通道云端交付与流式同步 (Chunk-and-Stream Cloud Delivery)**：
   支持 GitHub Actions 自动化构件归档 (Artifacts) 与 Google Drive API/CLI 云盘即时同步双通道，即使云盘凭证未配置也能优雅降级为本地/容器安全归档，杜绝虚假上传与未捕获崩溃。
3. **不可篡改密码学法证存证 (Tamper-Proof Ledger Verification)**：
   将每次云端自动生成的每日大盘决策与重点个股推演参数计算为 SHA-256 哈希链存入轻量级账本，支持日后客观回溯与防篡改对账。

## 三、 核心接口与执行契约说明

### 1. 命令行接口契约
云端主控脚本 `scripts/cloud_daily_pipeline.py` 严格遵循以下参数规范：

| 参数 | 类型 | 默认值 | 业务语义 |
|---|---|---|---|
| `--market` | 字符串 | `ALL` | 目标市场：`US` (仅美股), `JP` (仅日股), `ALL` (全市场) |
| `--as-of` | 字符串 | 当日日期 | 分析基准日期 (YYYY-MM-DD)，自动适配交易日历 |
| `--render-pdf` | 布尔开关 | 启用 | 是否调用无头浏览器编译生成纯净矢量 PDF |
| `--output-dir` | 路径 | `reports/daily_briefings` | 研报生成文件输出根目录 |
| `--dry-run` | 布尔开关 | 关闭 | 试运行模式，只校验流程与契约，不执行实际上传 |

### 2. 输出交付成果契约
每轮流水线执行后，在指定目录生成以下标准化成果：
1. `YYYY-MM-DD_<市场代码>_每日大盘总行情与深度推荐.html`：现代暗色买方交互式仪表盘；
2. `YYYY-MM-DD_<市场代码>_每日大盘总行情与深度推荐.pdf`：A4 规格矢量无截断出版级研报；
3. `YYYY-MM-DD_<市场代码>_daily_briefing.json`：全息强类型机器可读数据底账；
4. `pipeline_execution_receipt.json`：包含本轮任务状态、执行耗时、时效检查结果与 SHA-256 哈希凭证的防伪收据。

## 四、 云端无头渲染防腐机制

在无头 Linux 容器环境下，渲染引擎按以下优先级自动探测：
1. `chromium-browser` 或 `chromium` (Debian/Ubuntu 官方预装)
2. `google-chrome` 或 `google-chrome-stable`
3. `microsoft-edge` 或 `microsoft-edge-stable`
4. 环境变量 `BROWSER_HEADLESS_PATH` 指定的自定义二进制

渲染参数强制追加：
`--headless=new --disable-gpu --no-sandbox --disable-dev-shm-usage --print-to-pdf --no-pdf-header-footer`
确保在零图形界面、极简 Linux 环境下 100% 稳定运行。

## 五、 验收门禁标准

1. **零外部网络阻塞**：流水线内置离线兜底数据源，在未联网或沙箱环境中能够依托本地归档平滑降级，100% 通过语法与契约校验；
2. **Schema 契约 100% 合规**：生成的 JSON 数据必须通过 `schemas/daily_briefing.schema.json` 强类型核验；
3. **密码学验签通过**：每次运行的决策卡片必须产生唯一的 SHA-256 存证哈希并能通过 `ledger.verify_integrity()` 验签；
4. **单元测试零失败**：`scripts/test_cloud_daily_pipeline.py` 覆盖各阶段模拟测试，100% 成功。
