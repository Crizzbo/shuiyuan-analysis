# 美股与日股核心标的归档与分析技术设计规格书 (Cross-Market Equities Archive Specification)

> **功能标识**：`ARCHIVE_US_JP_CORE_UNIVERSE_SPEC`  
> **所属业务分类**：类别 E：底层数据工程层面（多市场统一归档、原生日元计价准则、ADR 反解与六步指标体检）  
> **技术成熟度**：生产基准 (Production)  
> **单一事实来源**：  
> - 结构化标的档案库：`knowledge/companies/`  
> - 归档主索引：`knowledge/companies/README.md` 与 `knowledge/companies/companies.json`  
> - 汇率与 ADR 折算引擎：`financial_reporting/data_converter.py` (`convert_adr_to_home_price`)

> - 自动化测试集：`scripts/test_company_archive.py`、`scripts/validate_knowledge_structure.py`

## 一、 功能背景与业务用途

### 1. 业务背景
在跨市场跨币种的买方投研实践中，标的覆盖与档案维护常面临三大工程挑战：一是美股（USD）与日股（JPY）在计价币种、申报准则（US-GAAP vs J-GAAP）与财报披露频次上的异质性；二是部分日股由于直接行情源受限，仅能获取美股柜台交易的 ADR 报价，若直接将美元 ADR 价格当作本土基准将导致估值量级严重错位；三是若缺乏标准化的多维度健康体检，容易导致投资组合忽视周期性顶部泡沫或重度烧钱企业的估值下杀风险。本功能构建美日双市场统一归档标准、原生日元计价规范、ADR 精确反解及全息通用指标体检系统。

### 2. 核心用途
本功能解决三大跨市场投研归档问题：
1. **多市场统一归档六步标准化模板**：确立涵盖“证券标识、商业模式与护城河、通用财务体检、行业专属驱动、估值分层策略、催化剂与风险边界”的标准化知识库结构；
2. **日股原生日元（JPY / 円）计价准则与 ADR 反解**：严格执行日股日元计价规范，针对仅有 ADR 报价的场景，通过 ADR 换算比率与即期汇率精准反解本土普通股价格；
3. **三大战略梯队分类与风险监控**：将全盘标的划分为“优质现金牛/防御复利型”、“核心工业与科技平台型”以及“高估值预警/周期顶部监控型”，实现差异化跟踪监控。

### 2. 核心数学模型推导

1. **ADR 价格反解本土日元价格方程**：
   $$P_{\text{Home, JPY}} = \left( \frac{P_{\text{ADR, USD}}}{\text{Ratio}} \right) \times \text{Rate}_{\text{USD/JPY}}$$
   其中：$\text{Ratio}$ 为每份 ADR 所代表的普通股股数。
2. **通用财务健康综合得分方程**：
   $$Score_{\text{health}} = 0.30 \times S_{\text{profit}} + 0.25 \times S_{\text{cashflow}} + 0.25 \times S_{\text{solvency}} + 0.20 \times S_{\text{liquidity}}$$
   评级转换规则：$\ge 85$ 为 A 级，$70 \sim 84$ 为 B 级，$55 \sim 69$ 为 C 级，$< 55$ 为 D 级。
3. **真实安全边际率**：
   $$\text{MOS}_{\text{pct}} = \frac{P_{\text{fair}} - P_{\text{current}}}{P_{\text{fair}}} \times 100\%$$

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **日股原生日元计价刚性遵从**：日股本土标的价格、市值与现金储备一律以原生日元（JPY / 円）呈现，严禁在下游报告中强制或冗余转换为美元。
- [ ] **ADR 换算比率正数断言**：执行 ADR 反解时，`adr_ratio` 必须严格大于零；若传入非正数值，系统必须抛出 `ValueError`，杜绝除零崩溃。
- [ ] **汇率时效与界限保护**：USD/JPY 即期汇率必须限定在物理合理区间 $[80.0, 250.0]$ 内，超出界限立即报警并拒绝执行反解。
- [ ] **链接内部封闭性自检**：所有归档文档中的 Markdown 相对链接必须解析在项目根目录内且目标文件真实存在，严禁越界或悬空死链。
- [ ] **现金储备量级标注清晰**：日股大额现金储备统一以“万亿日元（兆円）”为单位列报，美元统一以“百万美元”或“十亿美元”列报，严禁数量级混淆。
