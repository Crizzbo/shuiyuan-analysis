> **功能标识**：`FREE_SOURCES_AND_MCP_EVALUATION_SPEC`

## 一、 功能背景与业务用途

### 1. 业务背景
在买方证券投研系统的构建过程中，外部数据获取通常面临高昂的商业终端费用、复杂的接口授权（API Key/App ID）以及不透明的数据清洗黑盒。传统投研团队容易陷入两大极端：一是过度依赖商业付费数据供应商，在未授权或接口限流时系统直接瘫痪；二是将未经验证的第三方 MCP（Model Context Protocol）工具或社区爬虫直接引入生产环境，引发凭据泄露与协议越权风险。依据本项目 2026-10-11 原始数据接入授权与零配置数据策略，本规范对 14 类主流免费数据源及官方/社区 MCP 适配器进行深度安全审计与架构定界，确立“零付费依赖、公开权威披露优先、MCP 纯只读代理、缺口由官方原版补数”的工程准则。

### 2. 核心用途
本功能解决全系统三大数据源治理与准入问题：
1. **14 类免费数据源边界与限流矩阵 (Rate Limits SSOT)**：系统化定义美股 SEC submissions、日股 TDnet 披露、日本央行 BOJ、美联储 FRED CSV 及全球事件 GDELT 等免费渠道的并发频次与物理边界；
2. **MCP 工具安全性与权限审计架构**：对 EdgarTools、Alpha Vantage MCP、J-Quants MCP、长桥/富途 MCP 进行调用通道与鉴权机制审计，严禁将通道能力等同于免费全量数据覆盖；
3. **官方监管原件绝对事实优先准则**：严格区分“官方披露原件（Level 0 事实）”、“公开数据接口（Level 1 观察）”与“AI 搜索摘要/二手研报（Level 2 线索）”，禁止模型将二手推算作为原始事实录入底层。

## 二、 系统架构上下文与依赖关系

### 1. 前置依赖 (Inputs From Upstream)
- 官方监管系统公开披露协议（SEC EDGAR、TDnet、BOJ、FRED）：提供公开数据规范。
- 宿主 MCP 授权环境：提供受控只读的 Google Drive / Google Sheets 通道。

### 2. 后置消费 (Outputs To Downstream)
- `data_sources/official_filings/`：提供经核验下载的官方财报原始文件。
- `data/catalog/`：由 `data_catalog.py` 消费外部抓取切片并固化为不可变 `.blob` 对象。
- `financial_core/`：消费经来源凭证审计的权威财务与宏观序列。

### 3. 数据流转时序图
```
┌──────────────────────────────────────┐
│  外部数据需求 (财报/行情/宏观序列)   │
└──────────────────┬───────────────────┘
                   │ (匹配数据源准入白名单)
                   ▼
┌──────────────────────────────────────┐
│  数据接入与协议审计网关              │
│  ├── 免配置公开来源 ──► 直接安全调用 │
│  ├── 需商业 Key 接口 ──► 物理硬拦截   │
│  └── 第三方 MCP ──► 只读审计/受控接入│
└──────────────────┬───────────────────┘
                   │ (下载官方原件并验证哈希)
                   ▼
┌──────────────────────────────────────┐

│  (生成 SHA-256 签名与 source-manifest)│
└──────────────────────────────────────┘
```

### 2. 核心数学模型推导

1. **SEC 官方抓取限流漏桶算法 (Leaky Bucket Limiter)**：
   $$r_{\text{request}} \le 10.0 \text{ req/sec}, \quad \Delta t_{\text{interval}} \ge \frac{1.0}{r_{\text{max}}} = 0.10 \text{ sec}$$
   本项目防御性下调至 $\Delta t \ge 1.0 \text{ sec}$，以彻底杜绝被官方服务器屏蔽。
2. **三级事实置信度度量方程**：
   $$\text{Confidence}(D) = \begin{cases} 
      1.00, & D \in \text{Official Regulatory Filings (SEC/EDINET)} \\
      0.80, & D \in \text{Issuer Direct IR Releases} \\
      0.60, & D \in \text{Public Statistical Aggregates (FRED/BOJ)} \\
      0.20, & D \in \text{Media RSS / Secondary Feeds}
   \end{cases}$$
3. **文件指纹与完整性防篡改核验**：
   $$\mathbb{I}(\text{Integrity}) = \Big(\text{SHA-256}(\text{FileBytes}) \equiv \text{Manifest.Digest}\Big)$$

## 五、 状态机与来源成熟度 (State Registry)

### 1. 数据源集成与审计状态空间

| 状态代号 | 英文枚举标识 | 中文状态名称 | 判定特征 | 投研系统动作 |
| :--- | :--- | :--- | :--- | :--- |
| `SRC_01` | `PRODUCTION_FREE`| 生产免配置态 | 零 Key 依赖，官方公开稳定，已通过回归。 | 作为正式投研数据供给源。 |

| `SRC_04` | `MCP_READONLY` | MCP 只读受控态| 宿主已授权的只读通道（如 Google Sheets）。| 允许提取数据并在本地先归档。 |

### 输出字段逐项业务释义
| 输出字段名称 | 字段标识 | 数据类型 | 计量单位 | 业务释义 |
| :--- | :--- | :---: | :---: | :--- |
| 采集流水号 | `source_fetch_id` | `str` | 字符串 | 外部数据采集单次任务全局业务键。 |
| 提供商代号 | `data_provider` | `str` | 字符串 | 数据实际物理来源（SEC, TDnet, FRED 等）。|
| 归档物理路径 | `local_archive_path` | `str` | 相对路径 | 采集文件在本地不可变对象库中的落盘路径。|
| 密码学摘要 | `sha256` | `str` | 64位十六进制 | 原始文件的不可逆哈希校验指纹。 |
| 免配置标识 | `is_zero_config` | `bool` | 布尔值 | 指示该抓取过程是否 100% 摆脱 API Key 依赖。|

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **严禁自动订阅任何外部收费服务**：系统严禁代码包含任何发起扣费、购买套餐或升级 API 权限的逻辑。
- [ ] **严格遵循官方限流约束**：对 SEC EDGAR 的请求频次必须控制在 $\le 10 \text{ req/sec}$（生产环境执行 $\ge 1.0\text{s}$ 间隔），严禁并发轰炸被封。
- [ ] **MCP 权限严格锁定只读**：允许使用的 MCP 工具仅限于宿主已连接的只读数据读取通道，严禁通过 MCP 导出本地密码或凭据。
- [ ] **零本地个人下载目录扫描**：导入下载文件时必须使用确切传递的文件路径，严禁任何扫描系统 Downloads 目录的遍历行为。
- [ ] **先本地归档后参与研究**：所有外部获取的行情与文件，必须先在本地 `data/` 目录完成归档与哈希固化，再交由金融核心引擎参与计算。
