# 美日股全市场盘前采集调查

调查日期 2026-11-15（日本时间）。范围为项目内美股和东证证券池，以及每个交易日开盘前取得上一完成交易日的日线。美股盘前实时成交和报价属于另一个数据集，应单独评估时效与授权。

## 实施顺序与完成条件

1. **锁定每个交易日的证券清单。** 归档交易所清单与日历的原文和摘要。以市场、证券代码、交易日作为对账键，逐项报告挂牌、退市、代码变更、类别和重复记录。按计划执行日期推导最近完成交易日。
2. **先验证日股批量路径。** 从 JPX 日刊索引定位前一交易日原档。留存来源链接、取得时间、文件哈希及版式版本。以晚盘收盘或仅有成交的时段收盘组装日线，以首个有效开盘、有效高低点和换算后的成交量组装其余字段。用归档样本对照 PDF 原表，验证停牌、空值、单位和重复区段。自动化与使用范围通过核对后接入采集。
3. **验证美股公开批量候选。** 检查 Nasdaq 导出可否在盘前提供目标交易日的完整 OHLCV，并用交易所目录校验覆盖。如果公开源只能提供最新成交价或部分字段，美股任务继续归档实际查到的日线，保留每日全量批量源缺口。Massive 可供未来来源策略调整时对照评估。
4. **区分每日追加和历史回填。** 每天优先追加目标交易日的一条日线；一年历史另行分批获取，独立记录进度。先归档原始文件并校验，再按证券和交易日落盘。修订追加版本。失败恢复从来源或交易日断点续跑。
5. **用对账结果验收。** 每市场记录计划运行时间、实际运行时间、目标交易日、目标证券数、目标日匹配数、无交易、待补、未映射和异常数。原档迟到时在盘前窗口按可用性重试，面板显示当前覆盖与原因。验证一个普通交易日、跨周末、一个美股假期、一个日股假期和一个夏令时切换窗口。确认实际盘前计划连续运行且每个目标证券都有行情或可解释的状态，才能标记每日全量流程通过。

当前代码已接入全量轮询、任务日志、按市场续跑和历史日期展示。东证 PDF 解析及美股公开批量源仍处于调查与验收阶段。
