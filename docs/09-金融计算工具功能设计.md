## 一、 功能背景与业务用途

### 1. 业务背景
在买方机构投资决策中，定量计算是连接基本面事实与资产定价的枢纽。传统金融计算工程常存在四大系统性缺陷：
1. **开源库与自研逻辑边界混淆**：开源计算库与自研专有模型混杂调用，缺乏统一的参数校验与生命周期管控；
2. **底层计算反向依赖业务层**：核心计算引擎直接引用外层渲染脚本或网络工具，破坏了计算结果的纯净性与可复现性；
3. **函数调用缺乏图谱化链路**：各计算模块之间数据流动碎片化，输入参数与返回值缺乏严格类型契约与链路传递说明；
4. **缺乏极值防御与测试场景矩阵**：在面对资不抵债、负现金流、极端波动率等非标场景时，模型容易发生除零错误、数值发散或静默产出虚假数字。

本系统建立双层物理隔离架构，构建向下兼容中继层 (`finance_tools/`) 与底层纯净金融计算核心 (`financial_core/`)，为公司估值、期权定价、信用违约评估及组合风控提供单一事实来源（SSOT）。

### 2. 核心用途
本功能覆盖五大计算能力集群与七大分析模式：
1. **基础现金流与财务比率中枢**：等间隔现金流（NPV、IRR、MIRR）、日历日现金流（XIRR、XNPV）及杜邦三步拆解比率；
2. **多阶段内生价值折现与桥梁**：多阶段自由现金流折现 (FCFF)、股权自由现金流 (FCFE)、剩余收益模型 (EVA)、生物医药 rNPV 管线折现及 REITs/NAV 清算价值桥；
3. **结构化信用与破产违约测度**：Merton (1974) 结构化违约距离、预期违约概率 (EDF)、Altman Z-Score 财务破产评分及纯债安全垫；
4. **随机模拟与肥尾组合风控**：10,000 次蒙特卡洛 DCF 分位数分布、Cornish-Fisher 修正 VaR/CVaR、流动性加压调整及 Ledoit-Wolf 最优收缩协方差；
5. **衍生品曲面与跨周期估值**：连续红利 BSM 全阶解析希腊字母（Delta, Gamma, Vega, Theta, Rho）、Durrleman 偏斜凸度约束、CRR 100步美式二叉树提前行权溢价测算及 Shiller CAPE 穿越周期估值。

### 2. 核心数学方程系统

1. **加权平均资本成本 (WACC) 与宏观压力传导方程**：
   $$WACC_{\text{shocked}} = \frac{E}{V} K_e + \frac{D}{V} K_d (1 - \tau) + \Delta WACC_{\text{macro}}$$
   其中股权资本成本 $K_e$ 由资本资产定价模型与宏观溢价确定：
   $$K_e = R_f + \beta \times ERP + \lambda_{\text{carry}} \times \Delta \text{USDJPY} + \lambda_{\text{vix}} \times (VIX - 20)$$

2. **多阶段内生价值折现模型 (Multistage DCF)**：
   $$EV = \sum_{t=1}^{n} \frac{FCFF_t}{(1 + WACC)^t} + \frac{FCFF_n \times (1 + g_{\text{terminal}})}{(WACC - g_{\text{terminal}}) \times (1 + WACC)^n}$$
   $$P_{\text{fair}} = \max\left(0.10, \; \frac{EV - \text{TotalDebt} + \text{UnrestrictedCash}}{\text{SharesOutstanding}} \times \left(1 - \frac{\text{Haircut}_{\text{forensic}}}{100}\right)\right)$$

3. **Merton (1974) 结构化违约距离 (Distance to Default) 与违约概率**：
   资产价值 $V_A$ 与波动率 $\sigma_A$ 的伊藤联立方程：
   $$E = V_A \Phi(d_1) - D e^{-rT} \Phi(d_2)$$
   $$\sigma_E = \left(\frac{V_A}{E}\right) \Phi(d_1) \sigma_A$$
   违约距离定义为资产价值超出负债清偿线的标准差倍数：
   $$DD = d_2 = \frac{\ln(V_A / D) + (r - 0.5 \sigma_A^2) T}{\sigma_A \sqrt{T}}$$
   $$\text{Expected Default Frequency (EDF)} = \Phi(-DD)$$

4. **Cornish-Fisher 肥尾修正 VaR (Value at Risk)**：
   利用分布的高阶偏度 $S$ 与超额峰度 $K$ 修正正态分位数 $z_\alpha$：
   $$z_c = z_\alpha + \frac{1}{6}(z_\alpha^2 - 1)S + \frac{1}{24}(z_\alpha^3 - 3z_\alpha)K - \frac{1}{36}(2z_\alpha^3 - 5z_\alpha)S^2$$
   $$\text{VaR}_\alpha = - (\mu + z_c \sigma), \quad \text{CVaR}_\alpha = \mathbb{E}[-R \mid R \le -\text{VaR}_\alpha]$$

5. **CRR 100步美式期权二叉树反向折现方程**：
   上升因子 $u = e^{\sigma \sqrt{\Delta t}}$，下降因子 $d = \frac{1}{u}$，风险中性概率 $p = \frac{e^{(r - q)\Delta t} - d}{u - d}$：
   $$V_{i, j} = \max\Big(\text{Payoff}(S_{i, j}), \; e^{-r \Delta t}[p V_{i+1, j+1} + (1-p) V_{i+1, j}]\Big)$$
   $$\text{Early Exercise Premium} = V_{\text{American}} - V_{\text{European}}$$

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **四层架构纯净依赖**：`financial_core/` 目录严禁导入 `finance_tools`、`scripts` 或任何外层渲染模块，违者架构巡检直接判定不通过。
- [ ] **严禁正式投研模式静默加载演示样本**：若标的底账缺失且未显式指定 `allow_demo_sample=True`，系统必须立即抛出阻断异常，严禁加载假数据伪装真实研究。
- [ ] **有限责任与非负下界约束**：每股公允估值、股票现价与股权价值理论下界锁定为 0.00，禁止向报告层输出负资产价值。
- [ ] **戈登永续增长分母正数保护**：在计算永续终值时，强制 $WACC - g_{\text{terminal}} \ge 0.50\%$，若分母 $\le 0$ 必须触发数值截断并记录日志，杜绝数学发散。
- [ ] **IRR 单根唯一性保护**：现金流序列符号变化超过 1 次时，系统必须拒绝给出默认单根，提示使用 MIRR 替代。
- [ ] **资产负债表平账刚性门禁**：Stage 1 必须断言 $|Assets - (Liabilities + Equity)| \le \max(1.0, Assets \times 0.01)$，超差直接终止流水线，拒绝垃圾进垃圾出。
- [ ] **真实现金跑道区分净造血与净烧钱**：当经营现金流覆盖资本开支时，必须输出哨兵值 `-1.0`（持续净流入），严禁向造血企业计算虚假烧钱跑道。
- [ ] **期权未计算项显式置空**：未经过完整树计算或跨期定价的项，输出必须显式为 `None`，严禁使用 0.0 默认值导致下游误判为零成本期权。
- [ ] **单调估值走廊刚性约束**：三情景目标价必须在物理输出前满足严格的单调走廊检验：$P_{\text{pessimistic}} \le 0.90 \times P_{\text{neutral}} < P_{\text{neutral}} < 1.10 \times P_{\text{neutral}} \le P_{\text{optimistic}}$。
