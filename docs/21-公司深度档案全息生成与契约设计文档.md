> **功能标识**：`DEEP_DOSSIER_GENERATION_CONTRACT_SPEC`  
> **所属业务分类**：类别 E：底层数据工程与研报生产层面（全息财报三表、护城河五维解构、供应链网络、库存周期 DIO、三态 DCF 估值矩阵与流式交付）  
> **技术成熟度**：生产基准 (Production)

## 一、 功能背景与业务用途

### 1. 业务背景
在覆盖美股（SEC EDGAR 10,000+ 上市主体）与日股（东证 JPX 4,400+ 上市主体）的全量资产池深度研究实践中，传统研报生产面临四大系统性缺陷：一是机械数据堆砌，单纯打印冗长指标大表，缺乏针对商业胜负手与悲观底价的因果推演；二是缺乏官方原始底稿穿透，缺乏直接核验发行人 SEC 10-K / 10-Q 或 TDnet 有价证券报告书（有価証券報告書）三表底账的凭据链条；三是营运资本与债务墙盲区，忽略库存周转天数（DIO）周期演进与 24 个月债务墙风险；四是上下游产业链穿透不足，忽视核心供应商与客户集中度的单点断供传染风险。本功能构建全息公司深度档案标准体系，提供从底层官方三表、护城河五维解构、供应链网络到长短期差异化情景 DCF 估值矩阵的全息贯穿。

### 2. 核心用途
本功能解决三大深度研报交付与工程问题：
1. **六大业务维度全息档案建模**：严格遵循 `schemas/deep_dossier.schema.json`，标准化输出“标的概览、官方三表深度体检、护城河五维解构、上下游产业链生态、赛道格局与胜负手、长周期催化与三态 DCF 估值矩阵”；
2. **营运资本、库存周期与债务墙压力测试**：定量核算库存周转天数（DIO）四象限演进，穿透 24 个月短期债务墙与基准利差走阔下的利息覆盖倍数；
3. **买方机构 A4 矢量排版与流式分批分发**：基于 Microsoft Edge Headless 编译工业级 A4 矢量 PDF，支持 50~100 标的批次分块（Batch Chunking）与边渲染边上传（Chunk-and-Stream）的流式交付体验。

## 二、 系统架构上下文与依赖关系

### 1. 前置依赖 (Inputs From Upstream)
- `data_sources/official_filings/`：提供通过 $Assets = Liabilities + Equity$ 平账检验的官方原始三表底账。
- `knowledge/companies/<ticker>.md`：提供标的商业模式、历史胜负手与护城河基础事实。
- `financial_core/engines/`：提供 WACC 贴现率、所有者收益与三态 DCF 估值数值。
- `scripts/env_discovery.py`：动态感知本地 `msedge.exe` 与 `gdrive` 工具环境路径。

### 2. 后置消费 (Outputs To Downstream)
- `reports/ai_dossiers/<market>/<ticker>_deep_dossier.json`：落盘结构化全息深度档案底账。
- `reports/<batch>_generated/<market>_<ticker>_公司深度档案.pdf`：交付矢量排版 PDF 研报。
- `data/ledger/predictions_ledger.sqlite3`：消费悲观底价与公允估值锚点，写入不可篡改存证链条。

### 2. 核心数学模型推导

1. **存货周转天数 (Days Inventory Outstanding, DIO)**：
   $$DIO = \frac{\text{Average Inventory}}{\text{Cost of Goods Sold (COGS)}} \times 365$$
2. **利息覆盖倍数 (Interest Coverage Ratio, ICR)**：
   $$ICR = \frac{\text{Operating Income (EBIT)}}{\text{Gross Interest Expense}}$$
   当 $ICR < 2.5$ 时，标记进入财务警戒状态；当 $ICR < 1.0$ 时，判定利息无法由主营业务覆盖。
3. **基准利率走阔利息挤压压力测试方程**：
   $$\Delta \text{InterestExpense} = \text{DebtWall}_{\text{24M}} \times \Delta r_{\text{spread}}$$
   $$\text{FCF}_{\text{shocked}} = \text{FCF}_{\text{baseline}} - \Delta \text{InterestExpense} \times (1.0 - T)$$
4. **长短期差异化三态情景 DCF 估值矩阵**：
   $$P_{\text{fair}} = \sum_{t=1}^{T} \frac{\text{OwnerEarnings}_t}{(1 + WACC)^t} + \frac{\text{OwnerEarnings}_T \times (1 + g)}{(WACC - g) \times (1 + WACC)^T}$$
   - **悲观底价（Conservative Floor）**：$WACC_{\text{shock}} = WACC + 150\text{bps}$，永续增长率 $g \le 1.5\%$；
   - **中性公允（Base Fair Value）**：管理层正常化跨周期指引；
   - **乐观弹性（Bull Target）**：$WACC_{\text{bull}} = WACC - 50\text{bps}$，新业务超预期渗透。

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **官方三表平账硬性断言**：录入深度档案的财务数据必须满足 $|Assets - (Liabilities + Equity)| \le 1.0$，严禁非平衡底稿录入。
- [ ] **严禁模板假数字**：所有财务数字、DIO 天数、客户集中度及估值靶心必须来自官方真实底账，严禁使用静态占位符填数。
- [ ] **流式分批防锁控制**：批处理生成必须采用 Chunk-and-Stream 管道，严禁等待全量标的离线生成完成后才一次性启动网络上传。
- [ ] **工具路径零绝对硬编码**：Microsoft Edge Headless 与 Google Drive CLI 工具必须通过 `scripts/env_discovery.py` 动态探测，严禁代码硬编码本地个人路径。
- [ ] **高清矢量 PDF 编译保证**：必须采用 Headless 真实编译排版，严禁使用截屏图或低清位图伪造 PDF 研报。
