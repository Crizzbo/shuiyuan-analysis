## 一、 功能背景与业务用途

### 1. 业务背景
在传统量化金融与宏观压力测试中，普遍存在“大盘下跌 $X\%$ 则股票线性下跌 $\beta \times X\%$”的机械假设。这种线性映射切断了宏观货币水库、基准利率预期、要素成本通胀及主权法治环境对微观企业资本配置与折现成本的传导因果链。本引擎以新凯恩斯主义货币经济学、微观加成率理论、现代制度经济学及内生熊彼特创造性破坏模型为理论基石，建立自上而下内生贯通微观三表与折现率的量化传导架构。

### 2. 核心用途
本功能实现四大宏观向微观映射中枢：
1. **维克塞尔自然利率缺口与前瞻期限 WACC 传导**：计算政策利率与自然均衡利率的相对缺口，输出 1~10 年期非线性递延贴现率向量；
2. **微观加成率与成本通胀弹性挤压**：根据微观企业市场地位（加成率 $\mu$），推演大宗商品与劳动力成本上涨对企业毛利率的真实转嫁能力；
3. **主权制度质量指数 (IQI) 与终值治理核减**：评估法治、产权及监管稳定性，对跨国经营及制度脆弱企业执行长期资本折价；
4. **技术前沿距离 (DTF) 与熊彼特创造性破坏**：量化技术颠覆风险，给予领跑企业整合溢价，同时对落后产能计提淘汰折价。

### 2. 数学公式定义与推导

1. **维克塞尔自然利率缺口 (Wicksellian Monetary Gap)**：
   $$\text{Real Policy Rate} = i - \mathbb{E}[\pi]$$
   $$\text{Monetary Gap} = (i - \mathbb{E}[\pi]) - r^*$$
   - 缺口 $> 0$：货币环境处于实质紧缩区间，微观投资机会成本提升；
   - 缺口 $\le 0$：货币环境处于中性或宽松扩张区间。
2. **前瞻期限利率曲线与 WACC 向量推导**：
   $$y(t) = \frac{1}{t}\sum_{k=1}^t \mathbb{E}[i_k] + TP(t)$$
   $$WACC(t) = \frac{E}{V} \Big( y(t) + \beta \times ERP + \text{Spread}_{\text{inst}} \Big) + \frac{D}{V} \Big( y(t) + \text{Spread}_{\text{credit}} \Big)(1 - \tau)$$
3. **企业微观加成率与成本通胀转嫁方程**：
   $$\mu = \frac{P}{MC} \approx \frac{\text{Revenue}}{\text{COGS}} \times \frac{1}{\alpha_{\text{var}}}$$
   $$\text{Shocked Gross Margin} = 1.0 - (1.0 - GM_0) \times \frac{1 + \text{Input Inflation}}{1 + \epsilon \times \text{Input Inflation}}$$
   其中 $\epsilon = \min(1.0, \max(0.0, (\mu - 1.0) / 0.5))$ 代表成本转嫁弹性。
4. **主权制度质量指数 (IQI) 与治理利差**：
   $$IQI = 0.35 \times PR + 0.30 \times RoL + 0.20 \times Reg + 0.15 \times Corr$$
   $$\text{Spread}_{\text{inst}} = \max\left(0, \; (100 - IQI) \times 3.5\text{ bps}\right)$$

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **贴现率非负与下界保护**：动态 WACC 向量中的任意元素必须满足 $WACC(t) \ge 3.5\%$，严禁负折现率或零折现率穿透至估值核心。
- [ ] **加成率下界约束**：微观加成率 $\mu$ 设定物理下界 $\mu \ge 1.00$；当企业营业毛利严重倒挂时，$\mu$ 截断为 1.00，禁止出现小于 1.00 的加成倍数。
- [ ] **成本转嫁弹性区间收敛**：弹性系数 $\epsilon$ 必须闭包在 $[0.0, 1.0]$ 区间内，禁止转嫁系数超过 100% 导致利润虚假倒贴。
- [ ] **宏观参数时效门禁**：无风险收益率与通胀预期必须标注基准时点，早于当前交易日的数据必须声明为历史收盘基准。
