## 一、 功能背景与业务用途

### 1. 业务背景
在买方机构投资管理中，传统晨会往往面临四大顽疾：一是“研报过载与信息碎片化”，分析师各自为战，投委会面对成百上千页分散研报无法提炼决策焦点；二是“缺乏宏观流动性约束与仓位纪律”，在牛市中盲目全仓甚至加杠杆，在大盘极端流动性枯竭时无流动性护城河；三是“主观预测不可追溯”，历史研判存在事后修正与幸存者偏差，缺乏不可篡改的实证对账机制；四是“缺乏明确的买点与底线价格”，研报多为泛泛而谈的看多结论，缺乏导致击穿悲观底价的触发事件推演。本规范确立基于 Canyon 统一单向流水线的投委会决策晨报、30% 现金储备纪律、黄金击球区金字塔建仓及 SHA-256 密码学账本防篡改架构。

### 2. 核心用途
本功能解决全系统三大投委会核心决议与行动控制问题：
1. **端到端单向线性决策研判 (Canyon Linear Pipeline)**：串联“行情时效核验 ➔ 三表平账自检 ➔ 宏观动态 MOS ➔ 三态现金流折现 ➔ 击球决策与仓位控制 ➔ SHA-256 存证”，秒级输出机构级决策卡；
2. **大盘流动性雷达与 30% 现金硬约束**：由全市场综合压力分 $S_{\text{macro}}$ 动态调节安全边际（基准 20% 动态扩张至 23%+），并刚性锁定组合至少 30% 现金底线；
3. **不可篡改密码学法证对账 (Cryptographic Ledger)**：将每次晨会发布的买入/观望评级、靶心价格与置信区间写入 SHA-256 哈希链条，T+N 日强制自动对账复盘。

### 2. 核心数学模型推导

1. **全市场宏观综合压力分方程**：
   $$S_{\text{macro}} = w_1 \times \frac{\text{VIX} - \text{VIX}_{\text{min}}}{\text{VIX}_{\text{max}} - \text{VIX}_{\text{min}}} + w_2 \times \frac{\text{TIPS} - \text{TIPS}_{\text{min}}}{\text{TIPS}_{\text{max}} - \text{TIPS}_{\text{min}}}$$
2. **动态弹性安全边际扩张方程**：
   $$\text{MOS}_{\text{elastic}} = \text{MOS}_{\text{base}} \times \Big(1.0 + \alpha \times S_{\text{macro}}\Big)$$
   其中基准 $\text{MOS}_{\text{base}} = 0.20$，敏感度调节因子 $\alpha = 0.30$。
3. **带 30% 现金硬底线约束的半凯利仓位修正**：
   $$f_{\text{kelly}} = \frac{p \times b - (1 - p)}{b}, \quad f_{\text{half}} = 0.5 \times f_{\text{kelly}}$$
   $$f_{\text{final}} = \min\Big(f_{\text{half}}, 1.0 - \text{CashReserveRatio}\Big), \quad \text{其中 } \text{CashReserveRatio} \ge 0.30$$
4. **不可篡改密码学账本验签**：
   $$\text{Hash}_i = \text{SHA-256}\Big(\text{Hash}_{i-1} \,\|\, \text{Timestamp} \,\|\, \text{Ticker} \,\|\, \text{Corridor} \,\|\, \text{Signal}\Big)$$

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **严禁在溢价过热区追高**：当标的处于 `PREMIUM_OVERVALUED` 状态时，系统推荐仓位必须刚性断言为 $0.0\%$，严禁开仓建议。
- [ ] **30% 现金储备底线不可突破**：单标的或组合建仓算法中，可用资金池上限不得超过总资产的 $70.0\%$，必须强制锁定 $30.0\%$ 现金等价物。
- [ ] **必须前置核验行情时效与时区**：输出报价前必须强制执行 `verify_quote_freshness`，未核验时间戳的报价严禁流入决策卡。
- [ ] **不可篡改账本哈希单向校验**：生成的 SHA-256 签名必须包含前一区块哈希，并成功通过 `ledger.verify_integrity()` 验签。
- [ ] **极端流动性提款机右侧建仓**：当 $S_{\text{macro}} \ge 0.55$ 或 $\text{VIX} \ge 24$ 时，必须显式提示流动性提款机效应，指导分批金字塔建仓。
