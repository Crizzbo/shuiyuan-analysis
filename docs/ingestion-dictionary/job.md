# 采集任务表

对象：计划 JSON。任务定义摘要用于断点恢复，任务名称不能替代参数或证券身份。

| 字段 | 中文名称 | 类型 | 业务含义与约束 |
|---|---|---|---|
| schema_version | 计划版本 | string | 必须为 1.0.0 |
| jobs | 任务列表 | array | 单次最多 200 项，串行请求 |
| jobs[].id | 任务名称 | string | 非空，计划内唯一；修改日期或参数改变恢复身份 |
| jobs[].provider | 来源标识 | string | 必须存在于已登记 sources；未知来源拒绝 |
| jobs[].dataset | 数据集标识 | string | 仅支持适配器已实现的免费候选端点 |
| jobs[].params | 查询参数 | object | 股票代码、公司标识、日期、申报号等公开参数；不放密钥 |

各 dataset 的参数说明见 [使用说明](../12a-免费数据接入使用说明.md)。`cik` 表示 SEC 发行人；`symbol` 表示供应商证券；`sec_code` 表示 EDINET 证券代码；三者不是可互换字段。日期格式随来源不同，必须遵守接口说明。
