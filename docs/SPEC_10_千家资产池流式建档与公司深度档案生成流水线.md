# 水源智能投研系统 · 千家资产池流式建档与公司深度档案生成流水线 (SPEC-10)

> **设计典籍代号**：`SPEC_10_MULTI_THOUSAND_ENTERPRISE_STREAMING_PIPELINE`  
> **所属业务分类**：全盘海量资产池分层、批处理流式调度、深度档案自动化装配  
> **专责系统职能**：定义全量数千家美股与日股资产池分级架构、分批调度 (Batch Chunking)、流式边渲染边上传 (Chunk-and-Stream)、断点续跑与增量缓存更新机制。  
> **权威单一事实来源 (SSOT)**：`data/universe/`、`scripts/legacy_batch_runners/` 与 `data_sources/` 系列建档管线。

## 一、 全盘数千家海量资产池的分级治理架构

面对美股（SEC 官方登记 10,000+ 家上市公司）与日股（东证全市场 Prime/Standard/Growth 4,400+ 家上市公司）共计全量数千家标的庞大池子，系统严禁局限于少数静态样本，推行严密的分级资产池架构 (Tiered Universe Architecture)：

| 资产池分级 | 战略定位与目标标的规模 | 享受投研深度与更新频率 |
|---|---|---|
| **Tier 0 (核心旗舰 / 顶层重仓池, P0)** | 顶层蓝筹与系统重要性巨头（约 150~200 家，如科技七巨头、东证核心 30、黄金核心股等） | **最高频动态覆盖**：享受官方财报三表全息底稿、日度高频事件追踪、库存周转穿透与多情景差异化 DCF 估值矩阵。 |
| **Tier 1 (主线成长 / 细分中坚池, P1)** | 高流动性中大型成长股与各赛道行业胜负手代表公司（约 600~800 家） | **定期全景覆盖**：纳入季度情景更新、SEPA 波动收敛形态扫描与安全边际买点监控。 |
| **Tier 2 / Tier 3 (全市场全息池, P2/P3)** | 全市场数千家上市公司的全息索引（覆盖全量 14,000+ 家代码） | **底账自动化维护**：全息维护 SEC CIK、东证代码、行业分类与基础财报底账，支持自动化批量构建与分批增量覆盖。 |

## 二、 流式分批并发流水线 (Chunk-and-Stream Pipeline)

为了在海量计算与网络交付中实现高吞吐，系统坚决杜绝“全部任务在本地单机离线跑完才统一上传”的保守做法，强制推行**流式分批管道 (Chunk-and-Stream)**：
1. **分批任务切片 (Batch Chunking)**：
   全盘标的按每批次 10 至 50 家企业划分为独立运行单元（如 Batch 1 至 Batch 79），确保单个批次在受控的时间与内存窗口内完成；
2. **并发防锁与防假死**：
   各个批次拥有独立的临时编译沙箱与文件锁，避免多进程写入同一目标目录导致的数据冲突；
3. **边渲染边流式交付 (Streaming Delivery)**：
   每批次深度档案在 HTML/PDF 渲染及 Schema 校验通过后，即刻流水线触发云端同步与密码学链条存证，实现持续平滑的数据流转；
4. **断点续跑与增量感知 (Checkpoint & Resume)**：
   每个批次执行后生成带时间戳的防伪收据（`batchXX-receipt.json`）。调度器在重新运行时自动扫描已完成标的，仅对未建档的增量标的进行补数计算，坚决不进行重复无谓计算。

## 三、 公司深度档案 (Deep Dossier) 自动化装配与契约保障

每份深度档案必须通过 `schemas/deep_dossier.schema.json` 强类型自检门禁：
1. **公司商业机器概览 (overview)**：包含 Ticker、法定公司全名、所属市场 (US/JP)、行业代号、商业模式与业务营收结构拆解；
2. **财报质量与三表穿透 (financial_statement_deep_dive)**：覆盖造血盈利质量、净现金状态、DIO 库存周转天数、短长期负债结构与利息保障倍数；
3. **微观博弈护城河解构 (moat_analysis)**：涵盖网络效应、客户转换成本、规模成本优势、专有无形资产与资本再投资效率；
4. **上下游生态与供应链集中度 (supply_chain_analysis)**：穿透核心供应商替代壁垒与前五大客户集中度；
5. **行业终局与胜负手推演 (industry_dynamics)**：明确胜负手因子、市场份额集中度与行业 TAM 天花板；
6. **三态情景跨周期估值 (long_term_outlook)**：输出催化剂、下行黑天鹅熔断风险与三态 DCF 估值矩阵。
