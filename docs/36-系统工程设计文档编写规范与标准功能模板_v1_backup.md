## 第一部分：设计文档编写三大刚性法则

为确保技术文档具备工业级软件工程的严肃性、确定性与可审计性，全系统所有工程设计文档必须严格遵循以下三大法则：

### 法则一：全篇陈述，严禁疑问句与倒装句
1. **纯粹的陈述与肯定表达**：文档通篇采用清晰、客观的陈述句和肯定句，直接声明系统的结构、输入、处理逻辑与输出。
2. **拒绝探究式设问**：严禁出现“如何评估某项数值？”、“怎样处理异常？”、“是否应该采用某种方案？”等对话式、探讨式的疑问句。探讨与权衡过程属于前期立项阶段，正式设计文档仅记录最终拍板的确定性方案。
3. **消除倒装与歧义语序**：严格遵循“主语 + 谓语 + 宾语”的标准工业书面中文语序，避免文学性倒装。

### 法则二：客观工程语言，彻底剥离 AI 提示词（Prompt）符号
1. **剥离口语化与情绪化约束**：严禁在文档中出现诸如“【必须牢记】”、“【严禁...违者...】”等针对大模型指令跟随的 Prompt 式情绪化用语。
2. **去除工程符号伪装饰**：严禁在非必要场景滥用大写代号、感叹号或特定修辞标签，保持与国际主流技术规格书（如 RFC、IEEE 软件工程规范）一致的严谨客观文风。
3. **聚焦流程与因果网络**：文档核心聚焦于表达：**系统架构上下文、数据前后置依赖关系、状态跃迁矩阵、精确到字段的数据契约与数学公式推导**。

### 法则三：正向主流程与负面防御边界彻底分离 (Checklist 解耦)
1. **主文档专注正向确定性**：文档正文专注于描述系统在合法输入下的标准业务动线、主导数学模型与确定性返回值。
2. **负面约束收敛于自查清单**：所有关于“输入异常防御”、“参数非法拦截”、“边界极值保护”、“除零除负防御”等负面约束条件（“在 X 条件下，禁止执行 Y”），一律从正文主干中剥离，统一归入文末附录的《工程实现与边界自查清单（Checklist）》。

## 第四部分：工业级示范样板 (Golden Sample)

### [示范文档] 微观公司内在价值分析：多阶段自由现金流折现功能设计书

> **功能标识**：`VAL_MULTISTAGE_DCF`  
> **所属业务分类**：类别 C：微观公司内在价值与财务估值  
> **技术成熟度**：生产基准 (Production)  
> **单一事实来源**：`financial_core/engines/multistage_dcf_engine.py` 与 `finance_tools/valuation.py`

#### 一、 功能背景与业务用途
本功能用于计算企业在持续经营假定下的内在公允价值（Intrinsic Value）。通过对企业未来有限预测期内的自由现金流进行分阶段推演，结合终值永续增长模型折现至评估基准日，再穿透扣除企业带息净负债，最终输出普通股每股理论公允价格及安全边际，为买方投资组合提供基准价值锚点。

#### 二、 系统架构上下文与依赖关系
1. **前置依赖**：
   - `financial_core/engines/official_filing_mapper.py`：提供经配平核验的官方财报三表底稿（营业收入、经营性现金流、资本性支出、带息债务与现金储备）。
   - `financial_core/engines/macro_valuation_engine.py`：提供宏观利率传导后的动态加权平均资本成本（WACC）。
2. **后置消费**：
   - `financial_reporting/excel_dossier_builder.py`：消费每股公允价值与敏感度矩阵，渲染 5-Sheet Excel 估值底稿。
   - `financial_core/engines/prediction_ledger.py`：消费估值中枢与置信区间，生成 SHA-256 密码学时间链条。

       [ - 减去: 带息净负债 Net Debt: $50.00 百万美元 ]
                       ▼
             【股东权益价值 Equity: $1550.00 百万美元】
                       │
       [ ÷ 除去: 稀释流通总股数 Shares: 10.00 百万股 ]
                       ▼
             【每股理论公允价格: $155.00 美元/股】
```

##### 2. 核心数学公式
1. **预测期各期自由现金流推演**：
   $$FCF_t = FCF_{t-1} \times (1 + g_t) \quad (t = 1, 2, \dots, n)$$
2. **预测期离散现金流现值加总**：
   $$PV_{explicit} = \sum_{t=1}^{n} \frac{FCF_t}{(1 + WACC)^t}$$
3. **企业终值计算（采用戈登增长模型）**：
   $$TerminalValue = \frac{FCF_n \times (1 + g_{terminal})}{WACC - g_{terminal}}$$
4. **终值贴现至当前时点**：
   $$PV_{terminal} = \frac{TerminalValue}{(1 + WACC)^n}$$
5. **企业价值穿透为每股股权价值**：
   $$EnterpriseValue = PV_{explicit} + PV_{terminal}$$
   $$EquityValue = EnterpriseValue - NetDebt$$
   $$ValuePerShare = \frac{EquityValue}{SharesOutstanding}$$

#### 附录：工程实现与边界自查清单 (Engineering Defense Checklist)
- [ ] **贴现率与永续增长率分母正数约束**：贴现率必须严格大于永续增长率（$WACC > g_{terminal}$）。若分母 $\le 0$，程序抛出 `ValueError` 阻断计算，杜绝数学发散。
- [ ] **有限责任下界保护**：每股公允价值下限设定为 0.00。当净负债大于企业价值导致股权价值为负时，每股价值截断为 0.00。
- [ ] **除零防御**：稀释总股数必须大于零，禁止执行以零为分母的除法。
- [ ] **数值合法性校验**：所有浮点数入参必须为实数，禁止 `NaN` 或 `Infinity` 穿透至核心计算层。
