# 买方投研业务场景需求调研与一二期边界划分书 (Buy-Side Investment Research Requirements & Scoping)

> 版本：1.0.0  
> 适用对象：投委会委员、投资总监、宏观策略分析师、行业研究员、风控合规官与产品工程团队。  
> 核心目标：立足真实买方机构投资全流程，界定业务痛点、角色操作动线、核心场景闭环与一期/二期建设边界。

---

## 一、 买方机构核心业务痛点诊断 (Problem Diagnosis)

在传统的买方二级市场股票投研体系中，机构普遍面临以下五大深层次痛点：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. 宏观叙事与微观选股“两张皮”                                                │
│    宏观团队大谈降息与通胀，行业研究员却在算单台设备单价，两者缺乏数量化传导桥梁。 │
├─────────────────────────────────────────────────────────────────────────────┤
│ 2. 估值模型沦为“拍脑袋数字游戏”                                             │
│    DCF 模型随意调节折现率或永续增长率以迎合既定结论，缺乏硬性安全边际防线。      │
├─────────────────────────────────────────────────────────────────────────────┤
│ 3. 财报暴雷与“洗澡”陷阱频发                                                 │
│    净利润表面高增，但经营现金流枯竭、存货激增、应收激增，缺乏底层三表法证穿透。  │
├─────────────────────────────────────────────────────────────────────────────┤
│ 4. “好公司买在山顶”，缺乏精准择时与风控纪律                                  │
│    基本面优异但入场时机错误，买在第一/第三阶段或追高被套，跌破止损线却因人情犹豫  │
│    不断补仓，最终导致永久性资本损失。                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│ 5. 全球数千家企业资产池“看不过来”                                            │
│    美股 10,000+ 家、日股 4,400+ 家企业，人工无法兼顾高频跟踪与深度挖掘。         │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 二、 投研组织核心角色画像与人机操作动线 (User Personas & Workflows)

系统必须适配投资机构内部不同岗位的差异化关注点，提供精准的信息密度：

### 1. 投资总监 / 投委会主席 (CIO / IC Chair)
* **核心职责**：顶层资产配置、系统性风险控制、决定重点标的开仓/平仓决议。
* **人机操作动线**：
  * 早晨 07:15（美股收盘后）阅读《每日大盘行情研报（Daily Briefing）》，重点看宏观流动性、VIX 恐慌度与 AI 顶层决策研判；
  * 审阅投委会晨会 Memo，重点查看处于**“击球区”**且触发**“SEPA 买入信号”**的 Top-30 候选标的；
  * 监督 30% 硬性现金底线，做出加仓、观望或防御指令。

### 2. 宏观与资产配置策略师 (Macro Strategist)
* **核心职责**：追踪维克塞尔自然利率缺口、制度风险溢价、全球产业链投入产出与黑天鹅压力测试。
* **人机操作动线**：
  * 使用系统动态监测微观加成率 $\mu$ 与技术前沿距离 $DTF$；
  * 针对突发地缘冲突、关税战或流动性收缩事件，一键发起全资产池黑天鹅多资产血肉冲击测算，评估组合潜在回撤。

### 3. 行业与公司研究员 (Sector & Equity Analyst)
* **核心职责**：覆盖 41 细分行业，输出《公司深度建档报告书（5-Sheet Excel Dossier）》。
* **人机操作动线**：
  * 穿透官方原始 SEC 10-K/10-Q/TDnet 三表底稿，执行五刀法证解构；
  * 录入行业专属指标（如 DIO、上下游集中度、产能利用率、研发转化率）；
  * 设定悲观、中性、乐观三大情景的触发事件与公允内在价值。

### 4. 战术操盘手 / 交易员 (Tactical Trader)
* **核心职责**：严格执行买方交易纪律，捕捉最小阻力线突破买点，铁血执行风控。
* **人机操作动线**：
  * 监控米奈尔维尼 SEPA 买入信号状态；
  * 严格遵循“枢轴买点放量开火”、“超买 +5% 严禁追高”、“浮盈 3R 上提止损保本”及“跌破刚性止损线无条件斩仓”。

## 三、 四大核心业务场景闭环剖析 (Core Business Scenarios)

### 场景 A：晨会决策闭环（07:00 美股 / 16:00 日股）
```
[大盘收盘与行情落盘] 
       │
[QuoteFreshnessGateway 门禁核验] ──> 断言时间戳与时段（盘前/盘中/盘后/前收盘）
       │
[宏观流动性与恐慌度解析] ───────> VIX, Nikkei VI, 资金净流向, 期权 PCR
       │
[千家资产池击球区扫描] ─────────> 筛选现价落入悲观底价与中性公允之间的价值标的
       │
[SEPA买方时机决策卡挂载] ───────> 标记放量突破、超买拦截与深蹲洗盘状态
       │
[A4矢量HTML / PDF / MD输出] ────> 推送投委会晨会讨论并流式上传归档
```

### 场景 B：公司深度建档与投委会过会闭环
* 针对 Tier 0 / Tier 1 重点公司，自动生成 5-Sheet Excel 交互式工作簿：
  * **Sheet 1 (投资备忘录)**：估值防线走廊 + 诺奖宏观微观传导 + SEPA 操盘卡 + 上行催化剂/下行触发器；
  * **Sheet 2 (行业与护城河)**：商业模式画像 + 供应链上下游集中度 + 护城河结构解构；
  * **Sheet 3 (官方三表底稿)**：连续年度三表全息数据 + 刚性平账公式 ($A = L + E$) + 杜邦拆解；
  * **Sheet 4 (情景DCF与敏感度)**：动态 WACC 向量 + 自由现金流预测 + 双变量敏感度走廊；
  * **Sheet 5 (审计溯源台账)**：官方文件 SHA-256 登记 + 事件索引。

### 场景 C：洗盘识别与深蹲保护闭环 (Squat & Reversal Recovery)
* **业务痛点**：股票在放量突破枢轴买点后，常因大盘短暂跳水或主力震仓出现回落，若机械设定固定止损容易被假摔震出筹码。
* **系统闭环**：
  * 若股价回落至买点下方，但**守住刚性硬止损线**且处于 **50 日均线上方**，同时**成交量显著萎缩（缩量回踩）**；
  * 系统触发 `SQUAT_REVERSAL_WATCH`（深蹲洗盘观察态），发出指令：“给予 1~2 天观察期，守住底线坚决不割肉！一旦放量逆转收复买点，可再次加仓”。

### 场景 D：历史研判密码学对账与防篡改闭环
* 任何 AI 研判、给出的目标价与买卖指令，产生瞬间即由 `PredictionLedger` 生成 SHA-256 哈希值写入不可变区块链式数据库；
* 盘后复盘严格以加密时间账本为基准，杜绝“事后诸葛亮”或篡改历史预测。

## 四、 建设阶段划分与明确排除清单 (Scoping & Explicit Exclusions)

为确保工程交付质量与系统高吞吐稳定运行，严格界定一期（MVP）与二期的职责边界：

### 1. 一期建设范围（必须做透的主动脉）
* **资产池覆盖**：美股（10,000+ 家索引，567 家深度）与日股（4,400+ 家索引，150 家深度）的流式分批建档；
* **三表标准化**：官方 SEC EDGAR / TDnet 三表清洗与刚性平账自检；
* **估值防线走廊**：单调有序的三态情景（悲观底价 $\le$ 中性公允 $\le$ 乐观靶心）；
* **宏观微观联动**：自然利率缺口、加成率、制度指数与黑天鹅冲击模拟；
* **技术择时卡片**：米奈尔维尼 SEPA 买入信号、VCP 4T 收缩足迹、价格边界解耦与 3R 移动保本；
* **多模态交付**：A4 矢量 HTML、FAST 规范 5-Sheet Excel、投委会 Markdown 简报、PDF 自动生成与 Google Drive 流式同步；
* **治理底线**：四道硬核验收门禁（AST 零逆向依赖、全量单测全绿、密码学账本防篡改）。

### 2. 二期及后续规划（一期坚决不做的明确排除清单）

| 序号 | 排除功能项 | 一期坚决排除的业务原因 |
| :---: | :--- | :--- |
| **01** | **实盘交易柜台接口直连 (Broker API)** | 一期专注于**买方研究与决策中枢**，直连实盘涉及券商合规、高频网络与资金安全风险，避免系统臃肿。 |
| **02** | **毫秒级/Tick 级高频分时回测** | 本系统服务于**中长期价值与波段成长投资**，不需要高频逐笔撮合，一期统一以日线收盘价及分时整点快照为基准。 |
| **03** | **无证据的黑箱情感/舆情算命** | 严禁抓取未经核实的散户贴吧论坛水军言论计算所谓“情绪热度”；一期仅采用官方公告、机构期权大单 PCR 与 VIX 恐慌度。 |
| **04** | **复杂跨国多币种智能换汇结算** | 一期美股统一以美元（USD）核算，日股统一以日元（JPY）核算，财报换算采用官方固定报表汇率，不建自营外汇头寸对冲模块。 |
| **05** | **移动端原生 App 开发** | 投委会研报与 5-Sheet Excel 依赖大屏幕数据穿透与密集比对，一期全量支持响应式 A4 Web/iPad 与 Excel 交互工作簿。 |
