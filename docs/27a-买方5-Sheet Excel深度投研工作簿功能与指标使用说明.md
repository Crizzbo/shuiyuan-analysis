## 一、 功能背景与业务用途

### 1. 业务背景
在买方机构证券投资与投委会决议实践中，传统的静态卖方研究报告（PDF/扫描件）面临四大系统性痛点：一是“黑箱数字与死图”，公式不可见、不可查，杜邦拆解与内生估值缺乏可验证的数学勾稽链条；二是无法进行“实时交互调参”，投委会面对宏观基准利率变动时，无法即时测试贴现率或永续增长率调整对内在价值走廊的冲击；三是财务数据脱离法律事实，缺乏对发行人 SEC 10-K 或东证有価証券報告書官方文件编号与密码学哈希的溯源锚定；四是报告充斥主观臆测与晦涩工程符号，缺乏通俗商业投资直觉。本系统确立基于 FAST/CFI 国际建模标准的 5-Sheet 动态联动 Excel 深度投研工作簿技术规范。

### 2. 核心用途
本功能解决全系统三大专业交付与投委会交互决策问题：
1. **五大联动工作表全息建模 (5-Sheet Architecture)**：构建涵盖“00_投资备忘录与决策中枢”、“01_行业与护城河竞争格局”、“02_官方三表全息审计底稿”、“03_内生估值与敏感度走廊”及“04_审计溯源与重大事件跟踪”的完整金融工作簿；
2. **会计平账刚性置顶与杜邦三步穿透**：Sheet 3 首行置顶刚性平账自检（$Assets \equiv Liabilities + Equity$），并下嵌净利率、资产周转率与权益乘数的杜邦动力学分解；
3. **投委会现场 $5 \times 5$ 双变量敏感度走廊**：在 Sheet 4 中支持围绕 WACC 与永续增长率 $g$ 的淡黄色交互单元格调参，实时重塑估值矩阵并分发击球点决策信号。

### 2. 核心数学模型推导

1. **资产负债表刚性配平恒等检验**：
   $$\text{CheckRow} = \text{Total Assets} - (\text{Total Liabilities} + \text{Total Stockholders' Equity}) \equiv 0.00$$
2. **杜邦三步动力学分解方程**：
   $$\text{ROE} = \left( \frac{\text{Net Income}}{\text{Revenue}} \right) \times \left( \frac{\text{Revenue}}{\text{Average Assets}} \right) \times \left( \frac{\text{Average Assets}}{\text{Average Equity}} \right)$$
3. **两阶段自由现金流 DCF 与终值模型**：
   $$PV = \sum_{t=1}^{N} \frac{FCF_t}{(1 + WACC)^t} + \frac{FCF_N \times (1 + g)}{(WACC - g) \times (1 + WACC)^N}$$
4. **$5 \times 5$ 双变量敏感度矩阵单元格生成**：
   $$P_{\text{cell}}(i, j) = \frac{\text{EnterpriseValue}(WACC_i, g_j) + \text{NetCash}}{\text{SharesOutstanding}}$$
   其中：$WACC_i \in [WACC - 2\%, WACC + 2\%]$，$g_j \in [g - 1\%, g + 1\%]$。

## 五、 状态机与视觉色彩规范 (State Registry)

### 1. 华尔街 FAST 标准色彩状态空间

| 色彩样式代号 | 视觉颜色 | HEX 编码 | 代表语义 | 操作与工程规则 |
| :--- | :--- | :---: | :--- | :--- |
| `CLR_01` | 深蓝字白底 | `#0000FF` | 原始输入数据 (Inputs) | 来自官方财报，严禁手改，破坏底账一致性。 |
| `CLR_02` | 纯黑字白底 | `#000000` | 公式与计算结果 (Calculations) | 由原生 Excel 公式自动生成，滚动重算。 |
| `CLR_03` | 淡黄背景 | `#FFF2CC` | 关键假设调参区 (Assumptions) | 允许分析师在敏感度测试时修改数值观察弹性。 |
| `CLR_04` | 浅绿背景 | `#E2EFDA` | 击球买点区 / 平账通过 | 提示极佳的安全边际或三表配平 100% 正常。 |
| `CLR_05` | 浅橙背景 | `#FCE4D6` | 风险预警区 / 破位提示 | 提示估值过热溢价、客户集中或断供风险。 |

### 2. 买方击球决策信号空间 (Strike Signals)

| 信号代号 | 英文枚举标识 | 中文决策名称 | 判定特征 | 投委会行动策略 |
| :--- | :--- | :--- | :--- | :--- |
| `SIG_01` | `BUY_ZONE` | 击球买点区 | 现价折价落入悲观底线附近，安全边际极高。| 建立核心仓位，金字塔建仓。 |
| `SIG_02` | `HOLD_OR_WATCH`| 观望跟踪区 | 现价处于悲观底与中性公允锚点之间。 | 维持观察，等待更好价格或催化兑现。 |
| `SIG_03` | `PREMIUM_OVERVAL`| 溢价过热区 | 现价透支中性乃至乐观价值，风险收益比劣变。| 坚决回避追高，获利止盈。 |

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **严禁黑箱静态死数字**：Sheet 3 与 Sheet 4 中的合计行、杜邦分解与估值模型必须使用原生 Excel 公式编写，严禁写入硬编码死数字。
- [ ] **置顶平账自检行刚性断言**：Sheet 3 首行必须包含会计恒等式配平公式，差额不为零时工作簿必须标红预警，严禁掩盖不平账。
- [ ] **华尔街 FAST 视觉标准严格遵从**：输入数据统一深蓝字，计算结果纯黑字，调参单元格淡黄色背景，严禁随心所欲乱填颜色。
- [ ] **物理净化任何表情符号**：工作簿内严禁包含任何 Emoji 表情或非标装饰字符，保持买方机构级严谨质感。
- [ ] **零网络依赖纯代码生成**：工作簿编译必须完全由 Python 本地库（如 openpyxl）离线生成，严禁通过外部网络办公软件 API 转换。
