# 财务期间

| 字段代码 | 中文名称 | 类型 | 必填 | 业务含义 |
| --- | --- | --- | --- | --- |
| `start` | 期间起日 | string/null | 是 | 流量统计起日；时点存量必须为空 |
| `end` | 期间止日 | string | 是 | 统计止日或资产负债表时点 |
| `basis` | 期间类型 | string | 是 | 年度、季度、时点或累计/其他；不得自动把半年变成单季度 |

字段与 `schemas/financial-report.schema.json` 同源生成；对象数组的具体运行结果见 14 功能设计。
