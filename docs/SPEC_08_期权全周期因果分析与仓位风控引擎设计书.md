## 一、 期权投资的核心本质与因果防线

期权是一柄**高度不对称且自带时间熔断机制的杠杆手术刀**：
1. **彻底杜绝“跳过现价盘口直接预测百倍暴利”**：
   期权定价完全依赖于标的股票现价、行权价、剩余天数与隐含波动率。严禁在没有明确标的现价时效与盘口买卖价差的情况下给出任何期权建议；
2. **警惕虚值期权归零黑洞**：
   虚值期权 (OTM) 的权利金中包含 100% 的纯时间价值；若到期日标的股票未涨过行权价加权利金之和，该合约将**全额归零**（损失 100%）；
3. **仓位绝对硬约束**：
   由于期权自带高归零风险，系统强制采用**四分之一凯利公式 (Quarter-Kelly)**，单只期权配置金额通常严禁超过投资组合总净值的 2.0%，杜绝单次黑天鹅重仓爆仓。

## 二、 五级因果推导链条 (Five-Stage Causal Chain)

系统严格按照五级因果顺序依次展开推导：

```
[第一级：标的物现价与时效核验 (Spot & Session Gate)]
   │ 检验标的现价、时间戳及市场时段（盘前/盘中/盘后/前收盘）
   ▼
[第二级：期权盘口与合约属性 (Contract & Premium)]
   │ 锁定行权价 K、到期剩余天数 DTE、期权类型 (Call/Put) 与实际买入权利金 Ask
   ▼
[第三级：期权性质与时间价值拆解 (Moneyness & Time Value)]
   │ 判定实值 (ITM) / 平价 (ATM) / 虚值 (OTM)，拆解内在价值与纯时间价值
   ▼
[第四级：保本损益平衡点与归零风险 (Break-Even & Total Loss Risk)]
   │ 计算到期保本价（看涨为 K + 权利金）、标的所需涨幅 % 与到期归零概率
   ▼
[第五级：三态情景到期损益与四分之一凯利风控 (Payoff & Quarter-Kelly)]
   │ 测算悲观/基准/乐观情景下的实际净损益与回报倍数，输出仓位比例上限
```

## 三、 时间价值拆解与损益平衡点测算

1. **价值构成拆解**：
   - **内在价值 (Intrinsic Value)**：若看涨期权且现价大于行权价，内在价值 = 现价 - 行权价；否则为 0；
   - **时间价值 (Time Value)**：时间价值 = 市场买入权利金 - 内在价值；
   - 虚值期权醒目提示：**“本合约当前不含任何内在价值，权利金为 100% 纯时间价值，时间流逝每天都在产生价值损耗”**；
2. **保本平衡点 (Break-Even Price)**：
   - 对于看涨期权，到期保本股价 = 行权价 + 买入权利金；
   - 标的必须上涨幅度 % = (保本股价 - 标的当前现价) / 标的当前现价；
   - 投资直觉：股票仅上涨至行权价是不够的，必须额外涨出支付给卖方的权利金成本，投资者才能真正开始盈利。

## 四、 情景到期损益分布与四分之一凯利风控

结合标的股票在到期日的三态情景价格（悲观底价、基准价值、乐观靶心）：
1. **情景净损益核算 (Payoff Calculation)**：
   - 悲观情景：标的跌破支撑，期权虚值归零，每股净损失等于全部权利金（回报率 -100%）；
   - 基准情景：标的稳步上涨达到基准内在价值，行权获得内在收益，扣除权利金后得出净收益率；
   - 乐观情景：标的爆发大涨达到乐观靶心，期权深度实值，展现 2 倍至 10 倍以上高弹性净收益；
2. **四分之一凯利资金配置比例 (Quarter-Kelly)**：
   - 综合各情景概率与盈亏幅度计算数学期望收益与盈亏赔率 $b$；
   - 全凯利公式给出理论最大化几何增长率的最优仓位，但波动剧烈；
   - 系统强制取其 $1/4$，并在最乐观情况下**强制封顶于 2.0%**，确保即使连续遭遇极端归零事件，基金资产底盘依然绝对安全。
