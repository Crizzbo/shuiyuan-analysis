> **专责系统职能**：定义完全脱离本地环境依赖的云端无头定时自动化流水线、跨平台无头浏览器探测、交易时段行情时效门禁、大盘宏观研报与重点个股三态推演卡片生成标准。

## 一、 云端自治与每日大盘决策的核心价值

买方投资决策具备极强的时间窗口敏感性与无人值守自动化要求：
1. **彻底解放本地生产力**：
   本地个人电脑面临关机、休眠、网络波动与不同操作系统路径差异等不稳定因素；每日收盘后的大盘行情与研报生产必须交由云端 GitHub Actions 容器无人值守定时调度执行；
2. **拒绝机械打印数千行无用大表**：
   每日大盘研报绝不能泛滥打印数千行毫无决策价值的无用股票行情表；研报必须高度聚焦于宏观流动性大盘总况（利率、利差、美元指数、恐慌情绪、期权 PCR），并将核心重点推荐股票以独立富文本卡片呈现；
3. **强制标明行情新鲜度与交易时段**：
   严禁把过时的旧数据当作盘中最新价提供给投资者；每次生成报告前必须通过时效门禁，明确显式标注具体时间戳与交易时段状态（盘前、盘中、盘后或前收盘基准）。

## 三、 跨平台无头渲染防腐机制

在 GitHub Actions (Ubuntu 容器) 或无图形界面 Linux 服务器上，流水线按以下优先级自动探测并适配浏览器渲染引擎：
1. 系统预装的 `chromium-browser` 或 `chromium`；
2. 官方 `google-chrome` 或 `google-chrome-stable`；
3. 微软 `microsoft-edge` 或 `microsoft-edge-stable`；
4. 环境变量 `BROWSER_HEADLESS_PATH` 指定的自定义路径。

渲染调用参数强制包含：
`--headless=new --disable-gpu --no-sandbox --disable-dev-shm-usage --run-all-compositor-stages-before-draw --print-to-pdf --no-pdf-header-footer`
确保在零图形界面、极简 Linux 环境下 100% 稳定输出出版级矢量 PDF，无黑屏、无页眉页脚干扰、无布局截断。

## 四、 重点推荐股票独立富文本三态卡片规范

每日研报中的重点推荐标的必须以富文本卡片形式清晰呈现以下核心推演：
1. **现价与时效基准**：精确到分钟的报价与时效状态标注；
2. **买方安全边际买入触发点**：明确何种价格区间具备高确定性左侧布局赔率；
3. **三态情景具体推演**：
   - **悲观底价推演**：指明导致跌入悲观底价的具体触发黑天鹅事件（Downside Gap %）；
   - **基准公允推演**：指明基准业务进展下的合理目标（Upside Gap %）；
   - **乐观爆发推演**：指明催化剂爆发下的潜在上涨空间（Potential Gain %）；
4. **战术操作指南**：提供直接明了的买方配置策略（如“维持科技进攻核心仓位，在回调至支撑线分批吸纳”）。


## 行情门禁结果传播

报价日期以交易所当地日期判断，纽约盘后跨 UTC 零点仍属同一当地日期。进入后续开市时段后，先前时段的报价降为前收盘基准，不能继续标为盘中现价。真实节假日和提前收盘日历仍按发布矩阵单独验收。

归档写入与读取必须保留原始采样时间戳，并传播 QuoteFreshnessGateway 的 is_valid、is_fresh_today 和 session_status。缺少采样时间时不得使用读取时间补齐。档案门面缺少时间戳时标为 invalid_timestamp。归档成功与报价具有当前使用资格分别判断。
