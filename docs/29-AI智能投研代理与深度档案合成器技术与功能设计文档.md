## 一、 功能背景与业务用途

### 1. 业务背景
在买方机构研究实践中，定性商业研判与定量估值模型常处于脱节状态：定性文本常充斥“护城河极深”等主观描述，但在底层折现公式中却依旧套用生硬的静态参数，缺乏明确的数学联动机制。此外，依赖外部在线大模型服务存在断网不可用与执行结果不可复现的风险。本功能构建将官方核验三表、量化财务指标与定性商业逻辑统一融合的智能投研代理系统，实现护城河与供应链风险向贴现率和安全边际的参数化传导，并提供确定性离线回放支持。

### 2. 核心用途
本功能解决三大投研合成工程问题：
1. **质性研判向定量估值参数的动态映射**：将五维护城河综合评级映射为 WACC 利差扣减项（$-0.75\% \sim +1.50\%$），将大客户依赖风险映射为安全边际扩张乘数；
2. **多情景三态估值走廊合成 (Floor / Fair / Ceiling)**：基于基准情景、悲观压力测试与乐观催化，自动合成符合单调性约束的三态目标价与买入卡片；
3. **双模运行与强契约保障**：支持在线实时生成与离线确定性回放双模式，对产出的全部数据字典实施 Schema 契约校验与 Emoji 物理净化。

### 2. 核心数学模型推导

1. **护城河贴现利差补偿函数**：
   $$\text{Spread}_{\text{moat}} = \begin{cases} -0.0075, & \text{MoatScore} \ge 85 \\ 0.0000, & 60 \le \text{MoatScore} < 85 \\ +0.0150, & \text{MoatScore} < 60 \end{cases}$$
   $$\text{WACC}_{\text{effective}} = \text{WACC}_{\text{base}} + \text{Spread}_{\text{moat}}$$
2. **大客户依赖度对安全边际的扩张函数**：
   $$\text{MoS}_{\text{target}} = \text{BaseMoS} \times \left(1.0 + \max\left(0.0, \; \frac{\text{Concentration} - 0.30}{0.70}\right) \times 1.0\right)$$
3. **三态目标价单调性刚性断言**：
   $$P_{\text{floor}} \le P_{\text{fair}} \le P_{\text{ceiling}}$$
   若出现任何逆转（如 $P_{\text{floor}} > P_{\text{fair}}$），合成器立即抛出 `ValuationMonotonicityError` 阻断导出。

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **三态走廊单调性约束**：$P_{\text{floor}} \le P_{\text{fair}} \le P_{\text{ceiling}}$ 必须通过前置断言，严禁悲观价格倒挂超过中性价格。
- [ ] **文本 Emoji 正则完全过滤**：所有生成的分析文本必须经由 `clean_text_no_emoji()` 物理清洗，杜绝任何表情符号流入交付文档。
- [ ] **离线确定性回放支持**：在无大模型在线连接环境下，`AIEngineAdapter` 必须能够自动降级至确定性规则引擎，保障系统不宕机。
- [ ] **Schema 契约强校验通过**：产出的全部 JSON 结果文件必须通过 `schemas/deep_dossier.schema.json` 强校验，严禁缺少必填字段。
