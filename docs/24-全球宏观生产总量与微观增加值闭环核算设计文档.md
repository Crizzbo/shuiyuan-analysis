# 全球宏观生产总量与行业微观增加值闭环核算技术设计规格书 (World Production & Value-Added Equilibrium)

> **功能标识**：`INDUSTRY_VALUE_ADDED_EQUILIBRIUM`  
> **所属业务分类**：类别 B：中观行业层面（存量博弈、资金流动监控与收益守恒核算）  
> **技术成熟度**：生产基准 (Production)

## 一、 功能背景与业务用途

### 1. 业务背景
在传统投研体系中，宏观分析往往停留于宽泛的 GDP 预测，而行业与个股研究则通常假定各个赛道可以同时保持 15%~20% 的孤立高增长。这种方法忽略了全社会生产要素与资本供给的刚性物理边界，导致各行业微观预期的加总远超全社会潜在生产力。本功能以联合国国民账户体系（UN SNA 2008）与世界投入产出模型（WIOD）为基础，建立从宏观总量、中观行业存量博弈与增量产出、向下穿透至微观企业三表增加值的全闭环核算体系。

### 2. 核心用途
本功能解决三大中观行业量化核算问题：
1. **板块收益守恒核算**：将行业当年总收益精确拆解为“存量博弈转移净流入”与“行业实际创造的生产力增加值”，界定收益来源是零和抽血还是非零和增量；
2. **跨板块资金流动监控 (Sankey 拓扑)**：量化资本在防御性红利、周期性工业、先锋科技及消费等 11 大行业板块之间的动态再分配；
3. **企业增加值微观平账收敛**：确保企业创造的增加值严格配平为营业盈余 (EBITDA)、劳动者报酬与生产税，实现宏观微观零断裂。

### 2. 数学公式定义与推导

1. **板块收益守恒模型 (Sector Earnings Conservation)**：
   $$\Delta \text{Sector Earnings} = \Delta \text{Inflow}_{\text{transfer}} + \Delta \text{Productivity}_{\text{GVA}}$$
   其中：
   - $\Delta \text{Inflow}_{\text{transfer}}$ 代表跨板块零和博弈再配置净流入；
   - $\Delta \text{Productivity}_{\text{GVA}}$ 代表行业内生创造的实际商品与服务增加值。
2. **行业增加值 (Gross Value-Added, GVA) 生产法推导**：
   $$GVA_{sector} = \text{Gross Output} \times (1 - \text{pct\_intermediate\_ratio})$$
   $$\Delta GVA_{sector} = GVA_{sector, 0} \times \Big( g_{demand} \times (1 + \Delta \text{TFP}) \Big)$$
3. **微观企业分配法刚性闭环平账 (SNA Distribution Closure)**：
   微观企业三表创造的增加值按要素进行最终分配：
   $$VA_{firm} \equiv EBITDA + \text{Wages} + \text{Taxes}$$
   在行业增长冲击下，企业经营杠杆（DOL）放大 EBITDA：
   $$DOL = 1.0 + \frac{\text{Fixed Costs}}{\text{EBITDA}}$$
   $$\Delta EBITDA = EBITDA_0 \times g_{eff} \times DOL$$
   $$\Delta \text{Residual} = \Delta VA - \Delta EBITDA$$
   剩余增量由员工薪酬与政府生产税按基期比例吸收，断言平账残差 $\le 0.01$ 百万美元。

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **中间消耗比例定义域**：中间消耗占比 `pct_intermediate_ratio` 必须严格处于 $(0.0, 1.0)$ 区间，禁止等于 0 或大于 1 导致增加值倒挂。
- [ ] **跨板块资金流守恒零和约束**：全市场板块资金净转移求和必须满足 $\sum \Delta \text{Inflow} \equiv 0$，禁止凭空创造无源资本。
- [ ] **微观分配法平账刚性断言**：企业三表分配法核算必须满足 $|VA - (EBITDA + Wages + Taxes)| \le 0.01$，若误差超出容差必须抛出 `AccountingClosureError`。
- [ ] **经营杠杆极值截断**：当企业 EBITDA 逼近 0 时，经营杠杆 DOL 设定保护上限 $DOL \le 5.0$，杜绝除零导致利润杠杆数学爆炸。
