# 行业知识契约与软件行业样板技术设计规格书 (Industry Knowledge Contract & Software Spec)

> **功能标识**：`INDUSTRY_KNOWLEDGE_CONTRACT_AND_SOFTWARE_SPEC`  
> **所属业务分类**：类别 E：底层数据工程层面（行业知识强类型契约、146 项指标口径目录、软件行业驱动模型与阻断校验机制）  
> **技术成熟度**：生产基准 (Production)  
> **单一事实来源**：  
> - 行业知识主契约：`schemas/industry-knowledge.schema.json`  
> - 指标口径主契约：`schemas/metric-definition.schema.json`  
> - 41 行业知识档案：`knowledge/contracts/industries/`  
> - 指标口径主底账：`knowledge/contracts/metric-definitions.json`  
> - 自动化构建与检验：`scripts/validate_industry_contracts.py`、`scripts/test_industry_contracts.py`

## 一、 功能背景与业务用途

### 1. 业务背景
在跨行业买方证券投研中，传统投研框架常面临“行业指标口径混乱”、“公式定义模糊”与“经验阈值伪造”三大工程问题。典型缺陷包括：一是在软件与 SaaS 行业研究中，混淆年度经常性收入（ARR）与 GAAP 营业收入，混淆净金额留存率（NDR）与客户数留存率；二是将包含大量股权激励薪酬（Stock-Based Compensation, SBC）的非 GAAP 自由现金流直接当作巴菲特真实所有者收益，导致真实造血能力被严重夸大；三是在缺乏大样本真实历史财报统计校准的情况下，代码硬编码伪造的经验数值阈值。本功能确立行业知识强类型契约、146 项指标精细化口径目录，并以企业软件行业为标杆构建从商业驱动到法证扣减的标准样板。

### 2. 核心用途
本功能解决全系统三大知识契约与行业指标治理问题：
1. **行业知识设计与公司分析解耦 (SSOT)**：确立 `industry-knowledge.schema.json`，规范“进入公司深入研究前必须核验什么事实”，禁止将公司级变量硬编码为行业静态规则；
2. **复合指标口径精细化与阻断机制 (Needs Definition Gate)**：在 `metric-definitions.json` 中对 ARR、NDR、股权稀释等复合指标明确核算边界与分母定义，未完成口径绑定的指标刚性阻断计算；
3. **软件行业法证级真实现金流穿透**：确立将 SBC 视作刚性稀释成本并从经营现金流中全额扣减的标准化计算样板，杜绝纸面造血幻觉。

- `data_sources/official_filings/`：提供披露 GAAP 营收、SBC 与递延收入的官方底稿。

### 2. 核心数学模型推导

1. **净金额留存率 (Net Dollar Retention, NDR)**：
   $$NDR = \frac{\text{ARR}_{\text{end}, \text{Cohort}} + \text{Expansion} - \text{Contraction} - \text{Churn}}{\text{ARR}_{\text{start}, \text{Cohort}}} \times 100\%$$
   刚性约束：分母必须为同一基准客户群（Cohort）期初 ARR，严禁混入本期新增客户（New Logos）。
2. **软件企业真实所有者自由现金流方程 (True Owner FCF)**：
   $$\text{FCF}_{\text{true}} = \text{CFO}_{\text{GAAP}} - \text{Capex}_{\text{maint}} - \text{SBC}$$
   将股权激励薪酬（SBC）视作刚性现金薪酬成本予以扣减，防止以股份稀释掩盖经营性失血。
3. **资本效率得分 (Rule of 40)**：
   $$\text{Score}_{\text{Rule40}} = \text{RevenueGrowth}_{\text{YoY}}\% + \text{FCF\_Margin}_{\text{true}}\%$$

## 五、 状态机与成熟度注册表 (State Registry)

### 1. 指标口径成熟度状态空间

| 状态代号 | 英文枚举标识 | 中文状态名称 | 判定特征 | 系统动作 |
| :--- | :--- | :--- | :--- | :--- |
| `MET_01` | `NEEDS_DEFINITION`| 待细化口径态 | 复合指标，口径、分母或边界尚未锁定。 | 刚性阻断计算，提示缺失阻断原因。 |
| `MET_02` | `SPECIFIED` | 口径已明确态 | 计算公式、分母范围及输入科目完全锁定。 | 放行计算，进入样本数据核验。 |
| `MET_03` | `NOT_VALIDATED` | 待样本验证态 | 公式明确，但尚未在本地历史大样本验证。 | 允许用于定性分析，不启用阈值。 |
| `MET_04` | `VALIDATED` | 样本已验证态 | 经历史全周期实证校准，统计分布稳定。 | 全面启用全套自动化量化买点判定。 |

## 六、 返回值与输出数据结构 (Output Contracts)

指标口径校验通过后，产出结构化记录实体：

```json
{
  "metric_id": "pct_software_ndr",
  "category": "industry_specific",
  "industry_id": "ind_software",
  "unit": "pct",
  "status": "SPECIFIED",
  "formula_description": "(期初客户群期末ARR + 扩容 - 缩减 - 流失) / 期初客户群期初ARR * 100%",
  "inputs": [
    "carr_cohort_start",
    "carr_expansion",
    "carr_churn"
  ],
  "sample_verified": false,
  "thresholds": null
}
```

### 输出字段逐项业务释义
| 输出字段名称 | 字段标识 | 数据类型 | 计量单位 | 业务释义 |
| :--- | :--- | :---: | :---: | :--- |
| 指标主键 | `metric_id` | `str` | 字符串 | 全局唯一指标代号。 |
| 所属行业 | `industry_id` | `str` | 字符串 | 归属的 41 内部行业代码。 |
| 计量单位 | `unit` | `str` | 字符串 | 严格度量单位（如 `pct`, `USD`）。 |
| 口径状态 | `status` | `str` | 枚举字符串 | 指标成熟度状态（`SPECIFIED` / `NEEDS_DEFINITION`）。|

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **严禁未经验证启用数值阈值**：所有行业知识档案与指标定义中的 `thresholds` 在本阶段必须严格保持为 `null`，严禁代码硬编码虚假买卖阈值。
- [ ] **复合指标未定义刚性阻断**：处于 `NEEDS_DEFINITION` 状态的指标严禁参与自动计算，调用时必须直接抛出 `MetricNotSpecifiedError`。
- [ ] **SBC 真实所有者成本扣除**：在核算软件行业所有者自由现金流时，必须全额扣减 `Stock-Based Compensation`，严禁直接使用未扣减的会计 FCF。
- [ ] **NDR 分母客户群纯净性**：净金额留存率计算分母必须断言为同一期初 Cohort，严禁混入本期新获客 ARR。
- [ ] **引用路径全项目闭环**：所有契约中的来源引用必须为项目内合法相对路径，严禁指向外部绝对路径或网络链接。
