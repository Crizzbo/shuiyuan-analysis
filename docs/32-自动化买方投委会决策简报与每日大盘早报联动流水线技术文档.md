# 自动化买方投委会决策简报与单向流水线技术设计规格书 (Canyon Unified Linear Pipeline Specification)

> **功能标识**：`PIPELINE_CANYON_UNIFIED_LINEAR_SUITE`  
> **所属业务分类**：类别 E：底层数据工程层面（统一单向线性流水线、宏观流动性弹性加压、击球区买点与密码学存证）  
> **技术成熟度**：生产基准 (Production)  
> **单一事实来源**：  
> - 流水线主控：`scripts/canyon_linear_pipeline.py` (`CanyonLinearPipeline`)  
> - 宏观弹性引擎：`financial_core/engines/macro_elastic_margin_engine.py`  
> - 密码学账本：`financial_core/engines/prediction_ledger.py`  
> - 自动化测试集：`scripts/test_canyon_linear_pipeline.py`

## 一、 功能背景与业务用途

### 1. 业务背景
在传统投研工程中，多模块并联与多层过渡包装容易引发三大系统缺陷：一是各计算模块之间出现调用跳转环路与参数逆向依赖；二是未经过平账检验与时效验证的数据渗透进估值模型，导致垃圾进垃圾出；三是决策结论在事后容易发生篡改，缺乏客观的投研复盘凭证。本功能构建单一事实来源（SSOT）的单向线性流水线，严格按六大标准工位顺序执行，实现从行情时效门禁、官方财报刚性配平自检、宏观流动性弹性加压、三态现金流折现、黄金击球区判定到自然语言决策卡与 SHA-256 密码学存证的全链路闭环。

### 2. 核心用途
本功能解决三大投研流水线工程问题：
1. **单向线性拓扑与绝对隔离**：工位之间通过强类型不可变对象单向传递，消除中间层回环与逆向依赖；
2. **宏观流动性弹性安全边际扩张**：基于美联储净流动性、美债期限利差、VIX 恐慌指数与期权 Gamma 暴露动态测算宏观压力分，自动放大击球区安全边际；
3. **不可篡改密码学时间链条存证**：将三态估值结论与击球区买点计算为 SHA-256 哈希值写入本地区块链式数据库，杜绝事后修饰，支撑 T+N 法证复盘。

### 2. 核心数学模型推导

1. **宏观弹性安全边际扩张方程**：
   $$\text{MOS}_{\text{elastic}} = \text{MOS}_{\text{base}} \times (1.0 + 0.75 \times S_{\text{macro}})$$
   其中：
   $$S_{\text{macro}} = 0.35 \times S_{\text{liquidity}} + 0.25 \times S_{\text{yield\_curve}} + 0.25 \times S_{\text{vix}} + 0.15 \times S_{\text{gamma}}$$
2. **黄金击球买入底线价格**：
   $$\text{Strike Price} = P_{\text{neutral}} \times \left(1.0 - \frac{\text{MOS}_{\text{elastic}}}{100.0}\right)$$
3. **资产负债表刚性配平自检约束**：
   $$|\text{Total Assets} - (\text{Total Liabilities} + \text{Total Equity})| \le \max\Big(1.0, \; \text{Total Assets} \times 0.001\Big)$$
4. **密码学时间链条哈希方程**：
   $$H_t = \text{SHA-256}(H_{t-1} \parallel \text{Ticker} \parallel \text{Timestamp} \parallel P_{\text{quote}} \parallel \text{Rating} \parallel \text{Targets})$$

## 五、 状态机与流水线工位生命周期 (State Registry)

### 1. 流水线工位状态空间枚举表

| 状态代号 | 英文枚举标识 | 中文状态名称 | 判定条件 | 系统动作 |
| :--- | :--- | :--- | :--- | :--- |
| `STAGE_01` | `QUOTE_PASS` | 行情时效达标 | 价格大于零且携带时段标签。 | 推进至工位 2 财报平账。 |
| `STAGE_02` | `BALANCE_PASS` | 官方三表平账 | 资产负债残差小于等于容差。 | 推进至工位 3 宏观加压。 |

| `STAGE_04` | `VALUATION_DONE`| 三态估值合规 | 悲观、中性、乐观满足单调递增。 | 推进至工位 5 击球区判定。 |

| `STAGE_06` | `LEDGER_LOCKED`| 密码学锁定存证 | SHA-256 时间链条成功落盘。 | 流水线圆满闭环交付。 |

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **工位严格单向调用**：工位执行顺序必须严格锁定为 1 至 6，禁止跳过工位 1 或工位 2 直接调用后续估值算法，严禁逆向调用。
- [ ] **行情非正数硬性熔断**：当行情价格小于等于零时，工位 1 必须立即抛出 `QuoteFreshnessError` 阻断流水线，防止零价格破坏估值比率。
- [ ] **资产负债表刚性配平检验**：工位 2 必须断言 $|Assets - (Liabilities + Equity)| \le \max(1.0, Assets \times 0.001)$，超差直接抛出 `BalanceSheetInvariantError`。
- [ ] **密码学账本防伪验证**：工位 6 写入记录后必须即刻调用 `verify_integrity()` 验签，确保本次写入未破坏历史时间链条。
