## 一、 功能背景与业务用途

### 1. 业务背景
在买方机构针对全市场数千家企业进行深度投资研究时，直接套用通用的估值模型（如单一市盈率 P/E 或通用现金流折现 DCF）是引发重大定价误判的根源。不同产业的商业本质存在天壤之别：
1. **金融与重资本模式的负债属性差异**：商业银行与保险公司的负债端属于“核心经营原材料”（存款与浮存金），其资产负债表与营业利润表完全无法套用传统无息负债与净借款口径的企业价值（EV）与自由现金流（FCFF）公式；
2. **周期性大宗与设备制造的峰值估值陷阱**：在油气、金属采矿、化学品和半导体行业的高景气峰值时期，账面利润最高而市盈率最低，若不按跨周期正常化（Normalized）盈利与商品成本曲线进行资产折现，极易在周期顶部买入陷入漫长亏损；
3. **混合业态的分部混淆**：汽车整车往往捆绑巨额汽车金融信贷分部、软件企业往往混杂高资本开支的公有云基础设施与高利润的订阅 SaaS、商业地产与物业服务混同计算等。

本规范确立 41 细分行业“先细分后判断、按业态定模型、按风险设情景”的严格定性适配标准，拒绝盲目套用一刀切的机械估值。

### 2. 核心用途
本功能解决全系统三大行业研究定界与估值路由问题：
1. **41 细分行业前置细分强制约束 (Mandatory Segmentation)**：强制标的在进入估值前，必须按业务模式细分（如自营/加盟、纯设计/代工、传统烟草/新型烟草），严禁在未拆解业务结构前进行整体估值；
2. **专属估值技术路线自动适配 (Valuation Route Matching)**：为 41 个行业匹配合规的买方估值方法（资产 DCF、剩余收益模型、分部加总 SOTP、管线 rNPV、P/AFFO 与 NAV），阻断非法方法滥用；
3. **周期正常化与情景风险剥离**：在缺乏长期大样本历史回测统计校准前，所有适配结论定性生效，严格作为输入审查门禁，禁止启用未经校准的量化买卖绝对阈值。

### 2. 核心数学模型推导

1. **金融板块剩余收益估值模型 (Residual Income Model, RIM)**：
   $$V_0 = BV_0 + \sum_{t=1}^{\infty} \frac{ROE_t - r_e}{(1 + r_e)^t} \times BV_{t-1}$$
   商业银行与保险公司估值严禁采用 $EV = \text{MarketCap} + \text{Debt} - \text{Cash}$，必须基于账面净资产（$BV$）与超出权益资本成本（$r_e$）的超额回报展开折现。
2. **生物医药研发管线风险调整净现值 (rNPV) 方程**：
   $$rNPV = \sum_{j \in \text{Pipelines}} \left[ \sum_{t=1}^{T} \frac{CF_{j,t} \times \prod_{k=1}^{\text{Phase}(t)} P_{\text{success}, k}}{(1 + WACC)^t} \right] + \text{Cash} - \text{Debt}$$
   其中 $P_{\text{success}, k}$ 必须依据官方权威临床成功概率，若缺乏大样本证据，仅允许做乐观/悲观情景推演。

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **严禁对金融企业使用企业自由现金流 (FCFF)**：银行与保险公司绝对禁止计算 $EV$ 或 $FCFF$，必须路由至剩余收益（RIM）或股息折现（DDM）。
- [ ] **强周期行业严禁在峰值使用静态市盈率**：采矿、化工、航运等强周期标的，必须使用跨周期正常化自由现金流，严禁直接乘以当前低 PE。
- [ ] **多业务异构标的必须前置强制拆解分部**：包含自营与平台、整车与信贷的复合标的，必须先做分部加总（SOTP），严禁直接整体验算。
- [ ] **不动产 REIT 必须使用 AFFO 或 NAV**：权益型 REIT 严禁使用通用净利润或普通市盈率，必须以调整后运营现金流（AFFO）为基准。
- [ ] **未完成大样本校准前闸门刚性阻断**：所有 41 行业的估值规则均为定性适配审查，`research_gate` 必须保持 `blocked`，严禁触发量化买卖。
