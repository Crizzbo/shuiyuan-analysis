## 一、 功能背景与业务用途

### 1. 业务背景
在买方机构高频量化与深度基本面折现估值建模中，金融数学算法的数值稳定性直接决定了投资决策的安全底线。通用开源金融库（如早期基于标准 IEEE 754 双精度浮点实现的传统公式）在极端金融场景下存在严重的浮点消减（Catastrophic Cancellation）与物理定义域崩溃灾难。例如：当贴现利率趋于近零（如日元长期零利率/负利率或极小值 $r = 10^{-16}$）时，标准年金终值因子 $\frac{(1+r)^n - 1}{r}$ 会因分子 $(1+r)^n$ 与 $1$ 发生严重的浮点有效位相互抵消，导致现值 $PV$ 错误崩溃为 $0.0$ 或拒绝运算；当标的企业属于纯股权、零有息负债结构时，传统 WACC 求解器直接将 `market_debt=0` 判定为非法输入并报错崩溃；同时，元数据反射式哈希计算如果缺乏缓存，也会引发计算中枢高频调用的性能骤降。本规范确立六大阶段金融计算算法的严密法证审计、稳定级数展开与 80 位高精度独立交叉对账体系。

### 2. 核心用途
本功能解决全系统三大高精度金融数学与工程稳定性核心问题：
1. **近零利率年金因子数值稳定性重构 (Log1p & Expm1 Reconstruction)**：在 $|r| < 10^{-4}$ 区域启用基于 $z = n \times \ln(1+r)$ 与 $\text{expm1}(z)$ 的稳定展开方程，彻底修复浮点有效位消减，确保 $r \to 0$ 时的单调连续收敛；
2. **零债务企业 WACC 自然极限边界保护**：消除对无债务标的的机械阻断，在 $D \equiv 0$ 时自然平滑退化至 $WACC \equiv r_e$（权益资本成本），建立有限责任与零负债平滑边界；
3. **80 位高精度 Decimal 独立第三方绝对交叉对账**：杜绝被测代码与测试用例共用同一套公式的虚假测试，强制引入基于 80 位 `Decimal` 的逐期贴现参考基准，跨越 13 种极端利率与 234 项数值测试点进行全息验证。

### 2. 核心数学模型推导

1. **浮点消减根本诱因与解析方程**：
   标准年金终值因子：
   $$FVIFA(r, n) = \frac{(1+r)^n - 1}{r}$$
   当 $r \to 0$ 时，$(1+r)^n = 1 + n r + \frac{n(n-1)}{2} r^2 + O(r^3)$。在计算机中直接计算 $(1+r)^n - 1$ 时，高位相同的有效数字相互抵消，浮点误差被放大至 $\frac{\epsilon_{\text{mach}}}{|r|}$。
2. **`log1p` 与 `expm1` 稳定求解方程**：
   引入对数变换参数 $z$：
   $$z = \ln\left((1+r)^n\right) = n \times \ln(1+r) \equiv n \times \text{log1p}(r)$$
   增长因子为：
   $$\text{GrowthFactor} = e^z = \exp(z)$$
   期末年金终值因子重构为：
   $$FVIFA_{\text{stable}}(r, n) = \frac{e^z - 1}{r} \equiv \frac{\text{expm1}(z)}{r}$$
   当 $r \equiv 0$ 时，自然极限展开为：
   $$\lim_{r \to 0} \frac{\text{expm1}(n \ln(1+r))}{r} = n$$
3. **现金流全周期代数平衡闭环守恒方程**：
   $$PV \times \text{GrowthFactor} + PMT \times \text{AnnuityFactor} \times (1 + r \times \text{when}) + FV = 0$$
   任意已知四项可严格单调反解出第五项，残差恒为零。
4. **WACC 零债务自然极限方程**：
   $$WACC = \frac{E}{E + D} \times r_e + \frac{D}{E + D} \times r_d \times (1 - T)$$
   当 $D \to 0$ 时：
   $$\lim_{D \to 0} WACC \equiv r_e$$
   系统平滑支持无债务企业，严禁抛出除零异常。

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **极小利率严禁直接相减截断**：在绝对利率小于 $10^{-4}$ 时必须使用 `expm1`/`log1p` 展开，严禁直接使用 $(1+r)^n - 1$ 或机械将小利率截断为零。
- [ ] **零债务企业平滑支持零除防御**：无负债企业求解 WACC 时，必须平滑输出 $WACC \equiv r_e$，严禁抛出除零错误或强迫用户虚构假债务。
- [ ] **独立测试严禁复用被测公式**：测试用例必须使用独立的 80 位高精度 `Decimal` 逐期累加求和进行反向验证，严禁直接在测试中断言被测公式本身。
- [ ] **非有限浮点数物理拦截**：所有金融公式入参必须前置校验 `math.isfinite()`，对包含 `NaN`、`Inf` 的输入刚性抛出 `ValueError`。
- [ ] **性能缓存必须保持审计指纹一致性**：引入计算优化缓存时，必须将代码实现 SHA-256 哈希与输入参数一并纳入缓存键，杜绝代码变更后返回陈旧结果。
