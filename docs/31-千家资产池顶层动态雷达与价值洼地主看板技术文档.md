## 一、 功能背景与业务用途

### 1. 业务背景
在完成全盘数千家企业资产池的自动化建档后，单标的 5-Sheet Excel 深度报告书分散在各个子目录中，形成离散的“信息孤岛”。投委会与资产配置团队难以在全局视角横向比较跨行业折价率、快速识别全市场被错杀的深度价值洼地，亦缺乏直接穿透至微观底账的交互中枢。本功能基于 OpenPyXL 引擎构建买方机构级 4-Sheet 动态雷达主看板，集成全市场概览标牌、Top-30 深度击球区排位榜、美日股全息切片、41 细分行业估值冷热度分布，并利用 Excel 原生相对超链接实现秒级底账穿透。

### 2. 核心用途
本功能解决三大全盘投研中枢工程问题：
1. **全市场估值偏离与折价率动态雷达**：横向测算全量标的的内在价值偏离度，筛选安全边际折价率排名前 30 的核心击球区资产；
2. **41 细分行业横截面冷热度评估**：按行业统计击球区占比与平均折价率，评定进攻超配、防守低配与合理标配状态；
3. **本地相对路径超链接秒级穿透**：通过原生 `=HYPERLINK()` 公式构建指向本地 5-Sheet Excel 文件的相对路径，支持离线点击无死链跳转。

### 2. 核心数学模型推导

1. **安全边际折价率方程**：
   $$\text{Discount Rate} = \frac{\text{Fair Value} - P_{\text{current}}}{P_{\text{current}}} \times 100\%$$
2. **行业平均折价率加权方程**：
   $$\overline{\text{Discount}}_{\text{sector}} = \frac{1}{N} \sum_{i=1}^{N} \text{Discount Rate}_i$$
3. **行业击球区标的占比方程**：
   $$\text{Strike Ratio} = \frac{\sum_{i=1}^{N} \mathbb{I}(\text{Discount Rate}_i > 0.0 \land \text{Signal} = \text{BUY})}{N} \times 100\%$$

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **超链接相对路径有效性断言**：超链接注入公式必须严格使用相对路径（如 `=HYPERLINK("US\xxx.xlsx", "打开5-Sheet底账")`），严禁硬编码包含盘符的 Windows 绝对路径，确保文件移动时不失效。
- [ ] **全量启用 AutoFilter 自动筛选**：Sheet 1 与 Sheet 2 数据区域必须显式声明开启 Excel 自动筛选功能，方便分析师按行业和折价率进行条件筛选。
- [ ] **字符列宽自适应保护**：遍历各列单元格根据字符宽度动态调整列宽，避免出现 `###` 遮挡错误。
- [ ] **跨市场货币格式独立**：美股全息表严格采用 `$#,##0.00` 格式，日股全息表严格采用 `¥#,##0` 会计格式，严禁币种混淆。
