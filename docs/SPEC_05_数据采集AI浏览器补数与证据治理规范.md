# 水源智能投研系统 · 数据采集、AI 浏览器补数与证据治理规范 (SPEC-05)

> **设计典籍代号**：`SPEC_05_DATA_INGESTION_BROWSER_COMPLEMENT_AND_GOVERNANCE`  
> **所属业务分类**：底层官方数据接入、AI 浏览器定向补数、证据不可篡改归档  
> **专责系统职能**：定义全盘美股 (SEC) 与日股 (JPX) 官方底账接入标准、无需配置的公开数据采集 SOP、AI 浏览器补数机制、多币种汇率统一折算及审计存证规则。  
> **权威单一事实来源 (SSOT)**：`scripts/data_catalog.py`、`data/universe/` 及 `data/audits/` 治理基准。

---

## 一、 数据获取原则与来源合规红线

系统严格遵循买方机构合规与实事求是底线：
1. **公开与官方优先原则**：
   优先采用无需复杂 API Key、无需商业账号绑定的公开权威监管渠道（美股采用 SEC EDGAR 官方申报与纽交所/纳斯达克公开披露；日股采用东证 JPX 官方主板/标准板/成长板底账与 TDnet 开示系统）；
2. **AI 浏览器定向补数标准作业程序 (SOP)**：
   当遇到官方披露数据缺失或需核实细部商业合同时，由 AI 浏览器搜索进入官方监管机构、交易所或发行人投资者关系 (IR) 官方页面进行核实，下载原始 PDF/XBRL 或保存明确标注的浏览器页面原文摘录到项目目录内；
3. **严禁将 AI 生成摘要充当原始事实**：
   搜索摘要或大模型推断内容绝不能充当底层事实证据；分析与计算必须以实际落盘归档的本地官方文件为唯一依据；
4. **历史资料只追加、不手改**：
   所有存入 `data/` 的历史底账与研究成果，遵循密码学账本逻辑只做追加写入，严禁人工篡改历史文件。

## 二、 全球全息资产池底账结构

系统维护着覆盖数千家上市主体的双市场全息索引：
- **美股全量底账**：`data/universe/sec_company_tickers.json`（收录 10,000+ 家 SEC 注册企业 CIK、Ticker、公司法定英文名及行业代号）；
- **日股全量底账**：`data/universe/jpx_company_tickers.json`（收录 4,400+ 家东证上市公司 4 位代码、公司日文全称、所属东证板块 Prime/Standard/Growth 及行业类别）；
- **汇率与多币种统一换算**：
  在 `financial_core/engines/currency_converter.py` 中维护动态基准汇率（如 USD/JPY、USD/CNY），在多国企业横向对比时，自动折算为统一基准货币，并在前端显式标明原币金额与换算基准日。

## 三、 数据转换与标准化清洗管道 (OfficialFilingMapper)

针对不同国家和交易所的非标申报格式，系统构建标准映射器：
1. **单位与量级归一化**：
   自动识别 `$B` (十亿美元)、`$M` (百万美元)、`¥百万円`、`¥億円`，统一换算为标准绝对数值；
2. **会计准则自适应转换**：
   兼容 US GAAP (美股公认会计准则) 与 IFRS (国际财务报告准则) 的不同披露口径（如研发资本化差异、经营租赁权资产计量差异）；
3. **数据治理自检命令**：
   通过 `python scripts/test_data_store.py` 自动化回归全量数据目录，确保元数据一致性与文件完整性。
