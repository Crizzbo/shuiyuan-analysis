# 金融计算工具命令行与应用接口技术设计规格书 (Financial Calculation CLI & Tooling Specification)

> **功能标识**：`FINANCE_CALCULATION_CLI_SOP_SPEC`  
> **所属业务分类**：类别 C：微观公司内在价值与财务估值（离线纯净量化算力、标准 JSON-RPC 接口、多阶段 DCF 折现、XIRR 不规则现金流与敏感度矩阵）  
> **技术成熟度**：生产基准 (Production)  
> **单一事实来源**：

## 一、 功能背景与业务用途

### 1. 业务背景
在买方机构量化投研流水线中，财务估值与现金流折现（DCF、XIRR、WACC、残余收益模型）往往面临两大工程隐患：一是将计算逻辑散落在上层爬虫或报告渲染代码中，缺乏纯净解耦的底层计算中枢；二是直接在命令行或脚本中执行动态字符串 `eval()`，不仅带来严重的安全注入漏洞，且在浮点数极值、多根歧义及分母逼近零时发生非预期崩溃。依据本项目纯净金融核心层（`financial_core/`）物理隔离与零网络依赖准则，本规范确立标准化 JSON-RPC 命令行接口、严格防御性参数门禁、双变量敏感度走廊及研究记录映射规范。

### 2. 核心用途
本功能解决全系统三大离线金融计算与调度问题：
1. **统一单向计算网关 (Standardized Calculation Gateway)**：通过 `scripts/calculate_finance.py` 承接外部标准 JSON 请求，支持普通模式 (`calculate`)、敏感度模式 (`sensitivity`) 及情景加权模式 (`scenarios`)；
2. **金融数学边界刚性防御**：在 XIRR 牛顿迭代法、戈登永续增长分母 ($WACC - g \ge 0.5\%$)、有限责任股权价值 ($\max(0.0, EV - NetDebt)$) 等关键环节建立数学安全护栏；
3. **不可变研究记录对齐 (Research Record Mapping)**：自动将单次计算结果与六步研究分析 Schema 中的 `calculation.id`、`observation_refs` 勾稽绑定，无损输出至不可篡改时间账本。

### 2. 核心数学模型推导

1. **多阶段两阶段自由现金流折现模型**：
   $$PV_{\text{explicit}} = \sum_{t=1}^{N} \frac{FCF_0 \times \prod_{k=1}^t (1 + g_k)}{(1 + WACC)^t}$$
   $$PV_{\text{terminal}} = \frac{FCF_N \times (1 + g_{\text{terminal}})}{(WACC - g_{\text{terminal}}) \times (1 + WACC)^N}$$
   $$EV = PV_{\text{explicit}} + PV_{\text{terminal}}$$
   $$\text{EquityValue} = \max\Big(0.0, \; EV - \text{NetDebt}\Big)$$
   $$\text{ValuePerShare} = \frac{\text{EquityValue}}{\text{SharesOutstanding}}$$
   *极值安全防御*：强制断言 $WACC - g_{\text{terminal}} \ge 0.005$（$50\text{ bps}$），杜绝除以零或除以负数导致估值失控。
2. **不规则时间现金流内部收益率 (XIRR)**：
   $$\sum_{i=1}^{M} \frac{C_i}{(1 + \text{XIRR})^{\frac{d_i - d_1}{365.0}}} = 0.0$$
   采用严格牛顿-拉夫逊（Newton-Raphson）迭代法求解，迭代上限 100 次，残差容限 $\epsilon \le 10^{-7}$；若出现多根或发散，显式抛出 `ConvergenceError`，严禁伪造默认值。

## 五、 状态机与错误码规范 (Error Handling Registry)

### 1. CLI 退出状态码与错误类型空间

| 退出码 | 英文异常类型标识 | 中文错误名称 | 触发场景 | 处置方式 |
| :---: | :--- | :--- | :--- | :--- |
| `0` | `SUCCESS` | 计算成功 | 参数完全合规，成功求解收敛。 | 正常输出 JSON 结果。 |
| `1` | `INVALID_INPUT` | 参数校验违规 | 传入负股数、未配平或非法字符串。 | 打印错误定位，阻断计算。 |
| `2` | `MATH_DIVERGENCE` | 数学无根或发散 | XIRR 现金流全为正数或牛顿法不收敛。| 抛出收敛异常，提示修正现金流。 |
| `3` | `FILE_ALREADY_EXISTS`| 输出文件已存在 | `--output` 指向的磁盘文件已存在。 | 严禁物理覆盖，提示更换文件名。 |
| `4` | `PATH_TRAVERSAL` | 越界路径攻击 | 传入包含 `../` 的绝对路径或 UNC。 | 刚性拦截，保护本地工程目录。 |

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **严禁动态执行 `eval()` 或 `exec()`**：所有的参数解析必须经由强类型字典读取与转换，严禁执行任意 Python 字符串表达式。
- [ ] **利率与比例必须使用小数**：输入利率统一使用 `0.1` 表示 $10\%$，严禁在数值中夹杂百分号字符串 `"10%"` 导致解析异常。
- [ ] **永续增长分母极值硬拦截**：多阶段 DCF 必须强制校验 $WACC - g \ge 0.5\%$，严禁在贴现率小于或等于永续增长率时输出无意义荒谬数字。
- [ ] **有限责任底线下界截断**：企业价值扣除净负债后，股权价值必须经由 $\max(0.0, EV - NetDebt)$ 截断，严禁输出负每股估值。
- [ ] **输出文件原子增量防护**：当指定 `--output` 时，若目标文件已存在必须显式报错终止，严禁未经许可静默覆盖历史计算凭证。
