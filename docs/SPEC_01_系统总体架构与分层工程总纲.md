## 一、 系统定位与买方投研使命

水源智能投研系统是一个专为买方机构（公募基金、私募基金、高净值家族办公室与专业自营交易员）打造的**工业级量化与基本面一体化投研中枢**。系统旨在解决三大传统投研痛点：
1. **摆脱模板化虚假研报**：拒绝机械拼凑无逻辑的财务表格与公式推导，穿透公司真实官方三表底稿、商业模式造血本质与核心竞争护城河；
2. **统一时效性与因果链条**：任何报价、估值和期权定价必须具备精确到分钟的交易时段新鲜度验证，彻底杜绝跨交易日旧数据导致的决策失真；
3. **全市场数千家标的流式覆盖与云端自治**：摆脱本地单机运算瓶颈，实现全市场 10,000+ 家美股与 4,400+ 家日股资产池的流式分批建档、自动化密码学存证与云端定时巡航。

## 三、 四层单向物理架构与防劣变铁律

为了防止在长期迭代中架构退化与循环依赖，系统物理代码严格划分为四大层次，并遵循**严禁逆向依赖**铁律：

```
Level 4: scripts/ (调度器、批处理流水线、自动化回归与集成测试层)
   │
   ▼ (单向调用)
Level 3: financial_reporting/ (报告呈现、HTML/PDF 渲染与行情时效门禁层)
   │
   ▼ (单向调用)
Level 2: finance_tools/ (向下兼容中继门面层，仅提供开箱即用函数封装)
   │
   ▼ (单向调用)
Level 1: financial_core/ (底层独立纯净金融计算引擎层，零外部依赖，内部纯相对导入)
```

### 1. 核心架构红线
- **底层纯净性**：`financial_core/` 严禁导入 `financial_reporting`、`finance_tools`、`scripts` 或任何外部业务脚本；
- **单一事实来源 (SSOT)**：所有金融公式与核心算法必须在 `financial_core` 中唯一实现，外层工具仅作为门面中继（Facade）；
- **内部纯相对导入**：`financial_core` 内部子模块之间的引用必须使用相对路径（如 `from .xxx import ...`），严禁跨包循环引用；
- **配置驱动与数据解耦**：所有魔法数值与权重参数统一抽取到字典或配置类中，严禁在业务逻辑中散落硬编码数值。

## 四、 行业知识与研报表述规范

- **去工程符号化**：面向用户的 UI 标签、界面菜单、操作按钮及交互文档中，严禁暴露底层工程代号（如 L1/L2/L3、wsState、raw_calc_v1 等），统一采用自然中文业务功能语义命名（如“剧本核心”、“跨段接力”、“买方安全边际”）；
- **通俗自然语言汇报**：遵循买方机构高管汇报习惯，全面清除研报中的复杂数学推导符号，将其转化为直观的商业逻辑（如“资产周转天数拉长反映供应链塞车”、“自由现金流转正说明造血能力跨越盈亏平衡点”）；
- **三态情景推演**：个股分析必须包含悲观底价、基准价值与乐观靶心三态推演，并明确标出具体的黑天鹅触发事件与利好催化剂。
