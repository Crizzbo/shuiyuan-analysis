# 水源智能投研系统 · 多模态视觉呈现与研报 Token 设计规范 (SPEC-02)

> **设计典籍代号**：`SPEC_02_MULTIMODAL_PRESENTATION_AND_TOKENS`  
> **所属业务分类**：买方研报多模态输出、HTML/PDF/Excel 视觉设计体系  
> **专责系统职能**：定义出版级 A4 矢量无截断排版标准、买方暗色仪表盘设计语言、设计 Token（颜色、字体、间距、状态语义）及 5-Sheet Excel 样式规范。  
> **权威单一事实来源 (SSOT)**：所有报告渲染引擎（`financial_reporting/`）视觉呈现的唯一依据。

---

## 一、 视觉设计哲学与买方体验标准

买方专业投资机构（基金经理、投委会委员与资深分析师）对于投研报告的阅读具备极高的专业审美与效率要求：
1. **去工程符号化**：界面与报告文本中严禁出现未转化的代码变量（如 `calc_pe_ratio`、`state_vcp_1`），必须全部转为业务语言（如“动态市盈率”、“波动收敛形态完成”）；
2. **高对比度与信息分层**：核心结论置顶（买入/观望/减仓）、关键财务指标（营收、净现金、自由现金流、周转天数）通过高亮卡片呈现，细节推演折叠或依序展开；
3. **印刷与跨屏一致性**：无论在无头 Linux Chromium 生成的 A4 PDF，还是在移动端或桌面浏览器打开的 HTML 看板，字号、行距、分页点保持绝对严谨，杜绝跨页文字截断或表格断头。

---

## 二、 核心视觉设计 Token 体系

系统统一定义买方专业级设计 Token（以 CSS 变量与十六进制色值呈现）：

### 1. 颜色体系 (Color Palette)
- **背景与表面底色**：
  - 研报印刷白底背景：`#ffffff`（用于 A4 纸质与导出 PDF 打印）；
  - 现代暗色交互背景：`#0b0f19`（大盘总报深色深空底色）；
  - 暗色卡片表面底色：`#111827`；
  - 暗色边框线与分割线：`#1f2937` 或 `#374151`；
- **业务语义状态色**：
  - **看多 / 强劲 / 乐观靶心**：`#10b981`（翠绿），警示高收益机遇；
  - **看空 / 下行风险 / 悲观底价**：`#ef4444`（赤红），警示下行杀估值风险；
  - **中性 / 基准合理价值**：`#3b82f6`（买方科技蓝），代表价值中枢；
  - **警示 / 需重点关注**：`#f59e0b`（琥珀金），代表时效临界或波动收敛待确认；
- **文本层级色**：
  - 一级标题与重点数值：`#f9fafb`（暗色）/ `#111827`（亮色）；
  - 二级正文与业务解读：`#9ca3af`（暗色）/ `#374151`（亮色）；
  - 辅助说明与行情时间戳：`#6b7280`；

### 2. 排版与排印字体 (Typography)
- **西文字体栈**：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", sans-serif`；
- **中文字体栈**：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`；
- **等宽与数值字体**：`"SF Mono", "Consolas", "Liberation Mono", Menlo, Courier, monospace`（用于股票代码、价格数值与时间戳对齐）；
- **字号阶梯**：
  - 大盘顶层标题：`20px`（加粗）；
  - 章节一级标题：`15px`（加粗）；
  - 重点个股卡片标题：`13px`（加粗）；
  - 核心正文：`11.5px` 至 `12px`（行高 1.45 至 1.5）；
  - 脚注与时效声明：`10px`；

## 三、 出版级 A4 矢量 PDF 排版硬标准

1. **绝对无截断分页 (@page Rules)**：
   ```css
   @page {
     size: A4;
     margin: 12mm 14mm 12mm 14mm;
   }
   .avoid-break {
     page-break-inside: avoid;
     break-inside: avoid;
   }
   ```
2. **两栏响应式网格**：
   三表体检与护城河分析采用紧凑双栏布局，核心结论与原始财务底账采用单栏横贯置底；
3. **无缝去页眉页脚**：
   调用无头浏览器编译时强制开启 `--no-pdf-header-footer`，杜绝浏览器默认打印自带的 URL 与空白页码干扰。

## 四、 买方机构级 5-Sheet Excel 深度投研工作簿规范

通过 `scripts/build_institutional_workbook.py` 自动化生成的 Excel 必须包含五张标准化工作表，严禁手工修改：
1. **Sheet 1: 资产池总览与动态雷达 (Universe Radar)**：收录全量企业基本信息、所属行业、当前现价、新鲜度声明、安全边际买入触发价与买卖评级；
2. **Sheet 2: 官方财报三表全息底稿 (Financial Statements)**：涵盖资产负债表、利润表、现金流量表近 3 年及 TTM 官方底账；
3. **Sheet 3: 财务体检与供应链健康度 (Financial Health & Supply Chain)**：呈现 DIO 库存周转天数、净现金状态、应收应付账款周转与供应商集中度；
4. **Sheet 4: 跨周期多情景 DCF 估值矩阵 (DCF Valuation Scenarios)**：包含乐观、基准、悲观三态假设、折现率 WACC 与安全边际测算；
5. **Sheet 5: 宏观传导与期权技术足迹 (Macro & SEPA Footprint)**：提供标的宏观利率敏感度、VCP 波动收敛形态与期权到期盈亏赔率。
