> **核心铁律**：
> 1. **零侵入既有金融工具**：绝不修改 `financial_core/`、`finance_tools/` 及现有 `financial_reporting/` 核心计算与报告模块；全部后端聚合通过**新增独立适配服务**只读/安全调用完成。

## 四、 前后端对齐接口契约（REST + SSE Specification）

### 4.1 公共响应信封（Every JSON Endpoint）

所有成功响应统一返回如下结构，确保前端在任何网络或时效条件下都能渲染准确状态：

```json
{
  "ok": true,
  "data": {},
  "meta": {
    "as_of": "2026-11-07T12:41:49Z",
    "updated_at": "2026-11-12T08:00:00Z",
    "source": "watersource_terminal_aggregator",
    "status": "PREVIOUS_CLOSE",
    "run_id": "RUN-20261112-0001"
  },
  "error": null
}
```

#### 标准枚举字典

- **流水线运行态 (`pipeline_state`)**：`IDLE` | `QUEUED` | `RUNNING` | `STOPPING` | `STOPPED` | `SUCCESS` | `FAILED` | `PARTIAL_SUCCESS`
- **数据新鲜度态 (`data_status`)**：`FRESH`（当日开市/最新时段） | `PREVIOUS_CLOSE`（闭市前收盘基准，非故障） | `STALE_BLOCKED`（超期阻断，如 `USDJPY` 超期 30.2h） | `PARTIAL`（部分资产就绪/部分补数中） | `EMPTY` | `ERROR`
- **市场交易时段 (`market_status`)**：`CLOSED` | `PRE_MARKET` | `REGULAR` | `AFTER_HOURS`

| `POST /api/pipeline/stop` | 启停控制台 | 请求体 `{"run_id": "..."}`；平滑设置协作停止信号 `STOPPING -> STOPPED` 并广播 SSE |
| `GET /api/pipeline/runs` | 采集 / 日志历史 | 返回历史运行批次（内存最近运行 + `event_radar.sqlite3` 真实 `collection_cycles` 记录） |
| `GET /api/logs` | 系统日志 | `?level=ALL\|INFO\|WARN\|ERROR&module=...&q=...&limit=100`；返回实时缓冲日志 + 流水线子任务审计日志 |
| `GET /api/settings` | 系统配置 | 只读返回四层依赖合规状态、PredictionLedger SHA-256 账本状态（`1,413` 条记录 / 验签状态）、冷热分层阈值（30天热 / 3年温）、24 小时行情门禁策略与 API 端点字典 |
| `GET /api/stream` | 实时推流通道 | SSE (`Content-Type: text/event-stream`)；支持事件类型：`snapshot`, `pipeline_status`, `log_entry`, `heartbeat` |
