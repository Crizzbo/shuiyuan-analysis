## 一、 功能背景与业务用途

### 1. 业务背景
在买方机构投资管理中，仅依赖单一静态确定性模型（如单点估值或简单账面比率）无法衡量极值风险与资产价格的不对称尾部暴露。当面临市场极端流动性收紧、企业信用利差飙升或宏观周期反转时，模型需要对资产价值分布的各阶矩（均值、方差、偏度、峰度）以及违约边界进行全息测算。本子说明书定义系统底层纯净计算层中的高阶量化引擎群，涵盖结构化信用违约模型、蒙特卡洛随机模拟、肥尾修正风险价值、波动率曲面希腊字母闭式解以及密码学不可篡改预测账本。

### 2. 核心用途
本功能集成八大核心量化能力：
1. **Merton 结构化信用违约与破产测度**：联立求解企业无形资产价值与波动率，实现物理测度 $\mathbb{P}$ 与风险中性测度 $\mathbb{Q}$ 双重解耦；
2. **10,000 次向量化蒙特卡洛随机 DCF 估值**：在参数区间内随机抽样折现率与增长率，输出概率密度与公允价值分位数；
3. **Cornish-Fisher 肥尾修正 VaR 与组合风险分解**：对偏度与峰度实施四阶展开，基于 Ledoit-Wolf 最优收缩协方差测算 Euler 边际风险贡献；
4. **连续红利 BSM 全阶解析希腊字母与偏斜曲面**：计算一阶至二阶全阶希腊值，施加 Durrleman 凸度约束与 Roger Lee 渐进方差极限；
5. **跨周期正常化自由现金流与 Shiller CAPE**：平滑 7~10 年周期资本开支与折旧差异，判定产能利用率与库存周期四象限定位；
6. **美式期权 CRR 二叉树与 Richardson 组合外推**：采用 $2P_{2N} - P_N$ 外推消除离散阶梯震荡，收敛速度提升至 $O(1/N^2)$；
7. **多时区行情时效门禁**：盘前、盘中、盘后时态状态机判定与前收盘基准自动切换；
8. **SHA-256 不可篡改预测账本**：基于 SQLite ACID 事务与区块链式前序哈希链条，记录全部研判并提供毫秒级验签。

### 2. 核心数学模型推导

1. **Merton (1974) 非线性联立方程组与阻尼牛顿法**：
   $$E = V_A \Phi(d_1) - D e^{-rT} \Phi(d_2)$$
   $$E \sigma_E = V_A \Phi(d_1) \sigma_A$$
   其中：
   $$d_1 = \frac{\ln(V_A / D) + (r + 0.5 \sigma_A^2)T}{\sigma_A \sqrt{T}}, \quad d_2 = d_1 - \sigma_A \sqrt{T}$$
   物理测度违约概率：
   $$DD_{\mathbb{P}} = \frac{\ln(V_A / D) + (\mu_A - 0.5 \sigma_A^2)T}{\sigma_A \sqrt{T}}, \quad \text{EDF}_{\mathbb{P}} = \Phi(-DD_{\mathbb{P}})$$
2. **Cornish-Fisher 四阶展开修正风险价值 (VaR)**：
   $$z_{cf} = z_\alpha + \frac{z_\alpha^2 - 1}{6} S + \frac{z_\alpha^3 - 3z_\alpha}{24} K - \frac{2z_\alpha^3 - 5z_\alpha}{36} S^2$$
   $$\text{VaR}_\alpha = - (\mu + z_{cf} \sigma)$$
3. **Ledoit-Wolf 渐进最优收缩协方差**：
   $$\Sigma_{shrunk} = \delta^* F + (1 - \delta^*) S_{sample}$$
   其中 $F$ 为单参数常相关阵，$\delta^* \in [0.0, 1.0]$ 由样本方差渐进最小化解析求解。
4. **Richardson 组合外推二叉树**：
   $$P_{Richardson} = 2 \cdot P_{2N} - P_N$$
   自适应无套利步长下界约束：$N \ge \left\lceil T \frac{(r - q)^2}{\sigma^2} \right\rceil + 1$。
5. **SHA-256 哈希时间链条**：
   $$H_0 = 0^{64}$$
   $$H_t = \text{SHA-256}(H_{t-1} \parallel \text{Ticker} \parallel \text{Date} \parallel \text{Price} \parallel \text{Rating} \parallel \text{FairValue})$$

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **Merton 牛顿迭代收敛防死循环**：最大迭代步数限制为 100 步，初始阻尼系数为 0.50，残差容差小于等于 $10^{-5}$，若不收敛安全降级至账面简易比率。
- [ ] **蒙特卡洛永续分母刚性断言**：每次抽样强制校验 $WACC - g_{terminal} \ge 0.50\%$，若抽样点违反条件自动截断至保护边界。
- [ ] **有限责任非负保护**：蒙特卡洛每轮抽样及 Merton 权益估值下界严格截断为 0.00，禁止负权益价值穿透至研报。
- [ ] **波动率凸度与蝶式无套利检验**：对拟合偏斜曲率施加非负约束 $c = \max(0.0, c_{raw})$，杜绝负概率密度。
- [ ] **密码学账本防篡改验签**：`PredictionLedger.verify_integrity()` 在每次会话启动时必须执行全链遍历，发现任何哈希不匹配立即抛出中断异常。
