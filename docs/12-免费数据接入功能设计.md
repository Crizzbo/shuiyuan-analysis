# 免费数据接入与免配置采集技术设计规格书 (Free Data Ingestion & Providers Specification)

> **功能标识**：`INGESTION_FREE_PROVIDERS_SUITE`  
> **所属业务分类**：类别 E：底层数据工程层面（免费公开数据源适配、免配置采集通道、本地额度限流与原始归档管道）  
> **技术成熟度**：生产基准 (Production)  
> **单一事实来源**：  
> - 接入核心设施：`data_ingestion/core.py`  
> - 来源适配器群：`data_ingestion/providers.py`  
> - 命令行执行入口：`scripts/ingest_data.py`  
> - 来源注册配置：`data/ingestion-sources.json`  
> - 自动化测试集：`scripts/test_data_ingestion.py`  

---

## 一、 功能背景与业务用途

### 1. 业务背景
在量化投研系统中，依赖昂贵的商业私有数据接口不仅带来高额财务成本，还容易因接口授权中断或 Token 泄露导致生产管线停摆。同时，若采集程序缺乏严格的域名白名单管控与本地限流机制，容易触发上游官方网站封锁或引入不可信网络数据。根据系统安全授权策略，本系统禁止自动订阅收费源，全面启用无需复杂账号认证的公开免配置通道（如 SEC EDGAR、FRED 公开序列、日本央行 BOJ、东证 TDnet 公告及官方 RSS），构建统一的限流重试、原始归档与暂存区管理管道。

### 2. 核心用途
本功能解决三大外部数据接入工程问题：
1. **多源免配置公开数据管道集成**：实现对 SEC 官方登记列表、宏观经济序列（FRED/BLS）、央行政策利率及官方公告的规范化抓取；
2. **滚动 24 小时保守额度控制与幂等重试**：内置 SQLite 事务级共享配额中枢，支持指数退避重试（最多 4 次）与 `Retry-After` 响应头解析，杜绝超频违规；
3. **原始响应与规范化结果双重 SHA-256 存证**：解压后的原始报文直接写入 `data/ingestion/objects/`（`.raw` 文件），解析后的结构化数据存入 `data/ingestion/results/`，实现端到端物理可查。

## 二、 系统架构上下文与依赖关系

### 1. 前置依赖 (Inputs From Upstream)
- `data/ingestion-sources.json`：提供受信任域名白名单、环境变量映射及保守日配额字典。
- 操作系统环境变量：按需提供经过授权的免费公开 API Key（仅读取指定显式变量，不扫描系统账户）。

### 2. 后置消费 (Outputs To Downstream)
- `data/catalog/`：消费经暂存清洗的原始文件，登记入正式证据目录。
- `financial_core/engines/official_filing_mapper.py`：消费抓取到的官方财报底账。

### 2. 核心数学模型推导

1. **指数退避重试等待时间模型**：
   $$T_{\text{wait}} = \min\left( T_{\text{max}}, \; T_{\text{base}} \times 2^{\text{attempt}} + \text{Uniform}(0, 1) \right)$$
   其中 $T_{\text{base}} = 1.0$ 秒，$T_{\text{max}} = 30.0$ 秒，若响应头中显式给出 `Retry-After: N` 且 $N \le 30$，则优先遵从服务器指令。
2. **滚动 24 小时配额校验方程**：
   $$\sum_{i \in \text{Requests}} \mathbb{I}(t_{\text{now}} - t_i \le 86400) \le \text{DailyLimit}_{\text{provider}}$$
3. **双重 SHA-256 摘要配对**：
   $$Hash_{\text{raw}} = \text{SHA-256}(\text{RawResponseBody})$$
   $$Hash_{\text{result}} = \text{SHA-256}(\text{CanonicalJsonString})$$

## 五、 状态机与采集生命周期 (State Registry)

### 1. 采集任务执行生命周期状态空间

| 状态代号 | 英文枚举标识 | 中文状态名称 | 判定条件 | 系统动作 |
| :--- | :--- | :--- | :--- | :--- |
| `ING_01` | `COLLECTED` | 抓取成功暂存 | HTTP 200 且业务校验通过。 | 写入 .raw 与 .json 成果。 |
| `ING_02` | `RATE_LIMITED` | 触发限流拦截 | 触发 HTTP 429 或配额耗尽。 | 挂起任务，记录下一次可调度时点。|
| `ING_03` | `DOMAIN_DENIED` | 域名非法越界 | 请求地址不在配置白名单中。 | 立即抛出安全异常并阻断执行。 |
| `ING_04` | `OFFLINE_MISS` | 离线缓存缺失 | 处于 `--offline` 模式但本地无缓存。| 跳过任务，不发起网络请求。 |

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **域名白名单刚性拦截**：所有发起的网络请求必须前置校验目标域名是否存在于 `data/ingestion-sources.json` 的 `allowed_domains` 中，严禁向未知地址发送请求。
- [ ] **凭据脱敏与日志防泄漏**：打印日志与归档元数据中，URL 携带的查询参数与 Header 必须进行正则脱敏，严禁打印 API Key 等敏感明文。
- [ ] **禁止自动切换收费源**：遇到公开免费源 401/403 权限异常或服务下线时，必须记录为采集失败并转入补数清单，严禁代码自动跳转订阅收费接口。
- [ ] **缺失数据严禁自动补零**：网络抓取失败或返回空值时，必须如实记录为 `null` 或缺失状态，严禁代码静默填补零值或虚构估算值。
