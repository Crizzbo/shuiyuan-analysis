> **功能标识**：`VAL_FILING_PARSING_NORMALIZATION`  
> **所属业务分类**：类别 C：微观公司内在价值与财务估值（财报底稿清洗、平账自检与估值桥梁）

> **单一事实来源**：

## 一、 功能背景与业务用途

### 1. 业务背景
在买方深度投研中，跨市场财务分析面临三大结构性障碍：一是美股（SEC EDGAR US-GAAP）、日股（TDnet J-GAAP）与国际跨国企业（IFRS）会计准则科目定义差异；二是原始 XBRL/PDF 财报中存在大量的列年变化、非标附注扰动与舍入尾差；三是若直接将未经清洗的字符串或未配平底账录入现金流折现模型，将导致估值结果严重失真。本功能构建权威官方三表解析清洗、刚性平账自检与企业价值穿透桥梁。

### 2. 核心用途
本功能解决三大微观财务与估值问题：
1. **跨会计准则物理对齐**：将 US-GAAP、IFRS 与 J-GAAP 统一映射为标准资产负债表、利润表与现金流量表事实；
2. **资产负债表刚性配平自检 ($A \equiv L + E$)**：执行绝对平衡检验，剔除尾差扰动，拦截资产不平衡度超出 $0.1\%$ 的伪造或残缺财报；
3. **企业价值向每股股权价值穿透桥梁**：将经营性资产折现现值，经由有息债务扣减、闲置现金加回及非核心资产重估，穿透为普通股每股公允内在价值。

### 2. 数学公式定义与推导

1. **资产负债表刚性配平自检方程**：
   $$\text{Discrepancy} = \frac{|\text{Total Assets} - (\text{Total Liabilities} + \text{Total Equity})|}{\max(|\text{Total Assets}|, 1.0)}$$
   若 $\text{Discrepancy} \le 0.1\%$ 则判定平账；超出阈值立即抛出 `FilingReconciliationError` 阻断执行。
2. **自由现金流 (FCFF) 标准推导**：
   $$FCFF = \text{Operating Cash Flow} - \text{Capital Expenditures}$$
3. **戈登企业终值模型与分母极值防线**：
   $$TerminalValue = \frac{FCF_n \times (1 + g_{terminal})}{WACC - g_{terminal}}$$
   断言约束：$WACC - g_{terminal} \ge 0.50\%$，杜绝分母逼近零引发数学无穷大爆炸。
4. **穿透股权价值与每股公允价格**：
   $$EquityValue = \max\Big(0.0, \; (PV_{explicit} + PV_{terminal}) - NetDebt\Big)$$
   $$ValuePerShare = \frac{EquityValue}{SharesOutstanding}$$

## 七、 财报防腐中继门面体系设计 (Financial Statement Facade)

### 1. 架构定位与解耦目标
针对系统矩阵逻辑审计中暴露的“最长依赖调用链达 10 级、底层清洗细节向下游肆意穿透”的缺陷，本系统在纯净底层金融核心层 (`financial_core`) 设立统领全息财报处理的中继防腐门面：`FinancialStatementFacade`。
- **职责收敛单一事实来源**：统一封装三准则科目映射 (`OfficialFilingMapper`)、资产负债表刚性平账自检 ($Assets = Liabilities + Equity$)、核心比率安全归一化计算及行情时效门禁校验 (`QuoteFreshnessGateway`)；
- **上层依赖解耦**：上层分析器与研报合成器（如 `ai_dossier_synthesizer.py`、`excel_dossier_builder.py`）仅依赖该门面输出的强类型不可变对象，严禁直接解包和操作脏数据字典；
- **长链依赖压缩**：将上层研报合成器直接锚定至防腐门面，切断对多级底层解析脚本的直连穿透，使系统最长依赖链从 10 级直接收敛至 9 级，上游依赖负担降低 15.8%。

### 2. 强类型不可变输出契约 (`NormalizedFinancialProfile`)
门面执行处理后，向外输出 `dataclass(frozen=True)` 不可变财务档案对象：

```python
@dataclass(frozen=True)
class NormalizedFinancialProfile:
    ticker: str
    company_name: str
    currency: str
    fiscal_period: str
    total_assets: float
    total_liabilities: float
    total_equity: float
    cash_and_equivalents: float
    total_debt: float
    net_cash: float                  # cash_and_equivalents - total_debt
    revenue: float
    gross_profit: float
    operating_income: float
    net_income: float
    free_cash_flow: float
    inventory: float
    cogs: float
    gross_margin: float              # gross_profit / revenue
    operating_margin: float          # operating_income / revenue
    net_margin: float                # net_income / revenue
    roe: float                       # net_income / total_equity
    inventory_turnover_days: float   # (inventory * 365) / cogs (DIO)
    interest_coverage_ratio: float   # operating_income / interest_expense
    balance_discrepancy: float       # abs(assets - (liabilities + equity))
    is_balanced: bool                # discrepancy / assets <= 0.0010 (0.1% 容差)
    quote_price: float
    quote_timestamp: str
    market_session: str              # pre_market / regular_trading / after_hours / previous_close
    is_quote_fresh: bool
```

### 3. 防腐门面核心防御规则与异常拦截
1. **0.1% 刚性配平自检硬门禁**：
   门面计算 $\text{Discrepancy Ratio} = \frac{|\text{Total Assets} - (\text{Total Liabilities} + \text{Total Equity})|}{\text{Total Assets}}$。若该比率超过 $0.1\%$ ($0.0010$)，强制抛出 `BalanceSheetIdentityError`，从源头切断账目不平的脏数据下沉；
2. **缺失核心资产科目硬门禁**：
   若输入的财报底账中 `total_assets <= 0`，强制抛出 `IncompleteFilingFactError`，禁止未清洗底账伪造指标；
3. **金融数学边界防御与除零安全保护**：
   全指标计算均通过底层 `_safe_divide(numerator, denominator, default=0.0)` 保护，当分母为零或负数非法时，自动安全回退为零，杜绝 `ZeroDivisionError` 导致批量管线崩溃；
4. **行情数据时效性与时段状态穿透**：
   若输入包含盘中报价，门面自动调用 `QuoteFreshnessGateway` 校验交易时段状态，并在档案中标注 `pre_market`、`regular_trading`、`after_hours` 或 `previous_close`。

## 附录：工程实现与边界自查清单 (Engineering Defense Checklist)

- [ ] **资产负债表刚性配平约束**：$|\text{Total Assets} - (\text{Total Liabilities} + \text{Total Equity})| \le 0.1\% \times \text{Assets}$，超出必须抛出异常拦截。
- [ ] **有限责任下界截断**：每股公允价值与股权价值下界锁定为 0.00，当净负债超过企业总价值时禁止输出负股价。
- [ ] **跨市场货币单位对齐**：日元报表必须完整区分“百万日元”与“十亿日元”，美元报表必须区分“千美元”与“百万美元”，严禁数量级错位。
- [ ] **时效性与版本追加原则**：财报重述以新增版本追加写入数据库，严禁对已登记的权威事实执行 SQL `UPDATE` 或 `DELETE` 物理覆盖。
