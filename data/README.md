# 项目数据目录

使用说明：[数据与证据管理](../docs/04-数据与证据管理.md)。

- [质量提醒政策](quality-policy.json)
- `catalog/`：SQLite 目录、内容对象与研究版本；由脚本管理，禁止手工改写。
- `backups/`：项目内备份，必须新目录创建并独立校验。
- `.tests/`：回归测试临时目录，清理仅限本次已确认的项目内临时子目录。

目录内合成演示须与真实资料区分。`ingestion/` 和 `browser-search/` 包含官方原文及浏览器登记；`financial/` 包含 Intuit、Sony、任天堂真实财报解析快照和验收索引；`taxonomies/` 包含官方分类标准包及离线缓存。正式财务事实位于 catalog 的 financial_facts 表，由登记脚本管理，不代表六步分析已完成。[财报使用说明](../docs/14-财报解析标准化与计算功能设计.md)。

上述少量财报样本不能用于宣称行业投资阈值已完成统计校准。原始内容对象不自动执行或联网读取。
