# 烟草：行业专属指标数据字典

代表公司：Philip Morris International（US:PM）。适用范围：卷烟及无烟产品。代表公司不覆盖所有子行业。

## tobacco_driver_1 — 传统卷烟出货量

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 传统产品销量 |
| 业务含义 | 按产品和地区披露 |
| 值类型 | scalar |
| 单位 | physical_quantity |
| 必需原始数据项 | 传统卷烟数量,地区产品 |
| 口径与禁止替代项 | 加热烟与尼古丁袋单独保存；出货不等于终端消费 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| tobacco_driver_1__value | 传统卷烟出货量 | physical_quantity | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
