# 化工：行业专属指标数据字典

代表公司：Dow（US:DOW）。适用范围：基础及特种化工。代表公司不覆盖所有子行业。

## chemicals_driver_1 — 同产品原料价差

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 产品原料价差 |
| 业务含义 | 单位产品价格减匹配原料成本 |
| 值类型 | scalar |
| 单位 | currency_per_unit |
| 必需原始数据项 | 产品单位售价,匹配原料单位成本,投入系数 |
| 口径与禁止替代项 | 不同产品链分开；销售价格同比不是绝对价差 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| chemicals_driver_1__value | 同产品原料价差 | currency_per_unit | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
