# 油气勘探与生产：行业专属指标数据字典

代表公司：EOG Resources（US:EOG）。适用范围：油气勘探生产。代表公司不覆盖所有子行业。

## oil_gas_driver_1 — 分产品实现售价

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 实现售价 |
| 业务含义 | 销售收入/可比销售量 |
| 值类型 | scalar |
| 单位 | currency_per_unit |
| 必需原始数据项 | 产品销售收入,产品销售量 |
| 口径与禁止替代项 | 原油 USD/bbl、天然气 USD/Mcf 分开；套期保值前后分开 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| oil_gas_driver_1__value | 分产品实现售价 | currency_per_unit | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
