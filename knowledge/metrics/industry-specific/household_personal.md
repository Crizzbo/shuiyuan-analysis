# 家庭与个人用品：行业专属指标数据字典

代表公司：Procter & Gamble（US:PG）。适用范围：家庭及个人消费品。代表公司不覆盖所有子行业。

## household_personal_driver_1 — 有机可比销量增长

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 可比销量增长 |
| 业务含义 | 同范围销量同比 |
| 值类型 | scalar |
| 单位 | ratio |
| 必需原始数据项 | 公司可比销量披露,范围调整 |
| 口径与禁止替代项 | 并购退出与汇率排除方法保留；销售额增速不能替代 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| household_personal_driver_1__value | 有机可比销量增长 | ratio | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
