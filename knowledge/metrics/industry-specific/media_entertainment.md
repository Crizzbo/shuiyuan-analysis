# 媒体游戏与娱乐：行业专属指标数据字典

代表公司：Netflix（US:NFLX）。适用范围：订阅影视内容服务。代表公司不覆盖所有子行业。

## media_entertainment_driver_1 — 付费订阅用户数量

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 付费用户 |
| 业务含义 | 明确平均与期末口径 |
| 值类型 | scalar |
| 单位 | physical_quantity |
| 必需原始数据项 | paid membership,平均或期末,产品地区 |
| 口径与禁止替代项 | MAU 及广告受众不能代替付费用户；停披露后旧值不能冒充本期 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| media_entertainment_driver_1__value | 付费订阅用户数量 | physical_quantity | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
