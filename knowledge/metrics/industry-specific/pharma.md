# 成熟制药：行业专属指标数据字典

代表公司：Pfizer（US:PFE）。适用范围：商业化药品与研发管线。代表公司不覆盖所有子行业。

## pharma_driver_1 — 单药净销售收入

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 产品净收入 |
| 业务含义 | 按药品及返利后口径 |
| 值类型 | scalar |
| 单位 | currency |
| 必需原始数据项 | 产品净收入,药品与地区标识 |
| 口径与禁止替代项 | 返利折扣计入方式保留；联合销售和合作分成分开 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| pharma_driver_1__value | 单药净销售收入 | currency | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
