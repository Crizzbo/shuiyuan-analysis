## banks_driver_1 — 同口径年化净息差

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 净息差 |
| 业务含义 | 年化净利息收入/平均生息资产 |
| 值类型 | scalar |
| 单位 | ratio |
| 必需原始数据项 | 年化净利息收入,平均生息资产或公司 NIM |
| 口径与禁止替代项 | 税等价与 GAAP 分开；年化天数方法保留 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |
