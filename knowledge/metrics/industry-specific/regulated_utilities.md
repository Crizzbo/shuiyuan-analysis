# 受监管公用事业：行业专属指标数据字典

代表公司：Duke Energy（US:DUK）。适用范围：受监管公用事业法律主体。代表公司不覆盖所有子行业。

## regulated_utilities_driver_1 — 监管批准费率资产基数

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 费率基数 |
| 业务含义 | 经批准的可获回报资产 |
| 值类型 | scalar |
| 单位 | currency |
| 必需原始数据项 | 监管批准 rate base,法律主体,决定日期 |
| 口径与禁止替代项 | 集团 PP&E 与预测 rate base 不能当获批资产 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| regulated_utilities_driver_1__value | 监管批准费率资产基数 | currency | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
