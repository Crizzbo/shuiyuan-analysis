# 电信：行业专属指标数据字典

代表公司：Verizon（US:VZ）。适用范围：无线消费者及企业通信分部。代表公司不覆盖所有子行业。

## telecom_driver_1 — 单匹配用户服务 ARPU

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | ARPU |
| 业务含义 | 可比服务收入/平均匹配用户 |
| 值类型 | scalar |
| 单位 | currency_per_subscriber |
| 必需原始数据项 | 服务收入,平均对应用户,月数 |
| 口径与禁止替代项 | ARPA 是账户而非用户；账户收入不能直接改名 ARPU |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| telecom_driver_1__value | 单匹配用户服务 ARPU | currency_per_subscriber | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
