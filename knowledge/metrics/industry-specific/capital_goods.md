# 工业设备与自动化：行业专属指标数据字典

代表公司：GE Vernova（US:GEV）。适用范围：电力及电网设备。代表公司不覆盖所有子行业。

## capital_goods_driver_1 — 新增订单收入比

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 订单收入比 |
| 业务含义 | 同期间新增订单额/确认收入 |
| 值类型 | scalar |
| 单位 | ratio |
| 必需原始数据项 | 新增订单金额,同期间确认收入 |
| 口径与禁止替代项 | 按分部同币种；订单含取消和服务多年合同的定义保留 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| capital_goods_driver_1__value | 新增订单收入比 | ratio | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
