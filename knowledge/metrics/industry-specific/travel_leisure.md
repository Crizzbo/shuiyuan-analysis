# 旅游酒店与休闲：行业专属指标数据字典

代表公司：Marriott International（US:MAR）。适用范围：管理及加盟酒店。代表公司不覆盖所有子行业。

## travel_leisure_driver_1 — 可比酒店入住率

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 酒店入住率 |
| 业务含义 | 售出间夜/可售间夜 |
| 值类型 | scalar |
| 单位 | ratio |
| 必需原始数据项 | 售出间夜,可售间夜或公司披露入住率 |
| 口径与禁止替代项 | 同物业群、地区、品牌；管理加盟与自营分开 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| travel_leisure_driver_1__value | 可比酒店入住率 | ratio | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
