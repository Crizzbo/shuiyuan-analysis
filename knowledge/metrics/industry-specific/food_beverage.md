# 食品饮料：行业专属指标数据字典

代表公司：Coca-Cola（US:KO）。适用范围：饮料系统及浓缩液。代表公司不覆盖所有子行业。

## food_beverage_driver_1 — 可比产品销量增长

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 销量增长 |
| 业务含义 | 可比销量同比 |
| 值类型 | scalar |
| 单位 | ratio |
| 必需原始数据项 | 本期可比销量,同期可比销量或披露增长 |
| 口径与禁止替代项 | 系统销量与母公司浓缩液销售分别保存；日均与实际日历总量区分 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| food_beverage_driver_1__value | 可比产品销量增长 | ratio | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
