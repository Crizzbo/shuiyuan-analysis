# 零售与电商：行业专属指标数据字典

代表公司：Walmart（US:WMT）。适用范围：一般零售分部。代表公司不覆盖所有子行业。

## retail_driver_1 — 可比门店销售增长

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 同店销售增长 |
| 业务含义 | 相同门店范围收入同比 |
| 值类型 | scalar |
| 单位 | ratio |
| 必需原始数据项 | 公司同店销售披露,门店纳入规则 |
| 口径与禁止替代项 | 线上业务、燃油、汇率和 53 周调整明确 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| retail_driver_1__value | 可比门店销售增长 | ratio | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
