# 医疗保险与管理式医疗：行业专属指标数据字典

代表公司：UnitedHealth Group（US:UNH）。适用范围：UnitedHealthcare 医疗保险，Optum 单列。代表公司不覆盖所有子行业。

## managed_care_driver_1 — 报告医疗成本率

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 医疗赔付率 |
| 业务含义 | 匹配医疗成本/保费收入 |
| 值类型 | scalar |
| 单位 | ratio |
| 必需原始数据项 | 匹配医疗成本,医疗保费或公司 MCR |
| 口径与禁止替代项 | 报告与调整后 MCR 分开；监管 MLR 不直接替代 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| managed_care_driver_1__value | 报告医疗成本率 | ratio | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
