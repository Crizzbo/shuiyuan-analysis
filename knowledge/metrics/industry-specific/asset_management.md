# 资产管理与资本市场：行业专属指标数据字典

代表公司：BlackRock（US:BLK）。适用范围：收费资产管理，技术服务单列。代表公司不覆盖所有子行业。

## asset_management_driver_1 — 客户净资金流入

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 净流入 |
| 业务含义 | 剔除市场变化的客户资金流 |
| 值类型 | scalar |
| 单位 | currency |
| 必需原始数据项 | 客户流入,流出,资本返还,公司流量定义 |
| 口径与禁止替代项 | 市场收益外汇并购增加剔除；realizations 是否另列按原文 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| asset_management_driver_1__value | 客户净资金流入 | currency | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
