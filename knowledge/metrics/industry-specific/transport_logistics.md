# 运输与物流：行业专属指标数据字典

代表公司：Delta Air Lines（US:DAL）。适用范围：航空运输。代表公司不覆盖所有子行业。

## transport_logistics_driver_1 — 运输工作量载运率

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 载运或利用率 |
| 业务含义 | 已使用运力/可用运力 |
| 值类型 | scalar |
| 单位 | ratio |
| 必需原始数据项 | 收入客公里或吨公里,可用座公里或吨公里 |
| 口径与禁止替代项 | 航空、货运分开；单位距离口径相同 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| transport_logistics_driver_1__value | 运输工作量载运率 | ratio | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
