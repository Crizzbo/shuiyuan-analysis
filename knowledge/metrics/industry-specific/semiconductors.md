# 半导体设计与制造：行业专属指标数据字典

代表公司：Micron Technology（US:MU）。适用范围：DRAM 与 NAND 制造。代表公司不覆盖所有子行业。

## semiconductors_driver_1 — 终端渠道库存量或天数

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 渠道库存 |
| 业务含义 | 按终端与口径记录 |
| 值类型 | components |
| 单位 | components |
| 必需原始数据项 | 渠道产品库存量,匹配渠道日销量,终端类别 |
| 口径与禁止替代项 | 企业账面存货与渠道库存不同；缺渠道数据留空 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| semiconductors_driver_1__channel_units | 渠道存货数量 | physical_quantity | instant |
| semiconductors_driver_1__channel_days | 渠道库存覆盖天数 | days | instant |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
