## aerospace_defense_driver_1 — 已拨款订单占比

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 订单可执行比例 |
| 业务含义 | 已获拨款或承诺订单/可比订单 |
| 值类型 | scalar |
| 单位 | ratio |
| 必需原始数据项 | 已拨款或已承诺可执行订单,相同范围总订单 |
| 口径与禁止替代项 | funded 与 unfunded backlog 分开；总 backlog 不能替代比例 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |
