# 市场化发电：行业专属指标数据字典

代表公司：Constellation Energy（US:CEG）。适用范围：竞争性发电及售电。代表公司不覆盖所有子行业。

## merchant_power_driver_1 — 匹配售电捕获价格

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 捕获电价 |
| 业务含义 | 售电收入/匹配售电量 |
| 值类型 | scalar |
| 单位 | currency_per_mwh |
| 必需原始数据项 | 匹配售电净收入,对应 MWh |
| 口径与禁止替代项 | 批发零售和对冲结算分开；集团收入不能直接除总发电量 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| merchant_power_driver_1__value | 匹配售电捕获价格 | currency_per_mwh | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
