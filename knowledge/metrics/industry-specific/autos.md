# 汽车与零部件：行业专属指标数据字典

代表公司：Toyota Motor（JP:7203）。适用范围：整车零售与生产，金融分部单列。代表公司不覆盖所有子行业。

## autos_driver_1 — 终端零售车辆数量

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 终端销量 |
| 业务含义 | 交付终端客户的车辆数 |
| 值类型 | scalar |
| 单位 | physical_quantity |
| 必需原始数据项 | 零售终端交付数,品牌地区 |
| 口径与禁止替代项 | 批发销量和产量不能代替零售；含合营子公司须注明 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| autos_driver_1__value | 终端零售车辆数量 | physical_quantity | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
