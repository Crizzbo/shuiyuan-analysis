# 建筑与工程：行业专属指标数据字典

代表公司：Fluor（US:FLR）。适用范围：工程建设合同。代表公司不覆盖所有子行业。

## construction_driver_1 — 可执行积压订单覆盖年数

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 订单覆盖 |
| 业务含义 | 可执行积压订单/可比年度收入 |
| 值类型 | scalar |
| 单位 | years |
| 必需原始数据项 | 可执行期末订单额,同范围年度收入 |
| 口径与禁止替代项 | 总订单若包括未融资或可取消部分须披露差异 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| construction_driver_1__value | 可执行积压订单覆盖年数 | years | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
