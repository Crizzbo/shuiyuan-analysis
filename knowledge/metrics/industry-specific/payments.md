# 支付与金融基础设施：行业专属指标数据字典

代表公司：Visa（US:V）。适用范围：支付网络，非发卡贷款业务。代表公司不覆盖所有子行业。

## payments_driver_1 — 定义内支付处理金额

| 字段 | 中文说明 |
|---|---|
| 原驱动中文名称 | 处理金额 |
| 业务含义 | 按支付或交易定义 |
| 值类型 | scalar |
| 单位 | currency |
| 必需原始数据项 | 支付处理量,交易类型,地区币种 |
| 口径与禁止替代项 | 支付量与含现金提取总量分开；跨境增速不是总处理额 |
| 来源顺序 | 公司年报及经营补充表、监管原文、官方行业统计 |
| 采集方法 | AI 浏览器核验原文后归档；无 API 配置 |
| 缺数处理 | 保留空值、原因及核验材料范围；阻断对应结论 |
| 判断标准 | 比较同口径时间趋势并保留反证；无经验验证阈值 |

| 原子字段标识 | 中文名称 | 单位类型 | 期间类型 |
|---|---|---|---|
| payments_driver_1__value | 定义内支付处理金额 | currency | source_dependent |

所有字段均须绑定具体原文。currency 必须另填币种；physical_quantity 必须另填产品物理单位。缺数不得补零。
