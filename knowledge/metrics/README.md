- [行业专属指标统一目录](industry-specific/README.md)：41 个行业各自独立的数据字典。

- [已登记样本核验结果](../../data/financial/industry-specific-verification.json)：样本数量、内容地址和当前覆盖范围。
- [逐行业原文覆盖报告](industry-sample-coverage.md)：41 家代表公司的三项驱动分别列出已有样本和剩余缺口。
- [追加原子字段分表字典](industry-reviewed-bindings-20261011.md)：本批 30 个字段的中文名称、单位、用途及禁止替代项。
