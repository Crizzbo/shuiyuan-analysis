## 一、 产业生命周期非线性变异与阶段化聚焦

判定标的所处行业的生命周期发展阶段是行业研究的第一物理法则。**阶段判错，后续所有估值模型与投资逻辑全错**。产业发展并非机械的匀速直线运动，必须结合核心产品渗透率与 S 型技术扩散曲线进行非线性动态校准：

```
行业渗透率 S 曲线
100% ┌───────────────────────────────────────────────────────────── 饱和成熟 / 代际替代
     │                                                     . - '   (关注护城河、自由现金流与分红)
     │                                            . - '
     │                                   . - ' 成長加速期 (20%～40%)
     │                          . - '          (规模效应、单位成本骤降、龙头格局初显)
     │                 . - ' 导入期破产死亡谷 (10%～20% 达尔文大清洗)
     │        . - '
  0% └───────────────────────────────────────────────────────────── 导入萌芽期 (<10%) (验证商业模式与单位经济)
```

### 1. 生命周期五阶段与买方唯一聚焦维度
| 渗透率区间与阶段特征 | 发展阶段定位 | 买方唯一激活维度 | 核心三问与研究要害 | 投研判断工具箱与关键指标 |
| :--- | :--- | :--- | :--- | :--- |
| **渗透率 < 10%**<br>极低认知、技术方案未定型 | **导入萌芽期** | **商业模式可行性** | 1. 真实客户需求是否存在？<br>2. 单位经济模型 (UE) 能否转正？<br>3. 商业方案能否标准化规模化复制？ | 空间对标与时间对标、单客户经济模型 (LTV/CAC > 3.0x)、产品频次与价格弹性分析 |
| **渗透率 10%～20%**<br>技术路线收敛、大量作坊暴雷 | **破产死亡谷**<br>(Valley of Death) | **资金跑道与生存壁垒** | 1. 账面净现金能否支撑至盈亏平衡？<br>2. 核心研发专利是否具备排他性？<br>3. 能否抵御行业头部价格战降维打击？ | 动态现金消耗率 (Burn Rate)、现金跑道月数 (> 24个月)、供应链排他保供协议 |
| **渗透率 20%～45%**<br>客户认知普及、需求爆发式喷涌 | **成长期 / 爆发期** | **市场空间与规模效应** | 1. 潜在总市场空间 (TAM) 究竟有多大？<br>2. 产业链最大产能瓶颈环节在何处？<br>3. 龙头能否凭借规模扩张压低单件成本？ | TAM → SAM → SOM 逐级穿透拆解、资本开支转化率、学习曲线与制造成本降幅 |
| **渗透率 45%～80%**<br>增长中枢下移、供给端胜负已定 | **成熟期 / 收割期** | **竞争格局与护城河** | 1. 行业龙头五维护城河是否足够宽深？<br>2. 产业链上下游超额利润归属于谁？<br>3. 龙头能否将资本开支转化为自由现金流？ | CR3/CR5 行业集中度、杜邦三因子 ROE 拆解、自由现金流转化率 (> 80%)、股息分红 |
| **渗透率 > 80% / 替代出现**<br>总销量负增长、技术代际颠覆 | **衰退期 / 转型期** | **替代威胁与第二曲线** | 1. 核心需求会被哪种跨界技术颠覆替代？<br>2. 老业务能否转型为抗跌年金机器？<br>3. 研发投入能否成功孵化第二成长曲线？ | 替代品总体拥有成本 (TCO) 对比、存量客户流失率、资产减值压力测试、跨赛道研发转化 |

## 二、 买方波特五力模型实战重构与产业链价值分配博弈

经典产业经济学往往将五力模型作为静态文字描述，买方机构必须将其升维为**产业链资金与利润分配的动态博弈战局**：

```
                 ┌────────────────────────────────────────────────────────┐
                 │ 潜在跨界颠覆者与新进入者 (New Entrants)                 │
                 │ 评估进入壁垒：资本开支规模、特许牌照门槛、规模经济临界点│
                 └───────────────────────────┬────────────────────────────┘
                                             ▼
┌────────────────────────┐       ┌────────────────────────┐       ┌────────────────────────┐
│ 上游核心供应商         │       │ 行业现有竞争者         │       │ 下游核心客户与采购方   │
│ (Suppliers)            │──────►│ (Industry Rivalry)     │──────►│ (Buyers)               │
│ 关键零部件/原料垄断度  │       │ 产能周期与价格战激烈度 │       │ 议价能力、替换成本、   │
│ 涨价成本向下顺价转嫁力 │       │ CRn集中度与退出壁垒    │       │ 客户采购支出占自身比例 │
└────────────────────────┘       └────────────────────────┘       └────────────────────────┘
                                             ▲
                 ┌───────────────────────────┴────────────────────────────┐
                 │ 替代技术路线与替代商品 (Substitutes)                    │
                 │ 测算替代品性价比斜率、转换经济性与用户心智代际变迁      │
                 └────────────────────────────────────────────────────────┘
```

### 1. 上游供应商垄断性穿透 (Supplier Power)
- **核心供给集中度**：上游关键材料、设备或知识产权是否由极少数寡头掌控（如先进半导体制造中的 ASML 光刻机、大分子生物药的特种耗材）；
- **成本顺价传导力**：当上游原材料价格暴涨时，行业内企业能否在 1～2 个季度内将成本 100% 顺价转嫁给下游，而不造成自身销量的大幅萎缩。

### 2. 下游买方议价权与价格弹性 (Buyer Power)
- **买方集中度与单客户风险**：前五大客户销售占比是否过高（> 40% 构成重大依赖）；
- **客户转换成本**：客户放弃本企业产品转向竞品时，是否面临系统停摆、产线重置、员工培训等极高摩擦成本；
- **采购占比敏感度**：本产品占下游客户总生产成本比例越低，下游对其提价的敏感度越钝化，企业提价空间越大。

### 3. 产能周期四阶段与内耗价格战 (Industry Rivalry & Capacity Cycle)
1. **阶段 1：需求爆发、供不应求（暴利期）**：全行业产能利用率突破 95%，产品交期拉长，毛利率与净利率飙升至历史高位；
2. **阶段 2：盲目扩产、资本狂欢（过度投资期）**：高利润吸引全行业大举举债购置设备、新建工厂，在建工程暴增；
3. **阶段 3：产能集中释放、恶性价格战（出清期）**：新产能扎堆投产导致供给严重过剩，中小作坊低价倾销，产品跌破现金成本线，全行业陷入大面积亏损；
4. **阶段 4：作坊倒闭出清、龙头格局改善（复苏期）**：落后产能破产或被兼并，供需重新恢复健康平衡，龙头企业市场份额跃升，行业重获定价权。

## 三、 买方五维动态护城河结构 (Five-Dimensional Dynamic Moat)

护城河是企业在漫长岁月里抵御外部资本侵蚀、持续获取超额资本回报率 (ROIC > WACC) 的唯一物理屏障。买方必须从五个具体维度严密求证：

| 护城河维度 | 核心微观机制 | 典型商业载体与标杆企业 | 穿透检验断言与反证警示 |
| :--- | :--- | :--- | :--- |
| **1. 无形资产与品牌绝对提价权** | 独家专利技术配方、百年品牌心智垄断、特许准入许可 | 顶级奢侈品爱马仕、高端白酒贵州茅台、原研药礼来 Eli Lilly | **检验断言**：企业能否在连续提价 5%～8% 的同时，销量保持稳定或微增；若提价后客户大面积流失，则品牌护城河纯属虚妄。 |
| **2. 高客户转换成本与系统锁定** | 与客户业务底层 ERP 深度耦合、迁移面临停机与数据丢失风险 | 基础设施软件微软 Windows/Office、世邦魏理仕企业设施管理 (IFM) | **检验断言**：核心企业级大客户年化净收入留存率 (NDR) 是否长期大于 110%；若竞品降价 20% 即可引发客户切单，则转换壁垒不存在。 |
| **3. 网络效应与双边飞轮** | 随着使用该产品的人数增加，该产品对所有新老用户的价值呈几何级暴增 | 存量房流通平台贝壳找房 (ACN网络)、国际信用卡 Visa/万事达卡 | **检验断言**：平台两端用户能否实现自发裂变拉新、营销费用占营收比重是否持续收窄；若全靠平台补贴烧钱维持活跃，则属于假性网络效应。 |
| **4. 结构性低成本优势** | 独家不可复制的低成本资源禀赋、极端规模经济、专有高效工艺 | 铜矿巨头南方铜业 (副产品抵扣)、高周转零售好市多 Costco | **检验断言**：在全行业产品价格跌破全行业平均现金成本、同行大面积亏损时，该龙头能否依然保持正向自由现金流并持续逆势扩张。 |
| **5. 监管特许与法定垄断牌照** | 国家法律法规强制授权、区域排他经营权、极高安全准入门槛 | 受监管区域公用事业电网、核电站运营牌照 (NRC)、军工资质 | **检验断言**：核准权益回报率 (Allowed ROE) 能否在法律框架下得到刚性保障；警惕因政府换届或民粹反弹导致的追溯性费率削减风险。 |

## 四、 产业链微笑曲线与利润池 (Profit Pool) 动态迁移

在任何成熟产业链中，不同环节的附加值与资本回报率呈极其不均等的 U 型微笑曲线分布：

```
附加值 (Value Added)
高 ▲     【上游研发设计与底层材料】                                      【下游品牌渠道与终端服务】
   │      • 芯片 IP、先进光刻设备 (ASML, NVDA)                            • 终端奢品、数字化分发网络
   │      • 医药专利分子、特种合金配方                                    • 售后维保、订阅生态平台
   │         \                                                          /
   │          \                                                        /
   │           \                                                      /
   │            \                                                    /
   │             \               【中游标准化加工组装】             /
   │              \               • 代工组装、粗钢冶炼、注塑加工   /
低 ┼───────────────\────────────── • 资本开支沉重、极低议价权 ─────/─────────────────────────►
   └──────────────────────────────────────────────────────────────────────────────── 产业链环节
```

### 1. 利润池 (Profit Pool) 迁移法则
- **组装环节利润永久被两头挤压**：中游制造加工环节壁垒最低、可替代性最强，长期承受上游涨价与下游压价的“夹心饼干”酷刑；
- **投资策略核心指向**：买方投资必须坚决超配微笑曲线两端的**“高技术壁垒上游核心垄断者”**或**“掌控终端用户心智与渠道定价权的下游巨头”**，规避深陷重资产资本开支陷阱的中游代工厂。

## 五、 宏观传导、信贷利率与行业动力学

引用 [宏观周期框架](framework/cycles.md)，系统性解构全球央行基准利率、信用利差、大宗通胀与汇率波动对各行业的非对称冲击：

### 1. 利率传导的非对称分化
- **长久期与高负债重资产行业（极度承压）**：公用事业、重资产房地产开发、高负债电信运营商、未盈利科技股；其贴现率敏感性极高，加息将大幅推升财务利息负担并导致估值倍数膝跳式腰斩；
- **轻资产净现金流充沛行业（深度受益）**：大型银行 (净息差 NIM 走廊走扩)、手握数百亿美元净现金的成熟软件巨头 (利息收入暴增增厚净利)。

### 2. 危机极端情景与抗打击压力测试
在宏观流动性枯竭或滞胀危机爆发时，买方机构必须对行业内企业展开三道极限生存压力测试：
1. **现金流断裂点测试**：在行业下游需求停摆、收入骤降 50% 且债务再融资完全冻结的极端情景下，企业依靠账面净现金与营运资金能存活几个月；
2. **固定成本刚性测试**：企业营业成本中固定折旧与刚性租金人工占比有多高，在销量断崖式下滑时能否极速收缩经营杠杆；
3. **银行债务契约安全垫**：现有 EBITDA 能否维持对利息支出的 3.0x 以上安全覆盖，是否面临触发银行贷款加速到期强制违约的死亡条款。

## 六、 行业景气度量化雷达与买方穿透式排雷防线

买方研究员必须依托客观高频量化数据对行业进行实时对账，严禁听信管理层口头画饼。

### 1. 行业核心量化景气度雷达
- **领先先行指标**：订单出货比 (Book-to-Bill Ratio, > 1.05x 扩张，< 0.95x 收缩)、存货周转天数 (DIO 异动环比上升超过 20% 预示滞销)；
- **同步验证指标**：同店销售增长率 (SSSG)、运价指数 (BDI/SCFI)、核心大宗现货出厂价与价差 (Crack Spread)；
- **滞后结转指标**：营业收入同比增速、账面净利润、资产负债表存货与合同负债余额。

### 2. 穿透式财务排雷四道防线
1. **第一道防线：渠道虚假压货排查** -> 审查应收账款增速是否远超营业收入增速，排查企业在会计期末向经销商疯狂强行压货以粉饰账面收入的行径；
2. **第二道防线：大额在建工程长年不转固** -> 审视在建工程余额占固定资产比例，严防企业将正常生产运营成本、研发失败费用违规资本化挂账在建工程以逃避计提折旧；
3. **第三道防线：大额减值洗大澡预警** -> 监测企业是否在行业下行期一次性计提数十亿美元商誉与存货跌价损失，彻底掩盖前期激进盲目并购与高位囤货的经营溃败；
4. **第四道防线：非经常性公允价值变动虚增利润** -> 严格剥离投资性房地产、参股非上市公司股权评估收益对当期利润的干扰，还原纯主营业务真实造血成色。

## 七、 估值范式随周期跃迁的映射矩阵

不同生命周期阶段与不同商业属性的行业，必须严格匹配对应的金融估值范式，严禁全行业套用单一市盈率 (P/E)：

| 行业阶段与商业特征 | 法定主流估值模型 | 核心输入变量与参数假设 | 致命估值陷阱与反例警示 |
| :--- | :--- | :--- | :--- |
| **导入期 / 高成长早期** | **单位经济模型 (UE) + 市场空间概率折现** | 客户终生价值 (LTV)、客户获取成本 (CAC)、可触达市场上限 (TAM) | **切忌使用静态 PE**：在企业尚未实现规模盈利时使用静态市盈率会导致估值无穷大而错失十倍股机会。 |
| **稳健成长期白马股** | **两阶段自由现金流折现 (DCF) + PEG 模型** | 加权平均资本成本 (WACC)、超额增长期增速、永续增长率 (2%～3%) | **切忌盲目外推永续高增速**：将阶段性爆发的 30% 增速机械外推至未来 10 年，一旦业绩失速将遭遇剧烈戴维斯双杀。 |
| **成熟期现金奶牛** | **所有者收益 (Owner Earnings) 折现 + 正常化 EV/EBITDA** | 扣除维持性资本开支后的真实自由现金流、净债务调整、股东分红率 | **切忌混淆净利润与自由现金流**：将账面高净利润等同于真实造血，忽视沉重重置设备支出对现金流的蚕食。 |
| **强周期大宗工业股** | **穿越周期的市净率 (P/B) + 重置成本法 (Replacement Cost)** | 有形账面价值 (TBV)、历史估值分位数、产能重置建设成本 | **绝不可在周期顶部低 PE 时买入**：强周期股在盈利巅峰期市盈率往往仅 3～5 倍，盲目买入将面临盈利腰斩与估值下挫双重毁灭。 |
| **衰退期与清算破产标的** | **净流动资产价值 (NCAV) + 股息贴现 (DDM)** | 现金及等价物扣减全部长短期负债、固定资产折价清算系数 | **谨防价值陷阱 (Value Trap)**：看似只有 0.3x PB，但企业每月失血消耗现金、技术被时代彻底淘汰，最终走向清盘归零。 |
