# 行研框架（《如何快速了解一个行业》肖璟）

> 本文件为知识库：行业研究框架。SKILL.md 六步法第①②③步按需引用。

## 生命周期定位（第①步）

先判定标的所处行业的生命周期阶段（查核心产品渗透率），**阶段判错后续全错**：

| 渗透率区间 | 阶段 | 后续聚焦 |
|-----------|------|---------|
| < 15% | 导入期 | 商业模式可行性 |
| 15%～20% | 进入成长期 | 市场规模 |
| 20%～35% | 成长加速期 | 市场规模 + 竞争格局初判 |
| 35%～40% | 进入成熟期 | 护城河 + 竞争格局 |
| 高位且替代出现 | 衰退期 | 替代威胁 / 第二曲线 |

注意：行业未必线性走完四阶段——大量行业在导入期就死掉；成熟期也可能靠新技术开辟第二曲线回到成长期。

## 阶段化聚焦（第②步：基本面只激活一个维度）

| 阶段 | 唯一维度 | 核心三问 | 判断工具 |
|------|---------|---------|---------|
| 导入期 | 商业模式可行性 | 需求真实吗？盈利可持续吗？能规模化复制吗？ | 时间对标 + 空间对标；收入看「频次×弹性」、成本看「标准化程度」、搭 UE 单位经济模型 |
| 成长期 | 市场规模 | 天花板多高？3-5 年能做多大？我能分多少？ | TAM（渗透率×替代率）→ SAM → SOM（瓶颈环节） |
| 成熟期 | 护城河 + 竞争格局 | 护城河宽不宽？头部能分多少钱？ | 护城河两路 + CRn 集中度 + 产业链利润分配 |
| 衰退期 | 替代威胁 | 会被什么替代？有无第二曲线？ | 替代三结果：衰退 / 第二曲线 / 周期股 |

## 护城河

**两条路**：资源垄断（劳动/土地/资本/技术/数据）+ 网络效应（政府/同行/供应商/客户）。

## 盈利性（成熟期谁能赚钱，横向 + 纵向双看）

- **横向（行业集中度）**：CR3 / CR4 / CR5 / CR8。集中度越高 → 龙头议价权越强 → 行业整体盈利能力越强。集中度上升的驱动：行业吸引力弱、进入壁垒高、产业政策限供给、价格战/兼并重组。
- **产能周期四阶段**：供不应求 → 产能激增 → 产能出清 → 格局改善（判断当前处在哪一阶段，决定龙头盈利能否持续）。
- **纵向（产业链利润分配）**：议价意愿 = 商品在下游的价值占比 + 行业周期阶段；议价能力 = 对手方有没有得选（看各环节集中度 + 供需）。观察指标：各环节毛利率 + 占用上下游资金的能力。

## 估值随阶段切换

导入期用 VC 法（看梦想/空间，别用 PE）；成长期用成长股逻辑；成熟期用周期股；衰退期用低估值。估值本质：需求端看投资者「能力（宏观流动性）× 意愿（风险偏好）」，供给端看资产「赔率 × 概率」。

## 导火线（第③步：PEST）

**PEST 扫一遍，回答「什么事件能引爆这个行业」**：
- P 政治：产业政策第一位（扶持性 vs 限制性）
- E 经济：经济增速 + 货币价格（通胀/利率/汇率），高利率压制导入期标的估值
- S 社会：人口结构、文化变迁
- T 技术：三作用（可行/降本/新渠道），**必看技术成熟度而非画饼**

## 景气度指标（找产业链核心驱动环节，锁定 2-3 个核心指标持续验证）

| 环节 | 关键指标 |
|------|---------|
| 上游原材料 | 价格 + 库存 |
| 中游制造 | 产销量 |
| 大消费 | 通胀（必选）+ 房地产（可选） |
| 服务业 | 宏观经济整体 |
| 新兴行业 | 自身产业周期 |

> 白酒案例（可迁移）：核心指标是**批价**（数据可得、即时反映供需、直接影响业绩），辅以经销商库存、打款节奏、开瓶率。
