# 全维买方金融投研术语辞典 (Buy-Side Research Glossary)

> 本文件为知识库核心基础设施：全市场全天候买方金融投研、商业模式、财报穿透与交易风控术语速查总表。供六步分析法全流程、公司深度档案构建及个股深度研报按需引用。
> 版本：V3.0.0 买方机构级标准 | 更新时间：2026-11-07

## 一、 市场空间、行业竞争格局与护城河术语

| 术语简称 | 英文全称 | 核心商业含义与买方投研直觉 |
| :--- | :--- | :--- |
| **TAM** | Total Addressable Market | **潜在市场总空间**：在 100% 理想渗透率与产品完全替代情景下，行业所能达到的理论消费与支出总盘子。 |
| **SAM** | Serviceable Addressable Market | **可服务市场空间**：基于企业当前现有技术路线、地理覆盖区域、渠道能力与准入许可所能触达的真实市场盘子。 |
| **SOM** | Serviceable Obtainable Market | **可获得市场空间（终局份额）**：在激烈的行业竞争、供应链瓶颈与产能约束下，企业在未来 3~5 年内切实能够拿下的市场份额。 |
| **CRn** | Concentration Ratio (CR3 / CR4 / CR8) | **行业集中度**：行业排名前 3 / 4 / 8 大龙头厂商的营业收入或产量占全行业总额的比例。CR3 > 60% 通常意味着进入寡头垄断稳态格局。 |
| **HHI** | Herfindahl-Hirschman Index | **赫芬达尔-赫希曼指数**：全行业所有企业市场份额平方和，衡量行业反垄断与竞争集中度的高灵敏指标。 |
| **Moat** | Economic Moat | **经济护城河**：巴菲特提出的核心概念，指企业抵御竞争对手蚕食其超额资本回报率（ROIC）的结构性结构壁垒（网络效应、转换成本、无形资产、成本优势）。 |
| **UE** | Unit Economics | **单体经济模型**：拆解到单笔交易、单家门店、单台设备或单个活跃用户的核心收入、边际可变成本与毛利空间，用于评估规模效应扩张的可行性。 |

## 二、 核心财务造血、营运资本与资本回报术语

| 术语简称 | 英文全称 | 核心商业含义与买方投研直觉 |
| :--- | :--- | :--- |
| **CFO** | Cash Flow from Operations | **经营活动现金流净额**：企业日常主营业务产生的真金白银现金流入，扣除了各项实际付现支出，是检验净利润含金量的第一试金石。 |
| **CapEx** | Capital Expenditures | **资本性支出**：购买厂房、机器设备、土地或专利技术等长期资产所支付的现金，分为维持性资本开支与扩张性资本开支。 |
| **FCF** | Free Cash Flow | **自由现金流**：$FCF = 经营活动现金流 (CFO) - 资本开支 (CapEx)$。企业能够无条件向股东分红、回购股票或还债而不影响正常经营的“现金纯氧”。 |
| **FCF Yield** | Free Cash Flow Yield | **自由现金流收益率**：$每股自由现金流 \div 股价$。衡量每投入 1 块钱买入股票，企业底层能为你产生多少真体现金回报，买方极度看重。 |
| **EBITDA** | Earnings Before Interest, Taxes, Depreciation & Amortization | **息税折旧摊销前利润**：剔除资本结构（利息）、税务管辖（所得税）以及历史重资产投资折旧影响的纯粹经营性造血利润。 |
| **NOPAT** | Net Operating Profit After Tax | **税后净营业利润**：假定企业没有任何负债融资成本（无利息支出）情景下的主营营业利润，是计算企业真实资本回报率的核心基石。 |
| **ROIC** | Return on Invested Capital | **投入资本回报率**：$ROIC = NOPAT \div (总有息负债 + 股东权益 - 超额现金)$。衡量管理层配置每一块钱长期资本创造超额利润的终极效率指标。 |
| **ROE** | Return on Equity | **净资产收益率**：归母净利润与归母股东权益的比值。通过杜邦三分解（净利润率 × 资产周转率 × 权益乘数杠杆）洞察盈利来源。 |
| **ROTCE** | Return on Tangible Common Equity | **有形普通股股东权益回报率**：扣除商誉与无形资产后的真实有形资本回报率，银行与金融机构估值的核心标尺。 |
| **CCC** | Cash Conversion Cycle | **现金转化周期**：$CCC = 存货周转天数 (DIO) + 应收账款周转天数 (DSO) - 应付账款周转天数 (DPO)$。从采购原料付现到销售收款回款的天数，越短甚至为负值越体现对上下游的绝对定价权。 |
| **DIO** | Days Inventory Outstanding | **存货周转天数**：衡量原材料及成品在仓库中积压滞留的天数。天数异常拉长往往是行业下行与存货跌价暴雷的前兆。 |
| **DSO** | Days Sales Outstanding | **应收账款周转天数**：衡量销售发生后多久能实际收回现金。天数拉长通常意味着向渠道妥协放水压货。 |
| **DPO** | Days Payable Outstanding | **应付账款周转天数**：衡量向供应商付款的拖延周期。天数越长表明企业在供应链上拥有极强的议价与无息占资能力。 |

## 三、 买方估值方法论、折现模型与定价倍数术语

| 术语简称 | 英文全称 | 核心商业含义与买方投研直觉 |
| :--- | :--- | :--- |
| **EV** | Enterprise Value | **企业价值**：$EV = 股票总市值 + 有息净负债 + 少数股东权益 - 现金及现金等价物$。收购整家公司（包含清偿全部债务）所需付出的真实总代价。 |
| **fwdPE** | Forward Price-to-Earnings | **前瞻市盈率**：现价除以未来 12 个月或未来 1 个财年的一致预期每股收益。反映市场对短期成长预期的定价倍数。 |
| **trailingPE** | Trailing Twelve Months PE | **滚动市盈率 (TTM)**：现价除以过去 12 个月已实现的实际净利润。反映历史已经落袋利润的估值倍数。 |
| **PEG** | Price/Earnings-to-Growth | **市盈率相对盈利增长比率**：$PEG = PE \div 净利润复合增长率$。彼得·林奇倡导的指标，通常 $PEG < 1$ 视为高成长未被充分定价，$PEG > 2$ 提示估值透支。 |
| **PB / P/TBV** | Price-to-Book / Price-to-Tangible Book | **市净率 / 市有形净资产比率**：股价与每股账面净资产（或有形净资产）的比值。重资产制造、银行及资本中介类企业的核心估值锚。 |
| **DCF** | Discounted Cash Flow | **现金流折现模型**：将企业未来存续期内创造的全部自由现金流，以加权平均资本成本（WACC）折现到当下的内在价值总和。 |
| **WACC** | Weighted Average Cost of Capital | **加权平均资本成本**：企业通过股权融资与债务融资所需支付的综合资本回报成本，是自由现金流折现时的关键贴现率。 |
| **SOTP** | Sum-of-the-Parts Valuation | **分部加总估值法**：对拥有多元化业务的综合巨头，将其拆分为不同业务板块，分别按照行业专属估值乘数定价后再汇总，常用于识别控股公司多元化折价。 |
| **NAV** | Net Asset Value | **净资产价值法**：评估企业名下所拥有的土地、物业、矿权或股权投资的真实市场公允清算价值，扣减债务后得到的每股净资产净值。 |
| **周期陷阱** | Cyclical Valuation Trap | **周期性估值陷阱**：在强周期行业（航运、化工、存储芯片）景气度顶峰，暴增的利润导致 PE 看起来只有 4~5 倍极度诱人，实为周期顶部接盘；在景气谷底巨额亏损导致 PE 极其昂贵甚至为负，实为逆向买点。 |
| **错误边际** | Margin of Safety (安全边际) | **错误容忍安全垫**：买入价格显著低于审慎保守评估出的内在价值（如折价 30% 以上），为宏观黑天鹅、行业衰退或估值预测失误留出的抗风险缓冲空间。 |
| **52周位置** | 52-Week Price Range Position | **52周价格相对位置**：$(现价 - 52周低) \div (52周高 - 52周低)$。数值 $< 20\%$ 表明处于一年价格绝对低位区间，提示超卖错杀可能；$> 90\%$ 提示超买透支。 |

## 四、 行业专属商业模式微观造血术语

| 术语简称 | 适用商业模式与行业 | 核心商业含义与买方投研直觉 |
| :--- | :--- | :--- |
| **ARR** | 订阅模式（云计算、SaaS） | **年度经常性收入**：基于订阅合约按年化计算的确定性经常性收入底盘，不包含一次性专业咨询实施费用。 |
| **NRR / GRR** | 订阅模式（云计算、SaaS） | **净金额留存率 / 毛金额留存率**：衡量同一群老客户在 12 个月后的续费与增购扩张能力。$NRR > 120\%$ 表明即使不获新客，业务底盘也能自主高速膨胀。 |
| **LTV / CAC** | 订阅模式、互联网平台 | **客户生命周期总价值 / 获客成本**：衡量营销获客 ROI 的金指标。$LTV:CAC > 3:1$ 证明单客造血飞轮健康，$LTV:CAC < 1$ 属于亏损烧钱陷阱。 |
| **Rule of 40** | 订阅模式、企业软件 | **40法则**：$营收同比增速 (\%) + 自由现金流利润率 (\%)$。数值超过 40% 的软件企业兼具高速成长与强劲造血，享有顶级估值溢价。 |
| **RPO** | 订阅模式、项目合同 | **剩余履约义务**：已签约但尚未在损益表确认收入的在手确定性订单积压总额，是预测未来 1~3 年确定性营收的“蓄水池”。 |
| **Take Rate** | 交易抽佣（平台、支付） | **净变现抽佣率**：平台撮合交易总金额 (GMV) 中，最终转化为平台自身净营收的百分比。 |
| **SSSG** | 零售分销、餐饮连锁 | **同店销售增长率**：开业满 12 个月以上的老店在剔除新开店面积扩张扰动后，纯粹依靠客流与客单价提升带来的内生增长率。 |
| **RevPAR** | 酒店度假、文旅商业 | **平均每间可供出租客房收入**：$RevPAR = 平均单日房价 (ADR) \times 客房入住率 (Occupancy Rate)$。衡量酒店资产真实运营盈利能力的王牌指标。 |
| **Rate Base** | 受监管公用事业（电网、燃气） | **受监管准许费率基数**：公用事业企业名下获得政府公用事业委员会核准的净在役固定资产资产净值，乘上准许权益回报率（Allowed ROE）决定了企业法定净利润上限。 |
| **AUM** | 资产管理（公募、私募股权） | **资产管理规模**：受托管理的第三方客户资本总额。乘上基础管理费率决定了确定性经营造血底盘。 |
| **FRE** | 资产管理（另类资管巨头） | **费用相关收益**：扣除全部刚性运营支出后，纯粹由管理费产生的真实现金收益，不含易波动的业绩提成 Carry，具备极高的估值稳定性。 |
| **Float** | 保险承保（财产险、再保险） | **保险浮存金**：预先收取的客户保费在发生理赔前长期滞留在保险公司账上的无息甚至负成本资金，巴菲特伯克希尔进行超级长期复利投资的核心秘密。 |
| **Combined Ratio** | 保险承保（财产意外险） | **综合成本率**：$赔付率 + 费用率$。数值 $< 100\%$ 表明纯承保业务自身即可实现盈利，享受无息甚至“倒贴利息”的浮存金；$> 100\%$ 意味着承保亏损，依赖投资端收益弥补。 |
| **NIM** | 资产负债表放贷（商业银行） | **净息差**：$净利息收入 \div 生息资产平均余额$。衡量银行运用资金获得利息收入与付出资金存款利息成本之间的利差空间。 |
| **CECL** | 商业银行、消费金融 | **预期当前信用损失模型**：会计准则要求金融机构在贷款发放当日就必须针对整个生命周期预估坏账并计提信贷减值准备，极大提前了风险暴露时间。 |
| **FFO / AFFO** | 房地产投资信托 (REITs) | **营运现金流 / 调整后营运现金流**：在净利润基础上加回不动产折旧摊销，并扣除维持物业现状所需的经常性维护资本开支，是评估 REITs 真实股息派发能力的唯一客观标尺。 |
| **NNN** | 资产租赁、单租户商业地产 | **三重净租约**：租客全额承担物业资产的所有房地产税、建筑保险以及日常物业维护维修支出，出租方享受绝对旱涝保收的纯净现金流年金。 |
| **WALT** | 基础设施、仓储物流 REITs | **加权平均剩余租约期限**：按租金规模加权的在手租约剩余履约年限。数值越长表明未来现金流锁定程度越高，抗经济衰退抗周期性越强。 |

## 五、 宏观信贷、流动性潮汐与市场情绪温度术语

| 术语简称 | 英文全称 | 核心商业含义与买方投研直觉 |
| :--- | :--- | :--- |
| **OAS** | Option-Adjusted Spread | **期权调整利差**：企业高收益债（垃圾债）相对于同期限无风险国债的信用风险溢价。利差极度收窄提示市场盲目自满，利差飙升提示信用违约危机。 |
| **TIPS** | Treasury Inflation-Protected Securities | **通胀保值国债（实际利率锚）**：TIPS 收益率代表剔除通胀预期后的真实无风险资金成本。其实际利率大幅上行会强力杀伤长久期科技资产的估值倍数。 |
| **CAPE** | Cyclically Adjusted PE (Shiller PE) | **席勒周期调整市盈率**：用过去 10 年经通胀调整后的平均净利润计算的市场整体 PE，平滑了经济周期的盈利剧烈波动，是判断全市场大盘是否处于历史泡沫顶点的长周期温度计。 |
| **ERP** | Equity Risk Premium | **股票风险溢价**：$标普500隐含盈利收益率 (E/P) - 10年期美债无风险收益率$。衡量冒着股票波动风险相对于稳拿国债利息所能获得的额外补偿，数值接近零或为负表明股市性价比极度低劣。 |
| **VIX** | CBOE Volatility Index | **芝加哥期权交易所波动率指数（恐慌指数）**：基于标普500指数期权价格计算的未来 30 天隐含年化波动率预期。$> 35~40$ 往往对应恐慌抛售冰点区，$< 12$ 对应盲目自满过热区。 |
| **PCR** | Put/Call Ratio | **认沽/认购期权交易量比例**：看跌期权与看涨期权交易量的比值。数值异乎寻常高企通常意味着全市场充斥着恐慌对冲盘，具有强烈的反向指标意义。 |
| **Skew** | CBOE Skew Index | **期权偏度指数**：衡量深度虚值看跌期权相对于虚值看涨期权的溢价程度，度量对冲基金对尾部“黑天鹅暴跌”极端事件的对冲需求热度。 |
| **SLOOS** | Senior Loan Officer Opinion Survey | **美联储高级信贷员意见调查**：揭示全美主要商业银行对企业信贷标准是趋向“净收紧”还是“净宽松”，是领先宏观实体违约率 2~3 个季度的决定性先行指标。 |
| **情绪钟摆** | Market Sentiment Pendulum | **霍华德·马克斯情绪钟摆定律**：市场情绪永远在极度贪婪与深渊恐惧两极之间来回振荡，在理性合理中枢停留的时间最为短暂；风险在贪婪上涨中累积，在恐慌暴跌中释放。 |
| **第二层次思维** | Second-Level Thinking | **买方卓越认知思维**：第一层次思维问“这是否是一家好公司”，第二层次思维问“现价反映了多么完美的预期、谁在以这个价格卖给我、主流共识错在哪里、如果我对了超额收益从何而来”。 |

## 六、 市场微观结构、技术形态与风控术语

| 术语简称 | 英文全称 | 核心商业含义与买方投研直觉 |
| :--- | :--- | :--- |
| **ADX** | Average Directional Index | **平均趋向指数**：衡量价格趋势的强弱程度（不判断涨跌方向）。$ADX > 25$ 且持续上行表明单边强趋势确立；$ADX < 20$ 表明进入横盘无趋势弱震荡。 |
| **ATR** | Average True Range | **平均真实波幅**：衡量标的物在特定周期内的真实波动幅度绝对值。ATR 极度收窄通常意味着变盘临界点即将来临，常用作买方动态止损距离设定的客观物理基准。 |
| **均线排列** | Moving Average Alignment | **多头 / 空头排列**：短期、中期、长期均线从上到下依次顺向展开为多头排列（强上升趋势）；反之依次从下到上展开为空头排列（强下行趋势）。 |
| **箱体震荡** | Box Range Consolidation | **箱体结构**：价格在明确的水平阻力位上限与支撑位下限之间反复拉锯。在未发生放量实质性有效突破前，箱体下沿提供买点防御，箱体上沿形成估值压力。 |
| **移动止损** | Trailing Stop | **跟踪移动止损**：建仓盈利后，将止损触发线随着股价上行同步向上平移，永远不向下调低，以锁死账面已有利润，严防浮盈变为深套。 |
| **机会成本** | Opportunity Cost | **资本机会成本**：买方资金极其珍贵，将资本配置在平庸的 5%~10% 小机会上，意味着失去了在暴跌黄金坑中重仓胜率高、赔率大于 3:1 顶级暴利标的的权利。 |
