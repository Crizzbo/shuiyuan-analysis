# 术语表

> 本文件为知识库：术语速查。分析中遇到概念不确定时引用。

| 术语 | 含义 |
|------|------|
| TAM / SAM / SOM | 总体市场（渗透率×替代率）→ 可服务市场 → 可获得市场（瓶颈环节） |
| CR3 / CR4 / CR5 / CR8 | 行业前 3/4/5/8 大厂商市占率之和，衡量集中度 |
| UE 单位经济模型 | 单笔交易/单个用户的收入-成本模型（Unit Economics） |
| fwdPE | 前瞻市盈率 = 现价 ÷ 未来12个月预期EPS（分析师一致预期） |
| trailingPE | 滚动市盈率 = 现价 ÷ 过去12个月实际EPS |
| PEG | 市盈率相对盈利增长 = PE ÷ 增长率（<1 通常视为增长未被充分定价） |
| RPO | 剩余履约义务（Remaining Performance Obligations），云厂商在手订单积压指标 |
| 期望值 | 上涨概率 × 上涨空间 − 下跌概率 × 下跌空间 |
| 错误边际 | 买入价与内在价值的差距 = 安全边际 |
| 52周位置 | (现价 − 52周低) ÷ (52周高 − 52周低)，<25% 贴近低点 |
| 周期陷阱 | 周期顶部盈利虚高导致 PE 虚低，看似便宜实为假象 |
| 机会成本 | 小资金只做「一股能吃饱」的标的，赔率不够直接放弃 |
| 产能周期 | 供不应求 → 产能激增 → 产能出清 → 格局改善 |
| 情绪钟摆 | 市场情绪在贪婪与恐惧两端摆动，极少停在中间 |
| ADX | 平均趋向指数，衡量趋势强度：>25 且上升=单边趋势成立；<20=震荡无趋势 |
| ATR | 平均真实波幅，衡量波动率：ATR 收窄=震荡蓄势，放大=单边启动 |
| 多头/空头排列 | 短中长均线依次从上到下（多头）或从下到上（空头）排列，单边行情特征 |
| 箱体 | 价格在上下边界内反复震荡的区间形态；上沿卖、下沿买，放量突破才算方向选择 |
