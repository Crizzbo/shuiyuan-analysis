# 共同研究规则

每个行业都检查：需求真实性、商业模式、竞争与议价权、财务质量、资本配置、治理、债务及流动性、市场预期、重大风险和反证。

重点可随阶段调整，基础检查不得省略。区分公司质量、价格吸引力与行动适宜性。

每个指标定义 ID、对象、口径、单位、期间、公式或抽取方法、来源、发布时间、适用范围、不可用条件及更新频率。观测还需 recorded_at、known_at、证据引用及缺失原因。缺失与零不同，未知与中性不同。

每个判断规则记录 ID、版本、来源类型、输入、机制、支持和反对证据、适用条件、失效条件、验证状态与验证样本。阈值未验证前不允许硬编码为买卖裁决。

金额区分币种，百分比区分比例与百分点，财务数据区分 GAAP/非 GAAP、单季/全年/TTM、合并/分部和持续经营口径。非 GAAP 需保留调节项。

多个指标来自同一底层数据时识别相关性，不能把重复信息当成独立证据。估值要记录稀释股数、净债务、租赁和少数股权等桥接；无数据时明确未完成。
