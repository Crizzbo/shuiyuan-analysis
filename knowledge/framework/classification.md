# 行业与业务归类规则

行业字典采用内部稳定 ID，ID 不承载官方代码含义。当前为 sector/industry 两层，允许以 parent_id 添加 subindustry。层级、父节点和别名必须显式记录，禁止用显示名称连接数据。

公司通过业务分部连接多个行业与商业模式，产业链角色和主题标签独立。主行业判断需证据，不能用收入占比未知的数据强行排序。官方分类属于带来源和版本的外部映射。

更新分类时保留旧版本和时间范围；合并或拆分记录 replaces/replaced_by，稳定 ID 不随名称修改。新类别需边界、排除项、至少一个业务示例及复核状态。

权重区分 revenue/operating_profit/assets 等 basis，说明 period、币种和抵销项。亏损分部的利润占比不适合直接作为估值权重。分部信息缺失可以使用定性归类，但不能虚构精确比例。

主题可跨行业，平台可跨商业模式，ADR/REIT 等属性不替代行业。模板中的公司是假想对象，不能作为真实证券映射。
