# 项目内访问与引用政策

生效日期：2026-10-11，依据用户要求。

最新采用策略：六类需要额外配置的接口停用，不索取或读取其凭据；八类免配置来源继续执行。缺少数据用 AI 浏览器搜索官方公开原文，下载或保存明确标注的可见页面证据，先归档到项目。只导入当次浏览器实际返回的下载路径，不扫描项目外目录。搜索摘要和 AI 生成内容不作为原始事实。

研究资料、代码和指标观测仍引用项目内文件。初始结构建设采用离线资料；后续授权与实施状态以根目录 AGENTS.md 和建设文档为准。

2026-10-11 用户已授权免费原始数据来源调查与实际接入，允许只读检查猫哥公开采集源码。当前接入可访问显式来源配置中的官方 API、公开网站和成熟行情库，采用项目内虚拟环境；不读取外部账户配置，不自动订阅收费服务。远程原文先归档到本项目，再进入研究与计算。接入 URL 只是来源元数据，不能直接作为研究证据路径。

相对引用解析后的真实路径必须在项目内，避免符号链接越界。网络 URL、file URI、UNC 与绝对路径不得作活动引用。历史书目名称保留，原文缺失标记未核实。

结构校验针对知识文件，不等同操作系统沙箱。新工具必须采用同样的本地路径边界检查，执行者遵守根目录 AGENTS.md；旧 SKILL 在线工具要求不自动扩大授权，原始数据接入按新建免费计划执行。

数值校准需要足够的本地历史行情、时点可得财务数据和公司行动。当前已归档少量真实样板，尚未形成行业统计校准样本，因此行业规则仍为定性适配，回撤与估值阈值保持 null，不自动生成行动结论。
