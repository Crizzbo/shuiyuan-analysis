## 一、 微观造血机制与现金流飞轮

基础设施收费模式（Infrastructure Fee）是全球金融资本最青睐的“特许过路费”类微观造血机器。其商业本质是**“耗费巨资在关键地理区位或行业咽喉建设具备不可复制、排他性物理资产（如跨州管道、特高压电网、通信铁塔、深水港口），在漫长的特许经营期内，按照物理吞吐量、车流量、传输流量向使用者收取确定性费用的垄断年金机器”**。

```
              ┌────────────────────────────────────────────────────────┐
              │ 1. 取得主权特许经营权或环评路条，投入巨额不可逆资本沉淀│
              └───────────────────────────┬────────────────────────────┘
                                          ▼
┌────────────────────────┐    ┌────────────────────────┐    ┌────────────────────────┐
│ 4. 扩张资本开支终止    │    │ 2. 签署长期照付不议合同│    │ 3. 锁定下游核心使用方  │
│ 维持性支出极低 (<10%)  │◄───│ 绑定最低运量保底 (MVC) │◄───│ 建立通胀联动 (CPI) 调价│
│ 自由现金流爆发式大派息 │    │ 彻底隔离宏观大宗价格波动│    │ 构筑极高物理替换壁垒   │
└────────────────────────┘    └────────────────────────┘    └────────────────────────┘
```

### 1. 核心造血方程式
- **基础设施现金流生成方程式**：
  $$营业收入 = \sum_{j=1}^{m} (物理吞吐量_j \times 单位核准或市场化过路费率_j) + 刚性保底容量费 (Capacity Reservation)$$
- **照付不议与最低运量保底机制 (Take-or-Pay / MVC - Minimum Volume Commitment)**：
  成熟基础设施资产通常与下游信用优良的大型公用事业、跨国石油巨头签署 10～20 年不可撤销的长协合同。**客户即使单季度完全不运送货物或不使用管道，也必须按照约定的最低保证运量全额支付基础容量费**，使得该机器的收入与现金流与底层大宗商品的现货价格波动彻底脱钩；
- **资本开支双期分化与“年金化暴利”**：
  - **建设期**：承受极重资本开支包袱与高额债务杠杆；
  - **成熟运营期**：扩张性资本开支 (Growth Capex) 归零，维持性资本开支 (Maintenance Capex) 仅占营收 5%～10%，综合 EBITDA 利润率高达 55%～75%，扣除利息与税费后的**可分配现金流 (Distributable Cash Flow / DCF) 转化率超越 90%**，具备极其充沛的高分红与股份回购能力。

## 三、 买方排雷红线与脆弱性断裂点

### 1. 致命商业断裂点与假性繁荣陷阱
1. **监管费率追溯性削减风险 (Regulatory Rate Cuts)**：政府监管机构（如 FERC、各州公用事业委员会 PUC）在换届或民粹压力下，强行重新核准降低资产的准许权益回报率 (Allowed ROE) 或调低输配电/管网单位过路费率，导致企业年化造血盘子永久性结构缩水；
2. **下游核心承运大客户破产违约跳单**：基础设施资产虽然具备长期合同，但若签约的核心客户为投机级高杠杆中小型开采商或违约率高的物流公司，一旦经济危机爆发导致客户申请破产保护，法庭可能直接废除照付不议长约，导致基础设施利用率瞬间坍塌；
3. **加息周期下巨额浮动利率债务再融资穿仓**：基础设施在建设期积累了庞大债务，若债务结构中浮动利率占比过高，或在基准利率处于历史高位时面临数百亿美元债券集中到期，翻倍的再融资利息将瞬间吃光全部可分配现金流，引发股价断崖式崩溃。

## 四、 估值适配与模型选型

严格依据**资产特许期合同现金流折现 (Contracted DCF) 结合可分配现金流折现 (DDM)**：
1. **真实可分配现金流 (DCF) 计量**：
   $$可分配现金流 (DCF) = 调整后 EBITDA - 实际现金支付净利息 - 维持性资本开支 (Maintenance Capex)$$
2. **基础设施估值锚点**：采用基于长期特许经营年限的**自由现金流折现 (DCF, 6.5%～8.0% 稳健 WACC)**，结合企业价值倍数 (**EV/EBITDA, 9.0x～13.0x**)；
3. **股息率安全边际**：作为类固收资产，其股息收益率必须相比同期限基准国债收益率提供 **250～350 个基点的超额风险溢价**，且 DCF 覆盖倍数大于 1.4 倍时，才具备绝对投资安全边际。

## 六、 本地契约与法定买方核心反证逻辑

### 1. 本地契约规则
依据项目内 [指标字典](../metrics/catalog.json) 与 [行业规则](../taxonomy/industry_rules.json)。本模式作为油气中游、公用电网、通信铁塔、铁路运输、水利港口等行业的核心底层微观机器。

### 2. 法定买方核心反证逻辑
**“基础设施企业账面录得高达 7%～9% 的表观高股息收益率不等于投资绝对安全；若高分红完全建立在资产负债率超过 80% 的极高债务杠杆与人为压低维持性资本开支的脆弱假象之上，且签约客户充斥着高违约风险的投机级小企业，一旦遭遇宏观加息导致债务再融资成本暴增或核心客户破产跳单，随之而来的可分配现金流穿仓与被迫削减股息必将引发机构投资者踩踏抛售与戴维斯双杀。”**
